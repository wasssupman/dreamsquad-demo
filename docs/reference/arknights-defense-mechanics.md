# 참고: 명일방주(Arknights) 이동·저지·타겟팅 메커니즘

> 2026-07-20 deep-research 결과 정리. 출처: arknights.wiki.gg / arknights.fandom.com 의 Pathing·Attribute/Block·Aggression·Collision 문서 + PRTS 계열 상세 분석 + Kingdom Rush wiki (교차 일치 확인, 단 자동 검증 패널은 미실행 — 위키 원문 기반).
> 용도: 적 이동/공격 판정 설계 시 대조군. **우리 게임의 채택 여부와 무관한 사실 기록** — 결정은 하단 "우리 게임 결정 기록" 참조.

## 1. 적 이동

- 경로 = **저작된 액션 시퀀스("move → stop") + SPFA 최단경로**. 목적지(Position)와 ReachOffset 파라미터로 경로를 바이어스. 체크포인트는 작전별 저작 레이어.
- **오퍼레이터를 향한 동적 이동 없음**. 오퍼레이터를 피해가는 re-pathfinding 도 없음 — 경로 위에 있으면 저지당할 뿐.
- 로드블록(설치물)에 막히면 기본은 **재경로(reroute)**. 모든 출구가 봉쇄된 경우에만 장애물 공격으로 전환. "막히면 우회, 우회 불가면 그때 공격" 원칙.
- 이동 속도는 타일 단위(타일/2초), 슬로우는 곱연산 + 하한 0.1 (슬로우만으로 완전 정지 불가 — 정지는 저지/스턴/속박 소관).

## 2. 저지 (Blocking)

- 발동 = **동일 타일 점유/히트박스 접촉** (오퍼레이터 충돌원 반경 0.25타일). 원형 충돌 기반이며 타일 경계가 아니라 히트박스에서 멈춤.
- 저지 순간 **"정지 + 저지자 공격"이 단일 결합 상태 전환** — 정지했는데 공격 안 하는 상태가 구조적으로 불가능.
- **fiat 사거리 보장**: 저지된 적은 기하적으로 사거리 밖이어도 저지자의 사거리 안으로 간주 (예외: 무적 상태). 상호 공격 가능성을 규칙으로 강제.
- 저지 수 초과분은 **그냥 통과** (대기/고착 없음). 적측 block weight(1~4, 보스 페이즈로 가변)·저지 불가 적 존재.
- 원거리형 적은 melee/ranged 공격을 따로 갖고 **저지되면 melee 모드** 전환, 해제 시 즉시 ranged 사용 가능 (쿨다운 독립).

## 3. 타겟 선정 (적 → 아군)

- 우선순위: **저지자 > 특수 우선 > 높은 도발 > 최근 배치 > 낮은 도발**. "최근 배치 우선"은 별도 규칙이 아니라 공식의 결과.
- 어그로 값 공식: 아군 `10000 × 도발레벨(-2~2) + 배치경과시간(≤10000초)`, 적측 `1000 × 도발레벨 − 남은 경로거리`.
- **도발에는 사거리 개념이 없음** — 유닛에 붙는 수치일 뿐. 판정 기하는 **오직 적의 공격 사거리** (후보 풀 = 적 사거리 내 유닛, 도발은 그 안에서의 순위만). 적 사거리 밖 도발자는 비교 기회조차 없음.
- 타겟 탐색은 **3프레임 주기 스캔**(초당 10회, 유닛별 위상 독립). 공격 애니메이션은 락온 타겟에 커밋 (사거리 이탈해도 명중).
- 근접 오퍼레이터는 저지 대상 최우선 selector 보유, 원거리 오퍼레이터는 없음 (비대칭).
- **적을 물리적으로 데려오는 것은 도발이 아니라 강제이동(밀치기/당기기) 스페셜리스트** — 완전 별개 카테고리.

## 4. Kingdom Rush 비교

- 병사 저지 = 무조건 멜레 락 (적 이속 무관). 해제 조건 3개뿐: 병사 사망 / 적 사망 / 랠리 이동. 타이머·거리 해제 없음.
- **저지된 적은 반드시 반격** (교전 결합 보장). 저지 초과 통과, 원거리 적은 저지 없이 원거리로 병사 공격, 비행 통과.
- 저지의 설계 목적 = 킬이 아니라 **다른 타워의 딜 존에 묶어두기**. 카운터(AoE 적·원거리 적·비행)로 무한 스톨 방지.

## 5. 설계 불변식 (두 게임 공통)

1. **멈춘 적은 반드시 때린다** — 정지와 공격이 결합 상태이거나(저지), fiat 으로 사거리를 보장. "정지했는데 공격 못 하는 좀비"가 규칙 차원에서 불가능.
2. **갈 수 없으면 멈춰 있지 않는다** — 저지 초과/불가 시 통과, 경로 봉쇄 시 재경로. 도달 불가 상태로 고착되는 유닛이 없음.

## 우리 게임 결정 기록 (2026-07-20 사용자 결정)

- **명일방주식(접촉 저지 + 가중치-only 도발)으로 가지 않는다.** 이유: 우리 게임은 방어유닛이 적 이동경로 밖(Place 타일)에만 배치되는 전제라 접촉 저지의 몸통이 성립하지 않고, 마그넷 어그로(적을 끌어옴)는 유지할 고유 기획.
- **현행 구조(어그로가 이동 목표를 바꿈)를 유지하고 이동 버그를 잡는다.** 방향: 유닛 위치 추적 직선 이동이 아니라 **어그로 대상의 타일을 기준으로 목적지 타일을 정하고 경로 기반으로 이동** (상세는 해당 spec 참조).
- 위 불변식 2개는 우리식으로 번역해 채택한다: 정지⟺발사 metric 일치(기 구현) + 도달 불가 시 고착 금지.
