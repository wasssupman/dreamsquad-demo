# 드림캐쳐 시스템 최종 스펙 — 각성안 (v1)

> 재화의 정체성을 "각성"으로 확정한 안. 죽음(악몽·아군)을 자원으로 바꾸고, 유저가 자기 타이밍에 드림캐쳐(이하 드캐)를 산다.
> 문체 원칙: 쉬운 말, 짧게, 핵심만. 판내 UI에서 "카드/코스트/TCG" 용어 금지.

---

## 1. 한 줄 요약

**죽이고 죽으면 각성치가 쌓인다 → 버튼 눌러 손패를 열고 → 각성치로 드캐를 사서 유닛에 붙인다.**

이게 판내 규칙의 전부다.

---

## 2. 각성 — 재화 얻는 법

- **적(악몽)을 죽이면** 각성치를 얻는다. 악몽마다 값이 다르다.
- **내 유닛이 죽으면** 각성치를 더 크게 얻는다. → 유닛을 앞세워 갈아넣는 게 손해가 아니라 수익이다.
- 아군 사망은 각성치만 준다. **본진 HP와 무관하다.** (본진 HP는 적이 본진에 닿을 때만 깎인다 — 별개 사건)

**설계 의도**: "자주 죽고 자주 재배치"라는 코어 템포를 경제로 보상한다. 사리기(에이스 아끼기)가 규칙이 아니라 손해라서 저절로 사라진다.

**수급 감각 (기준값, 테스트로 조정)**
- 1웨이브에 악몽 10~20마리 노출, 웨이브당 각성치 70~80.
- 방어 유닛 2~3기 사망 시 +10 정도.
- 드캐 가격: 개별 타겟 15 / 스쿼드 타입 30.
- → 분당 5~6장, 넥스트웨이브 없이 3분 플레이 시 총 15장 전후 획득.

---

## 3. 드로우와 손패 — CR식 순환

- 판내 큐 **총 12장** = 내 부착 덱 **10장**(판 밖 구성) + 공용 드캐 **2종**(매판 공통 배정, §8). 랜덤 없음, 순서 고정 — **다음에 뭐가 올지 항상 안다.**
- **드로우 버튼**을 누르면 큐에서 손패로 **5장** 공개.
- 손패의 부착 드캐는 각성치로 사서 유닛/스쿼드에 붙이고, 공용 드캐는 각성치로 필드에 쓴다.
- 부착 드캐는 **붙은 유닛이 죽어야**, 공용 드캐는 **쓰면** 큐 맨 뒤로 돌아온다(순환 규칙 A, §8).
- 붙은 것 + 손패로 12장이 다 나가 있으면 **드로우 불가.** (죽여서/써서 순환시켜야 다시 뽑음)

**덱빌딩 감성**: 12장을 다 알고, 순서를 짜고, "이걸 쓰면 몇 장 뒤에 저게 온다"를 센다. CR 사이클과 같은 얕고 예측 가능한 덱 감성.

---

## 4. 부착과 슬로모 — 손 바쁨 관리

- **게임은 안 멈춘다.** 단, 손패를 열고 스와이프를 시작하면 **슬로모 모드**로 전환.
- 슬로모 덕분에 위기 중에도 침착하게 살 수 있다. → 자유 타이밍 지출(내 돈 내 타이밍)의 대가인 손 바쁨을 슬로모가 흡수.
- 부착 흐름: 손패 열기 → 드캐 선택 → 스와이프로 유닛에 붙이기. 목표 2탭 이내.
- 유닛당 최대 3개.
- 오부착 방어: 스와이프 후 1~2초 확정 지연(취소 가능, 리플레이엔 안 남음).

---

## 5. 드캐 종류 — 전부 전술

- **일반/고유 등급 없음.** 모든 드캐가 규칙·행동을 바꾸는 **전술 카드**다.
- **스탯 상승 드캐 없음.** 체급·기초 스탯은 전부 **스쿼드(판 밖 메타)**가 공급한다. 판내 드캐는 숫자를 안 올린다.
- 드캐 가치는 **적용 범위**로 갈린다: **개별 유닛 타겟(싸다)** vs **스쿼드 전체(비싸다, 덱 수량 제한)**.
- **스케일 불변 규칙**: 전술 효과 수치는 체급과 무관해야 한다. (히트 횟수, 지속 웨이브, 범위, 타겟팅 규칙 O / "공격력 +n%" 같은 스탯 스케일링 X) → 낮은 레벨이 전술로 뒤집는 서사를 지킨다.
- **동일 드캐 중첩**: 각 전술은 조정 숫자(예: 튕김 +1, 반경 +m)를 필수로 가져 중첩이 자연히 정의된다.

---

## 6. 무의식 — 저주 드캐 (그대로 유지)

- 하이리스크 하이리턴 전술. 흔히 말하는 **저주 카드.**
- EV는 일반 전술과 등가, **분산만 크다.** "세기 차이 금지, 상황 차이만" 규율의 극단 사례이지 위반 아님.
- **규율: 리스크는 선불·즉발, 리턴은 후불·지속.** → 저주 유닛을 일부러 죽여 리스크만 배출하는 세탁을 차단.
- 채용은 자발적. 등록 덱에 안 넣으면 안 뜬다. 저주의 리턴은 "판내 회피를 벌주는" 게 아니라 "덱에 넣고 싶게 만드는" 크기여야 한다.
- **스쿼드 저주**는 판 전체 성격을 바꾸는 최강 표현군 → 덱당 1장 상한.

---

## 7. 스쿼드 타입 드캐 — 수량 제한

- 스쿼드 전체에 적용, 개별 타겟의 ~2배 가격/가치.
- **덱 구성 시 수량 제한** (≤ 판당 예상 드로우 횟수). 몰빵 배열 차단.
- 모든 스탯 성장 책임은 스쿼드 메타에 있고, 판내 스쿼드 드캐는 전술만 제공.

---

## 8. 공용 드림캐쳐 — 액티브형 (소환사 주문 역할)

지금까지의 드캐가 유닛에 **붙이는 지속 전술**이라면, 공용 드캐는 유저가 필드에 **직접 쓰는 순간 전술**이다. 롤의 소환사 주문처럼 유닛 스킬과 별개 롤.

**서사 전환 — 왜 "스킬"이 아니라 "공용 드림캐쳐"인가**
- 원래 이건 "토너먼트 배정 공용 스킬"로 구상됐다. 이걸 별도 시스템으로 두지 않고 **드캐 우산 아래로 흡수**한다: "매판 모두에게 공통 배정되는 드림캐쳐".
- 이득은 셋. ① 유저 인지 비용 0 — 새 시스템이 아니라 드캐의 한 종류. ② 재화 통일 — 부착 드캐와 같은 각성치를 쓴다("부적 붙일까 스킬 쓸까"의 지출 경쟁이 생김). ③ 순환 통일 — 같은 큐에 들어가 같은 규칙(아래)으로 돈다.
- 판내 UI 용어는 "드림캐쳐"로 통일. "스킬/소환사 주문"은 설계 문서용 비유일 뿐.

**구조 (확정)**
- **10명 전원 완전 동일 배정.** 개인 선택 없음. 동일 시드 스코어어택이라, 같은 도구로 **누가 더 잘 썼나**에서만 점수가 갈린다 → 공용이 실력 귀속을 오히려 선명하게 만든다.
- **덱 풀에 포함, 총 12장.** 내 부착 덱 10장(온전히 내 것) + 공용 드캐 2종. 내 슬롯을 안 먹으므로 개성 표현 공간은 그대로.
- **손패로 뽑히고, 각성치로 쓴다.** 부착 드캐와 완전히 동일한 획득·지출 흐름.
- **순환 규칙(A): 쓰면 덱 맨 뒤로.** 부착 드캐가 "죽으면 맨 뒤"인 것과 대칭 — 공용 드캐는 "쓰면 맨 뒤". 규칙이 하나로 통일된다.
- 타겟: 타일 / 적 유닛 / 아군 유닛. (예: 포탈 — 타일 2회 찍어 적을 마지막 위치로 N초간 전송 / 레이지 — 아군 공속 +50% 5초 / 토네이도 — 타일에 적을 띄워 이동 방해)
- **컨셉: 유틸·응급 한정. 딜 없음.** 위기 순간 판을 구하는 순간기이지 상시 효율기가 아니다.

**"스킬만 쓰기"가 구조적으로 불가능한 이유 (확인됨)**
- 공용 드캐를 쓰면 큐 맨 뒤로 간다 → 다시 손에 오려면 앞 카드들이 큐에서 빠져야 한다 → 그러려면 **부착 드캐를 소비(붙이고 죽여 순환)해야 한다.** 부착을 안 쓰면 큐가 안 돌아 공용 드캐도 안 온다.
- 즉 스킬 편식은 순환 큐가 물리적으로 차단한다. 별도 규칙 불필요.
- **부수 효과 (좋음)**: 공용 드캐 재등장 간격이 내 부착 순환 속도에 묶인다. 유닛을 자주 갈아넣는 공격적 플레이일수록 스킬도 자주 온다 → 각성안 코어(죽음=자원)와 스킬 접근성이 같은 엔진에 물린다.

**밸런스 안전핀**
- 유틸·응급 한정이 필수 제약이다. 만약 공용 드캐에 딜이 붙으면: 스킬은 유닛 커밋·죽음 리스크 없이 각성치만으로 쓰이므로, 리스크 없는 쪽이 효율까지 좋아져 부착 경제를 압살한다.
- 따라서 **공용 드캐 단독으로는 점수(클리어·방어)가 안 나야 한다.** 실제 방어력은 유닛 부착에서만 나오고, 공용 드캐는 그걸 보조. 응급 컨셉이라 평시 사용은 각성치+순환 슬롯 낭비 → 유저가 알아서 아껴 쓴다.

## 9. 판 흐름

```
[판 밖] 스쿼드 편성(체급) → 부착 드캐 10장 덱 구성/순서 확정
   ↓
[판 시작] 시드 고정 · 각성치 0 · 큐 = 내 10장 + 공용 2종 = 12장
   ↓
┌─ 웨이브 루프 (비정지, 최대 15웨이브) ───────────┐
│  유닛 배치/재배치                                │
│  악몽 처치 → 각성치 +소량                         │
│  아군 사망 → 각성치 +다량 (본진 HP 무관)          │
│  웨이브 당기기 → 각성 가속 도박                    │
│                                                 │
│  [드로우 버튼] → 손패 5장 공개                    │
│  [손패 열고 스와이프] → 슬로모 전환               │
│    · 부착 드캐 → 유닛/스쿼드에 부착               │
│    · 공용 드캐 → 타일/적/아군에 사용 (응급)       │
│  유닛 사망 → 붙은 드캐 덱 맨 뒤로 순환            │
│  공용 드캐 사용 → 덱 맨 뒤로 순환 (규칙 A)        │
└─────────────────────────────────────────────────┘
   ↓
[판 종료] 점수 3축 = 시간 × 잔여 HP × 당기기
   ↓  판내 각성치·손패·부착 전부 소멸
[해몽] 리플레이로 승패 귀속 확인
   ↓
[동일 시드 재도전] → 덱 순서 다시 짜서 재도전
```

## 10. 점수와의 관계 (모순 없음 확인)

- 각성 벌이(아군 사망)와 점수(본진 잔여 HP)는 **다른 사건.** 서로 안 잡아먹는다.
- 좋은 트레이드오프만 남는다: **얼마나 갈아넣어 각성을 벌고, 얼마나 지켜 HP를 남길까.**
- 웨이브 당기기 = 각성 가속 vs 리크 리스크. 점수 3축과 경제가 한 몸.

## 11. 구현 요건 (`Game.Core`)

- 판내 상태: **덱 순서 큐(12장) + 손패 + 부착 맵 + 각성치(정수)**. 4존 상태 기계 불필요, CR식 큐 하나.
- 카드 서브타입: `Passive`(부착형) / `Active`(공용 드캐). 같은 큐·같은 손패에 공존, 순환 트리거만 다름 — Passive는 호스트 사망 시, Active는 사용 시 즉시 큐 말미 재삽입.
- 공용 드캐 2종은 판 시작 시 큐에 주입(전 유저 동일). 큐 삽입 위치도 결정론 고정.
- 모든 랜덤 배제 — 큐 순서 고정, `UnityEngine.Random` 금지.
- 모든 조작(드로우·구매·부착·공용 사용)은 타임스탬프 입력 이벤트 → 리플레이는 이벤트만으로 재구성.
- 슬로모는 **뷰 전용**. 시뮬 틱은 결정론 유지, 슬로모가 시뮬 속도에 영향 금지.
- 부착·공용 사용 확정 지연은 뷰 전용 pending → 커밋 시에만 시뮬 반영.
- 식별자는 인스턴스(`UnitInstanceId`, `CardInstanceId`) — 중복 배치·중첩 전제.
- 스탯 합성 페이즈 규칙(가산 전부 → 곱셈 전부), 등록 순서 의존 금지.

## 12. 튜닝 계수

| # | 계수 | 역할 |
|---|---|---|
| ① | 악몽별 각성치 표 | 웨이브당 총 수급 |
| ② | 아군 사망 각성치 | **최중요.** 사망 재화의 지분 = 이 안의 정체성 강도 |
| ③ | 드캐 가격 (개별/스쿼드) | 판당 드캐 획득 장수 앵커 |

| ⑤ | 사망 드캐 재삽입 위치 | 순환 속도 (구 회수비 후계) |
| ⑥ | 공용 드캐 코스트 | 응급성·유틸 강도 대비 각성치 비용. 부착 경제와 같은 시트에서 튜닝 (스킬 지출이 부착을 압살하지 않게) |

## 13. 테스트로 닫을 것 (종이로 못 닫음)

- **G1 재화 진폭**: 유닛이 강해지면 각성 수입이 마르나(디플레), 더 당겨서 버나(인플레). 둘 다 유저 선택으로 성립하되 진폭이 건강한 범위인지 실측. ②·③이 조정 노브.
- **G2 슬로모 체감**: 슬로모 전환이 위기 중 구매를 실제로 편하게 하나, 오히려 흐름을 끊나.
- **G3 사망 지분**: 아군 사망 각성치가 전체의 몇 %인가. 너무 낮으면(악몽 킬 지배) "사망 재화"라는 정체성이 희석 — 30%+ 목표.
- **G4 손패 5장 유효성**: 뽑고 싶은 게 5장 중 몇 장인가. 항상 0장이면 풀이 심심하거나 상황 대응이 안 되는 것.
- **G5 공용 드캐 지출 균형**: 공용 드캐 코스트(⑥)가 부착 지출을 압살하지 않나. 응급 한정이라 우선순위는 낮으나, 응급 발생 빈도가 높으면 스킬 지출이 커져 부착이 마를 수 있음.
- **G6 공용 드캐 응급성 체감**: 유틸·딜 없음 컨셉이 실제로 "위기에 아껴 쓰는" 행동을 유도하나, 아니면 상시 남발되나. 남발되면 코스트 상향 또는 효과 재설계.
