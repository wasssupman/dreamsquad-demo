# 아군 몸 원장 — footprint → 반경·피벗·소켓

> 정본 계약: `docs/spec/distance-based-range/README.md` 계약 1 rev 3 (2026-09-01 외부 세션).
> 코드 소스: `DefenderUnitData.BodyRadiusTiles`(파생식) · `FootprintMath`.

## UX 확정 문구 (2026-09-01)

- **「닿아 보이면 맞는다」**
- **「그림자가 진실이다」** — 적 그림자가 내 사거리 링에 닿으면 사거리 안. 근사가 아니라 판정식과 동치.
- **「적은 네 유닛을 막아서지 않는다 — 지나가는 놈을 잡는 게임이다」**

## 파생 규칙 (표가 아니라 식)

| 항목 | 식 | 근거 |
|---|---|---|
| 판정 반경 | **min(W,H)/2** (점유 박스 내접원) | 「안 닿았는데 맞음」 원천 차단 · 신규 footprint 자동 적용 |
| 몸 중심 | 앵커 + ((W−1)/2, (H−1)/2) = 기하 중심 | sim `LocalTransform` 그 자체 |
| 그림자 지름 | **2 × 반경** (상시, lift 로 안 줄어든다) | 그림자 = 판정 캐리어 |
| 피벗(스프라이트) | **점유 박스 하단 중앙** | 발밑 = 화면의 「서 있는 곳」 |
| 소켓(투사체 피격점) | 미저작 = 중심 + 기본 높이 (unit 16 대기) | 명중 판정은 접지 원이 결정 — 소켓은 뷰만 |

예: 1×1 → 반경 0.5 / 그림자 지름 1칸 · 2×2 → 1.0 / 2칸 · 2×3 → 1.0 / 2칸(장축 끝은 몸 밖 — 원 근사 수용).

## 아트 발주 규격 (B트랙 선행)

1. 피벗 = 점유 박스 하단 중앙. **루트모션 금지** — 런지·넉백은 시각 오프셋만(판정 위치는 sim 이 소유).
2. **그림자는 UI 다, 연출이 아니다.** 아트가 분위기용 소프트 섀도를 얹으면 「그림자가 진실이다」가 깨진다.
   그림자는 코드가 그린다(블롭, 지름 = 2r) — 에셋에 그림자를 굽지 말 것.
3. 접지 실루엣이 그림자 원(지름 min(W,H)칸)을 크게 벗어나지 않게 — 벗어난 몸통은 「닿아 보이는데 안 맞는」
   읽기를 만든다(키 큰 스프라이트의 비주얼 권위 문제, unit 15).
