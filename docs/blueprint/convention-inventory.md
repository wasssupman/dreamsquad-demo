# 전복 인벤토리 — 장르 관습의 의식적 채택/기각

> 장르(타워디펜스) 유저가 «당연히 이럴 것» 이라고 들고 오는 관습 중, 이 게임이 **의식적으로**
> 기각하거나 뒤집은 것의 기록. 항목이 여기 있다는 것은 「몰라서 빠진 게 아니라 알고 뺐다」는
> 뜻이며, 뒤집으려면 등재된 상속 조항을 함께 이행해야 한다.

## 1. 저지(블로킹) 관습 미채택 — 2026-09-01 확정

- **관습**: Arknights 계열에서 배치 유닛은 적을 몸으로 막아 세운다(저지 수). 유저 직관 충돌 계열.
- **이 게임**: **적은 방어유닛을 통과한다.** 판정은 원거리/근접 공격뿐, 몸은 표적이지 벽이 아니다.
- **왜**: 3분 킬 레이스 설계 — 흐름을 세우는 게임이 아니라 지나가는 흐름을 깎는 게임이다.
  UX 문구: 「적은 네 유닛을 막아서지 않는다 — 지나가는 놈을 잡는 게임이다」.
- **상속 조항**: 훗날 어떤 형태로든 블로킹을 도입하면 **블로킹 반경 = bodyRadius(판정 몸) 강제.**
  별도 저지 반경을 만드는 순간 「그림자가 진실이다」(그림자 = 몸 = 판정)가 깨진다.
