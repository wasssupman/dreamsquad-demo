# 드림캐쳐 구슬 독 — 브레인스토밍 결과 (2026-07-23)

> 얇은 design 문서. 구현 상세는 `docs/spec/dreamcatcher-orb-dock/` 참조.

## 문제

모바일 가로 양손 그립에서 우하단 각성 버튼(`AwakeningGaugeView`, 244px)이 전혀 인지되지
않는다. 우하단은 (a) 오른손 엄지 뿌리에 물리적으로 가려지고, (b) 시선은 전투 중앙에 있고,
(c) 엄지 작업 동선(트레이↔보드)이 코너를 지나지 않는 3중 데드존이다. 버튼이
재화 표시·ready 알림·덱 열기 스위치 세 역할을 전부 데드존에 두고 있는 게 근본 원인.

## 결정

1. **위치**: 우하단 코너 버튼을 제거하고, 통합 트레이 **오른쪽에 인접하되 분리된 독**을
   신설한다. 엄지 홈 포지션·시선 동선 위로 이동. 트레이 내부 셀이 아니라 별도 독인 이유:
   손패 열림 시 유닛 트레이만 플립되고 독은 같은 자리에 상주해야 재탭=닫기가 성립.
2. **형태**: 카드백/버튼이 아니라 **드림캐쳐 구슬**. 구슬 안에 스러진 유닛들의 미니
   피규어(Spine 최종 포즈, 스케일 ~0.2)가 물리로 떨어져 쌓이고 부딪힌다. 재화가
   "개수·부피"라는 실체로 보이고, 재화 소스(적 처치+수비수 사망)와 스토리가 일치.
3. **피규어 렌더링**: 베이크 없이 Spine 인스턴스를 `UpdateMode.Nothing`으로 프리즌
   (사용자 제안). 스폰 시 사망 애니 마지막 프레임 1회 적용 후 동결. 풀링 + 상한 20개.
   드로우콜 문제가 실기기에서 확인되면 스틸 베이크는 폴백.
4. **물리**: Physics2D 대신 원형 컨테이너 + 원-원 충돌 초경량 자체 시뮬. 순수 함수
   (제약 10) → EditMode 테스트. 마스크 불필요(물리 경계 + 림 오버레이) — UGUI Mask 는
   코스트 물통 스텐실 사고 전례로 금지.
5. **열기/닫기**: 구슬 탭=열기(기존 `Toggled → DreamcatcherHandView` 계약 유지),
   재탭+손패 바깥 탭=닫기. 드래그 실패 카드 복귀는 취소로 유지(닫힘 승격 금지).
6. **흡수 연출**: 킬/아군 사망 위치 → 구슬로 구슬 파티클 비행, 도착 순간 피규어 드롭.
   시선이 있는 중앙에서 출발하는 궤적이 독 위치를 반복 학습시킨다.

## 기각/보류한 대안

- 현 위치 유지+신호 강화(B안): 가림 존 자체가 남아 우회에 불과 — 기각.
- 카드백 peek+스와이프(C안): 제스처 발견성·드래그 방향 판별 부담 — 스와이프는 후속 후보로.
- 트레이 내부 셀(A-1): 손패 플립 시 셀만 남는 어색함 — 분리 독으로 대체.
- 스틸 스프라이트 베이크: 프리즌 스켈레톤으로 충분 — 성능 폴백으로만 유지.
