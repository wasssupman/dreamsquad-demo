# 드림캐쳐 적용 프로토타입 — 기능 요약

**목적:** 인게임에서 드림캐쳐를 뽑아 유닛에 효과를 적용하는 흐름만 프로토타입으로 구현하기 위한 최소 기능 명세. 카드 효과·수치는 부모 스펙 인용(새 값 아님).

---

## 1. 인게임 플로우 (핵심)

```
매치 시작
  ↓
[첫 유닛 배치 시점] → 덱 10장 중 3장 노출 → 1장 선택 → 효과 즉시 적용(장착)
  ↓
[5웨이브마다] → 3장 노출 → 1장 선택 → 효과 누적 적용
  ↓  (5/10/15/20… 웨이브 반복)
매치 종료
```

- 선택한 카드는 **그 판 끝까지 유지**(누적 장착).
- 노출 3장은 **덱 10장 안에서** 뽑힘. 중복 카드는 풀에 중복으로 존재.
- 선택 시 효과는 **조건에 맞는 아군 유닛 전체**에 적용(축 라벨 기준).

### 효과 적용 시점

| 시점 | 의미 | 해당 카드 |
|---|---|---|
| `passive_aura` | 장착된 동안 항상 적용 (기본) | 아래 표에서 별도 표기 없는 전부 |
| `on_place` | 유닛 배치 순간 1회 발동 | `G-LOWCOST-SUMMON-X2` |
| `match_start` | 매치 시작 시 1회 | `N-DECK-START-COST-2` |

---

## 2. 카드 목록 (적용할 기능)

### 일반 10장

| 코드 | 적용 대상 | 효과 |
|---|---|---|
| `N-CLS-RANGER-AS-10` | 레인저 전체 | 공속 +10% |
| `N-CLS-RANGER-ATK-10` | 레인저 전체 | 공격력 +10% |
| `N-CLS-RANGER-ROW-ATK` | 같은 행 레인저 | 공격력 +10% |
| `N-CLS-RANGER-CRIT-5` | 레인저 전체 | 치명타 +5% |
| `N-CLS-RANGER-PROJECTILE-PIERCE-1` | 레인저 투사체 | 관통 +1 |
| `N-COST-1-AS-5` | 1코 유닛 전체 | 공속 +5% |
| `N-COST-1-HP-10` | 1코 유닛 전체 | 체력 +10% |
| `N-CLS-GUARDIAN-HP-15` | 가디언 전체 | 체력 +15% |
| `N-CLS-GUARDIAN-TAUNT-RANGE` | 가디언 전체 | 도발 반경 +1칸 |
| `N-DECK-START-COST-2` | 코스트 시스템 | 매치 시작 코스트 +2 (`match_start`) |

### 고유 3장

| 코드 | 적용 대상 | 효과 |
|---|---|---|
| `G-GUARDIAN-FORTRESS` | 가디언 전체 | 체력 +50% · 이동속도 -50% |
| `G-RANGER-SPLASH` | 레인저 투사체 | 스플래시 부여 (반경 1.5칸, 60% 피해) |
| `G-LOWCOST-SUMMON-X2` | 1코 유닛 | 배치 시 50% 확률로 1체 추가 소환 (`on_place`) |

### 무의식 2장 (림으로 강제 편입)

| 코드 | 이름 | 효과 |
|---|---|---|
| `U-COST-FLIP-LOW-FREE` | 「공짜의 폭주」 | 1코 이하 유닛 코스트 0 · 2코+ 유닛 코스트 +2 |
| `U-NO-DEFENSE` | 「공격이 최선」 | 모든 아군 공격 +60% · 체력 -40% |

## 3. 덱 구성 (10장)

플레이어가 들고 입장하는 세이브덱. 룰: 정확히 10장 / 고유 ≤ 2 / 일반 중복 허용.

```
일반 8 + 고유 2
1  N-CLS-RANGER-AS-10
2  N-CLS-RANGER-AS-10        (중복)
3  N-CLS-RANGER-ATK-10
4  N-CLS-RANGER-ROW-ATK
5  N-COST-1-AS-5
6  N-COST-1-HP-10
7  N-CLS-GUARDIAN-HP-15
8  N-CLS-GUARDIAN-TAUNT-RANGE
9  G-RANGER-SPLASH           (고유)
10 G-GUARDIAN-FORTRESS       (고유)
```

- 덱 밖 스왑 후보: `G-LOWCOST-SUMMON-X2`, `N-CLS-RANGER-CRIT-5`, `N-CLS-RANGER-PROJECTILE-PIERCE-1`, `N-DECK-START-COST-2`.

---

## 4. 무의식 편입 (꿈런 중)

- 세이브덱(10장)엔 무의식 없음. 꿈런 중 **림 조우 시 거부 불가로 임시 덱에 추가**.
- 추가된 무의식은 인게임 3장 노출에 섞여 나올 수 있고, **봉인/디버프 신호로 표시**.
- 재조정 재화로 임시 덱에서 제거 가능 (세이브덱 원본 영향 없음).

---

## 5. 참고 (스펙과의 차이)

부모 스펙의 현재 인게임 흐름은 `빌드업 1택 + 1분/2분 5장 중 2택`(시간 기반). 본 프로토타입은 **`첫 배치 3중1 + 5웨이브마다 3중1`(웨이브 기반)** 로 단순화. 프로토타입 검증 후 채택 시 부모 스펙 갱신 필요.
