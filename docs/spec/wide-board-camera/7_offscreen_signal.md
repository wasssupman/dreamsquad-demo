# unit 7 — 화면 밖 상태 신호 계약

## 목적

판의 대부분이 안 보이는 게 정상이 된 뒤, **「지금 위험한가」를 무엇이 알리는지**를 계약으로 못박는다.
이 unit 은 대체로 **코드가 아니라 결정을 고정**하는 자리다 — 다음 세션이 미니맵이나 가장자리
지시자를 «합리적으로» 재발명하는 걸 막는 것이 목적이다.

## 계약

**화면 밖 상태를 알리는 신호는 통합 스트레스 비네트 하나다.**

그리고 **화면 밖 진입 루트 예고는 이 spec 이 풀지 않는다.** `spawn-point-alert` 의 스폰→골 경로 라인
트레일은 화면 안 정보이고, 판이 커지면 상당 부분이 화면 밖에서 흐른다. 방향 화살표로 대체할 수 없다 —
화살표는 방향을 말하지 **경로**를 말하지 못하고, 그 spec 이 셰브론 반복을 이미 한 번 폐기했다.
후보는 README 후속 후보의 「리드인 오버뷰 초대」이며, 초대는 «지금 볼 때다»이지 «어느 길로 온다»의
대체가 아니다 — 이 구분을 남겨 다음 세션이 화살표를 재발명하지 않게 한다.

- 마음이 맞으면 **화면 가장자리가 어두워지고 심박으로 뛴다**(`ScoreHudView` → `CameraDirector`).
  이건 **카메라가 어디를 보고 있든 작동하는 유일한 신호**다.
- 반대로 **마음 머리 위 스트레스 바는 월드 마커**라 팬하면 사라진다. 두 표면의 역할은 겹치지 않는다:
  비네트 = 「지금 위험하다」(offscreen-safe), 머리 위 바 = 「이 마음이 얼마나 남았나」(화면 안 정보).

## 만들지 않는 것 (그리고 이유)

**미니맵** — 사용자 결정. 상시로 **위치**를 보여주면 팬할 이유가 없어진다. 기각의 축은
「상시냐 아니냐」가 아니라 **「위치를 주는가」**다. 이 문장이 중요하다: 다음 세션이 「가장자리
지시자에 적 아이콘을 붙이자」로 미니맵을 재발명하는 걸 막는 것이 이 축이다.

**화면 가장자리 적 지시자** — 두 가지 이유로 만들지 않는다.

1. **자리가 없다.** 화면 가장자리는 이미 스트레스 비네트가 소유한다 — 위험할수록 안쪽으로 파고든다.
   위협 지시자를 거기 놓으면 **가장 필요한 순간에 가장 안 보인다.** 하단은 트레이·독·손패가
   100% 점유하고, 좌측은 선택 패널이 열리면 사라진다.
2. **곧 무의미해진다.** 후행 `heart-stress-axis` unit 에서 **마음 N개가 체력을 공유**하게 되면
   (사용자 결정 2026-08-25), 적이 어느 마음을 때리든 결과가 같다 → **「어느 쪽이 맞는지」가
   전술적으로 무의미**해지고 통합 스트레스 하나가 완전한 정보가 된다.

## 변경 대상

- `docs/spec/camera-direction/README.md` (계약 개정 — 아래)
- 코드 변경은 **없거나 최소**다. 기존 비네트 경로가 이미 카메라와 무관하게 작동한다 —
  이 unit 은 그 사실을 **검증하고 계약으로 적는다**.

## 구현

1. **비네트가 팬/오버뷰와 무관하게 작동하는지 검증**한다. 비네트는 포스트 처리라 카메라 포즈에
   독립이어야 하지만, 오버뷰 상태 전환 중에도 세기가 유지되는지는 확인이 필요하다.
2. `camera-direction` README 를 **세 곳** 개정한다 — 세 곳을 다 고쳐야 그 문서가 한 목소리를 낸다.
   - 「명시 제외 결정」 줄: *"플레이어 핀치 줌/팬 (조작 기능 — 하지 않기로 결정)"* →
     **"핀치 줌은 하지 않는다(줌은 상태가 소유). 팬은 `wide-board-camera` 가 개통했다."**
   - **개요 문단**: *"순수 연출 카메라다 — 플레이어 조작(핀치 줌/팬) 없음"* 도 같이 고친다.
   - 「카메라 탈취」 계약에 팬·오버뷰를 예외로 추가한다.
3. 이 spec README 의 「명시 제외」와 위 두 항목이 **서로를 가리키게** 한다.

## 완료 기준

- 팬을 끝에서 끝까지 밀고 오버뷰를 여닫아도 **스트레스 비네트의 세기·심박이 끊기지 않는다.**
- 마음이 화면 밖에 있는 상태에서 마음이 맞을 때, **화면만 보고 그 사실을 알 수 있다**(Play 확인).
- `camera-direction` README 계약이 개정돼 두 문서가 모순되지 않는다.
