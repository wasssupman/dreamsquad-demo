# unit 3 — 채널 진폭 재저작 + DoF 기준 전환

## 목적

카메라가 판에 가까워지면서 **기존 연출이 전부 과해진다.** 그리고 흐림 기준이 「보드 깊이」라
판 일부만 볼 때 의미를 잃는다. 둘 다 unit 2 가 만든 결과이므로 **같이 간다.**

## 왜 진폭이 변하나

델타는 절대 월드 단위로 합성된다(`CameraComposeMath` — `pos = basePos + baseRot * delta.localPos`).
화면에서 보이는 크기는 거리에 반비례하므로, 카메라가 절반 거리로 오면 **같은 진폭이 화면에서 두 배**가
된다. 각도 채널(pitch/roll)만 거리와 무관하다.

이건 새 발견이 아니다 — `pulseDolly` 의 config 주석이 이미 못박고 있다:
*"홈 포즈나 FOV 를 크게 바꾸면 이 값도 다시 환산해야 한다."*

영향받는 채널(위치 또는 dolly): 셰이크 진폭, 킬 스트릭 heat, 킥, 줌 펄스 dolly, 브리딩,
**드래그 포커스 dolly(`focusDolly`)**, 인스펙트 dolly, 손패 헤드룸 dolly, 이동모드 오버뷰 dolly.

**대상이 아닌 것 둘.** 드래그 포커스의 **lean 은 각도**(`leadYaw`/`leadPitch`)라 거리와 무관하다.
그리고 **배치 상태의 드래그 포커스는 `FocusDelta` 가 아니라 `PanDelta`** 이고 그 `localPos` 는 depth 에
정비례해 **이미 화면 정규화**다 — 재저작이 필요한 것은 전투 분기(`FocusDelta`)뿐이다.

## 구현

**진폭 재저작.** 새 전투 거리 기준으로 위치·dolly 채널을 전부 다시 잡는다. 값을 나눠 넣는 것보다
**실제로 보고 잡는다** — 킬 스트릭이 상시 도는 게임이라 셰이크가 팬보다 먼저 멀미를 만든다.
「거리로 나눈 진폭」 같은 자동 보정을 코드에 넣지 않는다: 채널마다 적정 체감이 다르고, 자동 보정은
다음 사람이 저작값을 못 읽게 만든다. **재저작이 맞다.**

**DoF 기준 전환.** 지금 임계는 **보드 깊이 범위**에 정규화돼 있다(0 = 보드 앞단, 1 = 뒷단).
판 일부만 보면 「보드 깊이」와 「보이는 깊이」가 갈라져, 전투 저작값(`dofStart 1.0 / dofEnd 1.6`)이
화면 밖 지점을 가리킨다 → 화면 전체가 선명하거나 전체가 흐려진다.
기준을 **뷰포트 깊이**(카메라 거리 + 수직 FOV 로 파생, unit 0 의 가시 사각형 재사용)로 옮긴다.
**오버뷰에서는 뷰포트 = 보드라 자동으로 기존 그림으로 수렴**한다.

**⚠ 값 이관이 아니라 재저작이다.** 뷰포트 깊이는 보드 깊이보다 훨씬 짧아 같은 숫자가 전혀 다른
그림이 된다.

**같은 원인의 UI 결함을 같이 잡는다.** 오버헤드 UI 는 컬링이 없고(NaN 가드뿐), **골·해저드 바는
`WorldToScreenPoint` 결과를 z 검사 없이 앵커로 쓴다.** 카메라 뒤 점은 부호가 뒤집힌 좌표를 주므로
**엉뚱한 자리에 바가 뜬다**(거울상). 지금은 판이 항상 카메라 앞이라 도달 불가한 분기지만, unit 4 가
칸수를 내리는 순간 라이브에서 난다 — DoF 의 `nearZ` 와 **같은 원인**이라 같은 자리에서 처리한다.
화면 안/밖 판정 1패스를 두고 (a) 오버헤드 UI 컬링 (b) 골·해저드 바 z 가드를 함께 건다.

**⚠ `nearZ` 부호.** `DofRange` 는 보드가 카메라 뒤면 `false` 를 주고 호출부가 DoF 를 **Off** 로
내린다. 지금은 판이 항상 앞이라 도달 불가한 분기지만, 넓은 판을 팬하면 판 끝이 카메라 평면 뒤로
넘어가 **팬 중에 흐림이 켜졌다 꺼졌다 한다.** 판정 대상을 **판 전체 bounds 가 아니라 가시 사각형**으로
바꾸면 이 깜빡임이 원인째 사라진다.

## 완료 기준

- **같은 이벤트의 화면상 진폭이 오늘 대비 ±20% 이내**다. 측정: 킬 스트릭 최대치·킥·줌 펄스를 각각
  고정 프레임에서 캡처해 오늘 빌드와 화면 픽셀 이동량을 비교한다(스크린샷 2장 비교).
- 그 위에 **사용자 체감 확인 1회**(이 항목만 사용자 판정 — 실기).
- 팬으로 판 끝을 카메라 뒤로 넘겨도 **골·해저드 바가 엉뚱한 자리에 뜨지 않는다**(거울상 없음).
- 화면 밖 유닛의 오버헤드 UI 가 갱신되지 않는다(컬링 동작 확인).
- **팬을 끝에서 끝까지 밀어도 흐림이 깜빡이지 않는다** — 이게 `nearZ` 수정의 관측 단언이다.
- 배치·전투 두 상태의 흐림이 의도대로(배치 = 끔, 전투 = 원경 빼기) 유지된다.
- 실기 확인 필수 — DoF 반경은 해상도에 비례한다.
