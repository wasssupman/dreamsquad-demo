## unit 0 이 철회된 이유 (2026-08-22 사용자 지시)

`spawnRoutes` 는 **레인의 성질**이라 그 맵의 **모든 웨이브**에 걸린다. 투어를 그 축에 얹으면
판 내내 같은 길이라 «가끔 다르게 온다» 가 성립하지 않는다. 저작한 경로 자체는 유효하고
unit 2 가 재사용하므로 버리지 않는다 — 꺼지는 것은 `spawnRoutes` 배선 하나다.

여기서 나온 규칙: **경로를 «누가 고르는가» 가 «어떤 그림이 나오는가» 를 결정한다.**
레인 축 = 항상 · 적 SO 축 = 그 적이 나올 때마다 · 컨셉 축 = 그 블록에만.

## 배경 — 왜 지루했나 (실측)

Duel 은 벽이 하나도 없는 개활지(23×10)에 강 한 줄(x=11)뿐이고, 저작된 경로는
`waypointPaths[0] = (11,4)` **공중 예약 하나**였다. `spawnRoutes` 는 비어 있어 지상 적 전원이
`pathIndex = -1` = 골 직행 = 플로우 최단이었다.

프로덕션과 같은 `FlowFieldBuilder` 로 재현한 현행:

```
lane0 (20,3) → x=11 을 y2 로 통과 (하단 다리)   dist 192
lane1 (20,5) → x=11 을 y7 로 통과 (상단 다리)   dist 200
```

두 레인이 갈리기는 한다. **다만 lane1 은 위·아래 총비용이 정확히 200 동률**이고, 갈리는 근거는
지형이 아니라 `FlowFieldBuilder` 의 동률 처리(직교 우선, 방향 순서)다. 즉 «지형이 가른다» 는
설명은 실제로는 «구현 세부가 가른다» 였다. 경로를 저작하면 그 의존이 사라진다.

## feature-wide 계약

1. **`waypointPaths[0]` 은 공중 예약이다**(`Enemy_Skimmer.waypointPathIndex = 0`). 지상 투어는
   **1번부터**. 되돌리지 말 것 — siege-lane-spawn 계약 4.
2. **투어 하나 = 경로 2개.** 레인마다 다른 투어를 주므로 `spawnRoutes` 는 항상 길이 2 이고
   `[lane0(하단 스폰), lane1(상단 스폰)]` 순이다. 길이가 파생 스폰 수와 다르면 빌더가 **조용히
   버린다** — 그 순간 전 맵이 최단거리로 되돌아간다.
3. **경유점 간격은 2칸 이상.** 도달 판정이 체비셰프 1(자기 칸 + 8이웃)이라 인접한 지점은
   자동 통과된다. 페인터·`OnValidate` 가 경고한다. 튜닝 손잡이가 아니라 격자 위상이다.
4. **경유점 사이는 최단거리다.** 웨이포인트는 «경유점» 이지 «경로» 가 아니다. 꺾이는 지점만
   찍는다 — 직선 구간을 채우면 아무 효과 없이 슬롯만 먹는다.
5. **경유셀 하나 = 플로우 필드 슬롯 (경유셀 × 통행층).** 저작만 하고 안 쓰는 경로도 굽는다.
   이 맵 크기(230칸)에서는 무시할 비용이지만 공짜는 아니다.
6. **투어 길이는 밸런스 knob 이다.** 3분 킬 레이스라 적이 오래 걸으면 방어 사격 시간이 늘고
   골 압력이 준다. 우회를 길게 잡을수록 판이 쉬워진다.

## 후속 후보

- **직행 경로도 거점을 관통한다** [S] — 경로 저작과 무관한 기존 성질이다. Duel 현행 최단거리가
  아군 본능을 lane0 3칸 · lane1 2칸, 적 본능을 3칸 지난다. 거점이 통행을 막지 않는 설계
  (instinct-content unit 1)의 파생이라 맵 저작으로는 못 막고, 「거점은 비켜 간다」를 흐름장이
  알아야 한다. 이 spec 범위 밖.

- **T4 뒷문 투어** — 골을 서쪽에서 치는 투어. 반전이 가장 크지만 골을 지나쳤다 되돌아오는
  구간이 어색해 보일 위험이 있어 T3 체감 뒤로 미룬다.
- **웨이브가 투어를 고르는 축** [M] — 지금 축은 «적 종류» 와 «입구» 둘뿐이라 투어가 판 내내
  고정이다. `WaveConceptSlot` 에 경로 인덱스를 추가하면 «이번 블록은 크게 돌아온다» 가 된다.
  배관은 `laneGroup` 이 이미 판 홈(컨셉 슬롯 → 배정 → 스폰 그룹 → 펼침 → 브리지)을 그대로 탄다.
  ⚠ rng 를 소비하지 않는 저작 필드로만 얹어야 웨이브 편성 재추첨을 피한다.
- **Ford·Isle 투어 저작** — 두 맵은 레인 경로가 «상단/하단 경유» 1점씩이라 여전히 거의 최단이다.
