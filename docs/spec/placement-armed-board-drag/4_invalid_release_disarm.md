# 4. 무효 릴리즈 = 선택 해제

## 목적

armed(트레이 셀 탭 선택) 상태에서 **못 놓는 자리에 손을 뗐을 때** 선택이 그대로 남던 것을 고친다.
릴리즈는 언제나 제스처를 끝낸다 — 유닛이 놓이거나, 선택이 풀려 원래 플레이 상태로 돌아가거나 둘 중 하나다.

기존 계약(unit 0·2)은 무효셀 릴리즈를 **"거부 + arm 유지(재시도)"** 로 뒀다. 재시도 배려였지만
실제로는 빠져나올 길이 슬롯 재탭뿐이라, 배치를 그만두려는 사용자가 선택 하이라이트와 배치 가능 타일
하이라이트를 켜 둔 채 갇혔다. 트레이 D&D(`EndDrag`)만 릴리즈에서 항상 상태를 정리하고 있어
**같은 배치인데 입력 방식마다 종료 규칙이 달랐다**.

곁가지로 같은 릴리즈 지점의 두 번째 구멍도 닫는다: armed 경로는 관대한 `TryScreenToCell` 을 써서
**맵 밖을 가장자리 셀로 clamp** 했다. 그래서 배경에 놓아도 가장자리 칸이 배치 가능하면 거기 배치됐다
— "배치 불가한 곳에 놓으면 취소" 가 성립하지 않는 상태였다(재배치 unit 9 가 같은 함정을 이미 기록).

## 구현

**공용 릴리즈 꼬리 하나로 모은다** — `ResolveArmedRelease(screen, out cell, out unit)`:

| 릴리즈 지점 | 결과 |
|---|---|
| 맵 안 · 배치 가능 | `true` 반환 → 호출자가 기존 시뮬 비행 배치(변화 없음) |
| 맵 안 · 배치 불가 | `FlashPlacementReject(cell)` + `Disarm()` → 선택 해제 |
| 맵 밖(셀 없음) | 취소음(`PlayCardReturn`) + `Disarm()` → 선택 해제 |

- `CommitBoardDrag`(드래그 릴리즈)과 `HandleBoardTap`(무이동 탭)이 **둘 다** 이 꼬리를 지난다.
  두 입력의 종료 규칙이 갈릴 여지를 없앤다.
- 셀 판정을 `TryResolveArmedCell` 로 바꾼다(릴리즈 + `UpdateBoardScout` **둘 다**). 한쪽만 바꾸면
  배경 위에서 가장자리 칸이 빛나는데 릴리즈는 취소로 가서 하이라이트가 거짓말한다.
  이 함수는 clamp 하는 관대 변환(맵 밖도 가장자리 칸으로 접어 true)도, 관용 0 의 하드 판정도 쓰지 않고
  **트레이 D&D 와 같은 `placementOutsideToleranceCells`(=1)** 를 태운 `PlacementCellSnap.Resolve` 를 부른다:
  - 관대 변환이면 "배치 불가한 곳에 놓으면 취소" 가 성립하지 않는다(배경에 놓아도 가장자리 칸이
    배치 가능하면 배치된다 — 재배치 unit 9 가 기록한 함정).
  - 관용 0 이면 **최상단 행 오버슛이 전부 취소로 돌아간다.** 배치 판정 포인터는 손가락보다 화면 위로
    65px(@1080) 올라가 있어 위쪽 행을 노리면 조준점이 격자를 넘기 쉬운데, D&D 는 1칸까지 용서해
    테두리 칸에 붙여준다. armed 만 0 이면 같은 손동작이 한쪽은 배치, 한쪽은 선택 해제가 된다
    (최상단 행 도달성은 `DragPlacementReachTest` 가 지키는 계약).
  - 관용 규칙을 여기서 재구현하지 않는다 — 정책은 `PlacementCellSnap.Resolve` 단독 소유.
    히스테리시스는 0 으로 넘긴다(armed 스카우트는 매 프레임 생 판정이 unit 1 계약).
  브리지에는 좌표만 넘기는 `TryScreenToBoardFrac` 하나를 연다(판정 없음 — clamp 도 bounds 도 안 함).
- press 게이트에서 "셀이 나와야 제스처 개시" 조건을 없앤다. 없애지 않으면 배경을 눌렀다 떼는 동작이
  상태기계에 도달하지 못해 선택이 남는다(= 고치려는 증상이 배경에서만 재현).
- 해제는 `Disarm()`(notify) — 슬롯 하이라이트 · 배치 가능 타일 하이라이트 · 스카우트 범위가
  기존 경로 그대로 정리된다(`Disarm` → `ResetBoardGesture` → `ClearBoardScout`). 새 정리 경로 없음.
- 거부 표시는 남긴다. 취소음만 내면 **왜** 안 놓였는지가 사라진다 — 칸이 빨갛게 튕기고 선택이 풀리는
  것이 "여긴 못 놓아, 그래서 놓던 걸 내려놨어" 한 문장으로 읽힌다.
