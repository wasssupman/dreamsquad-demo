# unified-effect-layer — 통합 효과 층

> **상태: spec 작성 2026-09-26 · 승인 대기.** 출발 맥락 = `docs/spec/battle-core-rebuild/12_next_unified_effect_layer_guide.md`(하드 케이스 실측 · 코드 지도). 계약의 근원 = 그 spec README 「조각 E 사용자 결정」 ⑪ + 아래 U1~U3.

## 상위 목표

**트리거 검사와 효과 발동이 출처(유닛 스킬 · 드림캐쳐 · 악몽)와 무관하게 한 경로를 탄다.** 이 spec 은 카드·콘텐츠를 만드는 일이 아니다 — 하드 케이스 둘이 드러낸 **논리적 구멍**을 설계로 메우는 일이고, 하드 케이스는 그 구멍이 메워졌는지 재는 **탐침**이다(`Tests/EditModeCore/HardCase*ProbeTests.cs`).

## 메울 구멍 (하드 케이스가 대표하는 것)

| # | 구멍 | 지금 | 통합 설계 | 탐침 증상 |
|---|---|---|---|---|
| H1 | **원점을 사건이 주지 않는다** | 효과가 원점을 「바인딩을 든 자」나 갈래 관례(대상 있으면 거기, 없으면 의도 좌표)로 **추정** | 트리거 종류 → (좌표 · 원점 항 · 선택적 대상) 을 내는 **원점 산출기 하나**. 모든 효과가 그 값만 소비 | AA 가 호스트 자리에서 쏜다 |
| H2 | **발사 요청 조립이 두 갈래** | 대상 갈래 / 자리 갈래가 반경·예고·비행시간을 **다른 출처**에서 읽는다 | 궤적 결합 종류(대상 · 칸 · 방향) 하나로 채우고, 값은 효과 파라미터에서 | 타격 운석 반경이 탄 정의에 묶임 · 예고·낙하 시간 없음 |
| H3 | **귀속과 수명이 한 자에 묶임** | 바인딩을 든 자 = 탄 소유자 = 수명 | 귀속 = **발동 주체**(U3) · 수명 = 발동 주체 **와** 바인딩을 든 자(U2) | AA 킬이 호스트 몫 |
| H4 | **효과에 정체가 없다** | 같은 효과를 두 출처가 쓰면 값 struct **복사** | 효과를 한 번 정의하고 출처가 **참조** | A·AA 두 줄이 값 복사 |
| H5 | **검증이 출처별 블랙리스트** | 카드 빌더만의 「OnPlace 불가 · 발사 명세는 주기만 · 칸 탄 불가」 | **한 검증 함수**(트리거 × 주체 × 효과 → 원점을 낼 수 있나)를 전 출처가 공유 | 같은 조합이 유닛 능력엔 되고 카드엔 안 된다 |
| H6 | **그림이 사건만으로 안 그려진다** | 뷰가 생성 사건을 받고 월드 탄을 **되찾는다**(제약 4 위반) | 사건이 뷰 키를 값으로 나른다 | 즉발 탄은 낙하 그림이 없다 |

## 계약

1. **효과 = f(원점, 파라미터).** 원점 = 좌표 + 원점 항(제약 13: 자리형 = 칸 반폭 0.5 · 몸형 = 발동 주체의 몸) + 선택적 대상 엔티티. 효과는 출처를 모른다.
2. **트리거 = 사건 → 원점 산출기**(H1). 커맨드 = 지정 칸 · 타격 = 맞은 적 · 남의 배치 = 배치된 유닛 · 자기 사건(사망·퇴근·주기·배치) = 주체. 산출 규칙은 **한 파일**에 트리거 종류별 한 줄.
3. **호밍 여부는 탄 궤적의 성질**(H2). 요청 조립은 궤적 결합 종류로만 갈린다.
4. **귀속 = 발동 주체 · 수명 = 발동 주체 ∧ 바인딩을 든 자**(H3 · U2 · U3). 출처(`BindingOrigin`)는 수명·표기 꼬리표.
5. **효과는 정체가 있다**(H4) — 한 정의, 여러 참조.
6. **검증은 하나**(H5) — 출처는 검증 입력이 아니다. 거절 사유는 「원점을 못 낸다」 또는 「효과가 그 원점 형을 못 받는다」뿐.
7. **라이브 동작 무변.** 오늘 저작의 동작은 안 바뀐다 — 구조가 바뀌고 조합이 열릴 뿐. 증거 = 골든 11 · `EffectWitness` · 기존 코어 테스트 · 빌더 스냅샷(굽힌 `BindingDef` 필드 동치). 골든은 합성이라 이 경로를 거의 안 타 **보조 증거**다.
8. **판정 자는 하나**(제약 13) · **enum append-only** · 새 사건·채널엔 트레이스 정거장.

## 사용자 결정 (2026-09-26)

- **U1 착탄 예고는 효과 파라미터** — 효과마다 켜고 끈다(기본 꺼짐). 액티브 운석(켬)·퇴근 운석(끔) 무변.
- **U2 연사 중 발동 주체가 사라지면 멈춘다**(호스트가 사라져도 멈춘다 — 오늘 그대로).
- **U3 킬은 탄이 나간 유닛 몫** — ⑪ 의 「출처 = 귀속 꼬리표」 중 귀속은 「발동 주체」로 정정.
