# nextwave-clear-attention

> 상태: **초안 2026-07-26 — 구현 전 승인 대기**

## 목표

Battle 좌하단 `NextWaveDock`을 **다음 전투를 여는 주 행동 버튼**으로 재구성한다. 호출된 적이
전부 사라지고 다음 웨이브가 남으면 누를 시점임을 알아보는 반복 어필을 시작한다.

## Feature-wide 계약

- **클리어 = 호출된 웨이브 합집합이 비었음**이다. `_pending.Count == 0`이고 `AttackUnitTag`가
  0일 때만 성립한다.
- 다음 웨이브가 남고 전투 중이며 한 웨이브 이상 호출됐을 때만 강조한다.
- 킬과 골 도달을 별도 카운트하지 않는다. 둘 다 “필드에서 사라짐”으로 같은 쿼리 결과에 수렴한다.
- 강제 호출로 웨이브가 겹치면 **겹친 모든 호출분**이 사라질 때까지 강조하지 않는다.
- UI는 ECS를 직접 읽지 않는다. `BattleBridge`의 읽기 전용 bool만 폴링한다. 신규
  Component/NativeQueue/C# 전역 이벤트는 만들지 않는다.
- 스케줄 이동·2초 리드인·연타·클릭 SFX는 변경하지 않는다.
- 강조는 시뮬 상태를 바꾸지 않으며 클릭·자동 호출·전투 종료 시 멈춘다.
- 수치·색·주기·크기는 `NextWaveDock`의 `[SerializeField] private` 값과 Sprite에서 조정한다.

## 시각 방향

- 큰 젤리 프레임 안 2단 구조를 **작은 타이머 캡슐 + 큰 행동 버튼**의 비대칭 실루엣으로 바꾼다.
- 행동 버튼은 청록 본체, 네이비 외곽, 코드형 이중 화살표와 `다음 웨이브 N` 라벨을 사용한다.
- 클리어 시 골드 림·빈 펄스 링·바운스·중앙 쪽 넛지로 주의를 끈다. Jar Figure 어필의 리듬만
  참고하고 코드를 결합하지 않는다.
