# 15 — 판정 캐리어 3종, 값 하나 (뷰)

> 외부 세션 확정 8: 그림자(상시 = 몸)·선택 링(정확값)·소켓 VFX(피격 순간)가 동일
> 반경·중심에서 유도된다. 「그림자가 진실이다」의 이행.

## 목적

판정 반경을 화면의 캐리어로 만든다. 핵심 읽기: **「적 그림자가 내 사거리 링에 닿으면 사거리
안」** — 링 반경 = 사거리+selfR(unit 9 계약 그대로), 그림자 반경 = targetR 이므로 이 문장은
근사가 아니라 판정식과 동치다.

## 변경 대상

- 블롭 그림자(`Presentation/UnitLiftVisual` 계열) — 지름 = **2r 파생**(아트 임의 크기 은퇴).
  ⚠ 뜬 높이 규칙과 충돌 해소: lift 로 크기를 줄이던 연출 은퇴 — **크기는 2r 고정**, 공중은
  진하기/블러로만. 「그림자는 UI 다, 연출이 아니다」(발주 문구 — unit 17).
- 링 — 원 회귀는 unit 12 공급값으로 끝난다. 여기서는 옅은 채움 확인 + **시각 권위**:
  그림자 진하기·링과 같은 시각 언어로, 스프라이트 몸통 읽기(키 큰 스프라이트가 링에 걸쳐
  보이는데 접지점은 밖 → 「왜 안 때려」)를 그림자가 이기게 한다.
- 대상 마크(unit 7) — **유지**(그림자-링 읽기의 학습 보조·비선택 시 보완).
- 채움 = 배치 판정 독점 유지(확정 문면 그대로 — 현행과 일치, 확인만).

## 완료 기준

- [ ] 그림자 지름이 반경과 1:1 — 소형 0.5칸 · 중형 1칸 · 2×2 아군 2칸.
- [ ] 링에 그림자가 닿는 순간 판정이 참 — 스크린샷 + 판정 로그 대조 1회.
- [ ] lift 중 그림자 크기 불변(진하기만 변화).
