# 16 — 임팩트 소켓 (뷰)

> 외부 세션 확정 8 후반: 투사체는 소켓을 조준하고, 명중은 접지 원이 결정한다.

## 목적

투사체가 발밑(접지점)이 아니라 몸통의 소켓을 향해 날아가 거기서 터진다 — 보이는 것(몸통
피격)과 판정(접지 원)의 분리. **sim 은 무변**이다.

## 변경 대상

- 유닛 뷰 저작(`ISpineUnitVisualData` 계열 / 프리팹) — 소켓 오프셋 1개(기본 = 중심 + 고정 높이).
- 투사체 뷰 — 비행 목표·임팩트 VFX 위치를 소켓으로.
- ⚠ sim 도달 판정(`hitThreshold + bodyRadius`, 접지)은 손대지 않는다.

---

### 진행 기록 — 구현 2026-09-01

- **sim·판정·이벤트 전부 무변** — `ProjectileState.target` 을 브리지가 읽어 frame 에 값만
  싣고, 뷰 풀은 ECS 무지 유지. 히트 드레인은 「sim 파괴 프레임에도 뷰 상태가 살아 있는 창」
  (드레인이 sync/despawn 보다 먼저 돈다)을 이용해 이벤트 스키마를 안 넓혔다.
- 호밍 2종(HomingToEntity·BezierHomingToEntity)만 소켓 흡수 — 마지막 2칸 blend.
  포물선·낙하·수류탄은 지점 착탄이라 대상 소켓이 정의되지 않는다(무변).
- 저작: 보스 3종 `impactSocketHeight: 0.8` (시트 컬럼 없음 → SO 로 끝).
- EditMode 전건 초록(선행 실패 2건 제외).
