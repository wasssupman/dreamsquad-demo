# 4c — 어그로 추격의 접근 보정 (unit 1 완료 기준 3 마감)

## 목적

「도착했는데 못 쏘고, 필드 기울기가 0이라 못 움직이는」 **영구 동결**을 닫는다.
unit 1 이 이 항목을 열어 두고 unit 4 로 이관했고, 4a/4b/4d 어디에서도 닫히지 않았다.

## 왜 생겼나

추격 레인은 자가 셋이다:

| 역할 | 어디 | 자 |
|---|---|---|
| 어그로 **획득** | `AggroTargeting` | 셀 원 |
| 이동 **정지** | `FlowFieldBuilder.CollectDefenderSources` → `FlowRecovery` | **셀 정사각** |
| **발사** | `AttackReach.InReach` | **월드 원** (unit 4a 이후) |

원이 정사각형의 모서리를 잘라낸 만큼 「필드는 도착이라 하고 사거리는 밖이라 하는」 칸이
남는다. 그 칸은 `dist == 0` 이라 기울기가 없어 자기 이동도 0 이고,
해제는 가디언 사망뿐(`AggroPolicy.ShouldRelease`)이라 판이 끝날 때까지 간다.

**적은 칸에 들어서는 순간 멈추므로 늘 그 칸의 바깥 모서리에 선다** — 최악의 자리다.

### 실측 (사거리 1, 가디언 타일 고정, 9×9 전면 walkable)

| | |
|---|---|
| 정지 위치 | 대각 소스 칸, `dist 0` |
| 가디언까지 | **2.051칸** |
| 도달 | 1.50칸 → 발사 불가 |
| 구 체비셰프였다면 | max 1.450 ≤ 1.5 → **통과** |

**unit 4a 의 회귀다.** unit 1 의 「연속 이동 가디언이 생기면 성립 · 오늘 저작 0종이라
도달 불가」 판정은 당시 `bothContinuous` 게이트 덕에 참이었고, 4a 가 그 게이트를 은퇴시키며
전제를 삭제했다. 그리고 **어긋남을 만드는 것은 가디언의 이동이 아니라 적 자신의 칸 안
위치**라, 게이트가 사라진 순간 상시 도달 가능이었다.

## 구현

**사격 칸 도착(`dist == 0`)인데 FSM 이 아직 `Chasing` 이면 지배축 cardinal 로 한 칸 더.**
막히면 나머지 축(순찰 `PatrolAreaMath.CloseInDir` 과 같은 형태).

⚠ **여기서 사거리를 다시 판정하지 않는다.** `ai == Chasing` 자체가 `EnemyAiStateSystem` 이
정본 술어(`AttackReach.InReach`, 대상 몸 포함)로 방금 계산한 「어그로됐고 사거리 밖」이고,
그 시스템은 `[UpdateBefore(MovementSystem)]` 이라 값이 신선하다.
**자를 하나 더 만드는 순간 그게 다음 교착이다** — 이 결함의 원인이 정확히 그거였다.

⚠ **고립 셀(`dist != 0`)은 보정 대상이 아니다.** `RecoveryDir` 의 zero 는 「도착」과 「고립」
두 뜻인데, 고립은 unit 4a 이전에도 멈췄으므로 이 spec 의 회귀가 아니다.

⚠ **소스 디스크를 원으로 좁혀서 고치지 말 것.** 사거리 1 이면 칸 전체가 원 안인 소스가
하나도 없어(축 칸 최대 1.581 > 1.5) 어그로가 통째로 거부된다.

## 관측 도구의 결함 (이 결함이 드러낸 것)

**코퍼스도 카나리아도 이걸 구조적으로 못 본다.**

- `RangePredicateMirrorTest:118` 의 `damaged` 는 **적 총 체력 델타**라, 다른 적이 맞고 있으면
  `stuckStreak` 이 매 프레임 리셋된다 → **개체 하나의 영구 동결은 검출 불가.**
- 골든은 이벤트 스트림을 비교하는데 동결의 신호는 **부재**다. 그리고 이 결함은 사거리를
  17.8% 줄이는 커밋에 실려 왔고 **신호(피해 이벤트 감소)가 의도한 변경과 같았다.**
  4a 진행기록이 `long_boss` 이벤트 **−83%** 를 「직관과 반대라 그냥 넘기지 말 것」이라고
  표시까지 하고, 「사거리 술어는 적이 멈출지도 결정한다」로 설명하고 넘어갔다 —
  **그 설명이 버그 자신의 정의였다.**

→ 후속 후보: 카나리아를 **개체별 정지**(어그로된 적이 N프레임 무이동 + 무발사)로 교체.
