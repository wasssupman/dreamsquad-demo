# 0 — 감지 전 기준선 측정

## 목적

구현 전에 **감지가 값을 하는지** 판정한다. 같은 기능이 `enemy-hunter-targeting` 에서 한 번
폐기됐고(사유: 맵 기하상 추격이 마칭 대비 얻는 게 0), 그 결론이 오늘의 멀티골·분리복도 맵에서도
참인지는 재 봐야만 알 수 있다. 부수 산출로 **반경 기본값**과 **구현 레인(A/B)** 의 근거를 뽑는다.

## 변경 대상

- `Assets/_Project/Editor/Battle/DetectionProbeMenu.cs` (신규) — 계측기
- `Assets/_Project/Editor/Battle/SimHarnessRunner.cs` — `Run(...)` 에 관측 전용 훅 `onTick` 1개

sim 은 한 줄도 바꾸지 않는다. 고정 스텝 하네스를 돌리며 매 틱 월드를 읽기만 한다.

## 구현

`Wassup/Battle/Sim Harness/Detection Probe (measure)` — 맵 풀 전체(4개)를 각각 10800틱(3분 판)
돌리며 잰다. 맵은 `DevMapOverride` 로 **의도적으로** 고정하고 끝나면 원복한다(골든 베이크가 이
값을 끄는 것과 목적이 반대다 — 골든은 조건을 못박고, 계측은 맵별 편차가 질문이다).

**배치를 하네스의 `ApplyScheduledInput` 에 맡기지 않는 것이 핵심이다.** 그쪽은 「골에 가장 가까운
가능 칸」을 고르는데(교전 보장이 목적), 그러면 방어유닛이 전부 골 앞에 뭉쳐 「적이 레인을 끝까지
걷는 동안 근처에 아무도 없다」가 되어 **재려는 값 자체가 편향된다.** 계측기는 골까지 남은 거리
(흐름장 dist)로 정렬해 분위수 자리에 놓는다 — 실제 플레이의 «길을 따라 배치»에 가깝다.

측정 정의:

- **간격(gap)** = 몸 가장자리 기준 칸 거리. `gap <= attackRange` 가 곧 사거리 안(`AttackReach` 와 같은 자).
- **legal** = 그 적의 `targetMask` · 통행층 · `classMask` 를 전부 통과하는 방어유닛(`AttackSystem` 후보 루프 미러).
- **payload** = 「마칭 중인데 legal 방어유닛과 간격 ≤ R」인 틱. 마칭은 정의상 사격 대상이 없는
  상태이므로, 이 틱은 곧 「감지를 켰다면 그쪽으로 향했을 시간」이다.

두 렌즈(핵앤슬 플레이어 · 시스템 기획)의 critic 리뷰가 **측정 자체의 구멍 5개**를 찾았고,
각각이 결정이나 스펙 하나를 바꿨다. 초판 수치는 이 지적들 이전이라 **더 이상 인용하지 말 것.**

### 재현성 사고 하나 — 덱을 못박기 전까지 측정이 흔들렸다

같은 seed·같은 맵인데 두 시점의 결과가 갈렸다(적 67 vs 57 · 킬 51 vs 42). 원인은 코드가 아니라
**공유 가변 상태**였다: 시나리오가 덱을 안 지정하면 `SimHarnessRunner` 가 «씬 기본 풀»
(`BattleBridge` serialized 필드 + 정적 메모)을 쓰는데, 그 값이 7종 → 8종으로 바뀌어 있었다.

**차단**: 계측기가 덱을 `DefenderCatalog.defaultSquadUnits` 7종으로 **명시 고정**한다. 씬이 아니라
데이터가 소유하므로 git 에 추적되고 다른 세션의 씬 편집에 안 흔들린다 — `DevMapOverride` 를
못박은 것과 같은 이유다. 고정한 뒤 unit 1 **전/후 수치가 정확히 일치**했고, 그게 unit 1 이
거동상 무해하다는 두 번째 증거다.

**판정에 쓴 나머지**:

- 「방어유닛을 한 번도 안 만나고 골에 닿은 적」 **3기 / 195** → 감지는 누수 방지 기능이 아니다.
- 「최근접이 못 때리는 놈」 **2기 / 195** → B안(자가 유발 어그로)의 주된 정당화가 1%.
- 상태 점유: 마칭 73.2% · 교전 25.5% · **추격 0.0%** · 대치 1.3% → 어그로 추격 레인은 라이브에서
  사실상 안 돈다(어그로 37기 전원이 이미 사거리 안이라 곧장 대치). 반면 보스 사냥 레인은
  2520틱 동안 실제로 돌았다 → **A안이 검증된 코드 위에 있다.**
- 맵별 편차: map2(30×11)는 R=3 신규 교전이 3기뿐 — 좁고 이미 다 교전한다. map0·map1 이 주 무대.
