# 장부 — 규칙 분류표 (unit 0 · 항목 6 · rules.md)

> 생성 2026-09-23. census 6편 「코드에만 박혀 있고 문서에 없는 규칙」 전량 + 「우연」 애매 항목. 필수 = 없으면 조용히 망가진다 / 보류 = 의도만 옮기고 상세는 안 옮김(플레이 후 재결정) / 제거 = 제거 확정 기능.

## 읽는 법

- **등급의 뜻.** 「필수」는 **이식 의무**다 — 새 코어에 같은 규칙이 다시 서지 않으면 판이 조용히 다르게 돈다. 「보류」는 **의도만** 옮기고 기계는 안 옮긴다(땜빵·우연·Entities 산물). 「제거」는 새 코어에 자리가 없다(제거 확정 기능 · 소비처 0 좀비 · 고아).
- **애매하면 필수.** README 계약 2 가 그렇게 못박았다. 「기계처럼 보이는데 규칙이 숨어 있다」가 이 장부가 막으려는 실패다.
- **출처 표기.** `cX` = census-combat · `cE` = census-effects · `cN` = census-entities · `cM` = census-map-movement · `cP` = census-match-presentation · `cS` = census-skills. 뒤의 꼬리표는 그 census 안의 절 — `코드에만` / `애매`(키워드 표의 애매 행) / `ECS고유`(「사라지는 기계 ↔ 살아남을 규칙」 절에서 ⚠ 또는 명시 반례가 붙은 것만).
- **자리 열.** `담당자`/`phase`/`타입` 은 [`class-diagram.md`](../class-diagram.md) 의 이름이다. 미정이면 그 unit 번호만 적는다.

## 보류 항목의 재결정 질문 목록

플레이 뒤 사용자가 답할 질문이다. 괄호 안은 그 답에 걸린 행.

1. **부여가 즉시 듣게 할 것인가.** 고정 틱에서는 「즉시」가 기본값이라 **가만히 두면 바뀐다** — 현재 밸런스는 1프레임 지연에 구워져 있다. (F29)
2. **버프를 「지운다」는 어휘를 열 것인가.** 열면 강제 고정 해제·효과 타일 회수·출처 사망 시 회수가 한 번에 풀린다. 어느 슬롯을 지우나(키 설계)와 연산자별 면역 정책이 선행. (F27 · F28 · F33 · S7)
3. **슬롯 칸 번호를 출처 태그로 바꿀 것인가.** 바꾸면 결정론의 근거가 삽입 순서에서 정렬로 옮겨간다. (F26)
4. **스택 임계 규칙을 출처별로 가를 것인가.** 오늘 드래곤과 킨들러가 한 벌을 공유한다. (F31)
5. **초당 재생을 곱하기 슬롯에도 열 것인가.** 지금은 곱하기만 있으면 0 이다. (F5)
6. **선딜을 공속의 천장으로 둘 것인가.** 두면 표시와 실제가 계속 어긋난다. (C19)
7. **폭탄맨의 사각 자와 부채꼴의 몸 누락을 제약 13 으로 접을 것인가.** (C20 · C21)
8. **통행 가능한 「지면」 층을 3층으로 유지할 것인가.** 흐름장 슬롯 수가 여기서 정해진다 — unit 2 **진입 전**에 답이 필요하다. (M23)
9. **입구별 기본 경로를 살릴 것인가.** 코드·검증은 끝나 있고 저작이 0이다. (M24)
10. **효과 타일 자리를 매치 시드로 갈아탈 것인가.** 지금은 맵마다 고정이다. (M25)
11. **사망으로 터지는 규칙도 붙은 것 전부 발동시킬 것인가.** 오늘 사망만 첫 하나다. (E4)
12. **소비처 0 인 예약 값을 옮길 것인가.** 정예 등급 · 대형 몸집 · 중립 진영 비트 · 희귀도 — 직렬화 계약이 사라지면 유지 근거도 사라진다. 한 번에 정한다. (E21 · E24 · E25 · E26)
13. **집계 단계를 남길 것인가.** 없애면 저장된 카메라 설정의 정수가 밀린다. (X19)
14. **스폰 오프셋을 순번 파생으로 바꿀 것인가.** 결정론 등급 상향의 전제다. (X25)
15. **슬로모를 틱 발행률로 바꾼 느낌이 지금과 같은가.** 플레이로만 답할 수 있다. (X26)
16. **미개방 게이트 조합을 열 것인가.** 「대상의 체력 × 피격 N회」는 한 프레임 다중 출처의 주체 선정 규칙이 선행. (S26)
17. **저작이 concrete 를 직접 가리키게 할 것인가.** 간접층의 근거(Burst)가 사라진다. (S27 · S24)
18. **범위 안 후보 상한을 어떻게 자를 것인가.** 64 를 넘는 판이 생기면 그때 계약으로. (S23)
19. **낡은 흐름장 슬롯 요청을 큰 소리로 거절할 것인가.** fail-open 을 닫으면 미저작 맵이 판을 못 연다. (M2)
20. **이동하는 가디언을 저작할 것인가.** 저작하는 순간 추격 필드 재굽기가 필요해진다. (M6)
