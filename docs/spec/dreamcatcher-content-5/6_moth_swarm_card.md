# 6 — 불나방떼 카드 (`moth_swarm`)

> T초마다 주변 적들에게 불나방이 한 마리씩 날아가 터진다. 뭉쳐 있으면 각각 다른 적을 쫓는다.

## 목적

unit 5 가 연 문으로 첫 카드를 낸다. **이 단위의 코드는 0줄이 목표다** — 저작(에셋)만으로
카드가 성립하는지가 unit 5 의 배당금을 증명한다.

## 변경 대상

- `Data/Projectiles/Projectile_Moth.asset` — **신규**(불나방 한 마리)
- `Data/Projectiles/Pattern_MothSwarm.asset` — **신규**(발사 명세 — 기존 패턴들과 같은 폴더)
- `Data/Dreamcatcher/Card_MothSwarm.asset` — **신규**
- `Data/Dreamcatcher/DreamcatcherCardCatalog.asset` — 등록

코드 변경이 필요해지면 **멈추고 보고한다** — 그건 unit 5 의 개통이 덜 됐다는 신호다.

## 구현

**조합**: `PeriodicTimer × EmitProjectilePattern`.

**저작(초기값).**

| 값 | 자리 | 초기값 |
|---|---|---|
| 발사 주기 | 카드 `trigger.periodSeconds` | 3초 |
| 한 번에 몇 마리 | 패턴 `shots` | **10발** (0.12초 간격 → 버스트 1.08초 < 주기) |
| 어떻게 흩어지나 | 패턴 `selection` / `reselectPerShot` | 결정론 셔플 / **발마다 재추첨** |
| 얼마나 멀리서 찾나 | 패턴 `scopeTileRange` | 4타일 |
| 마리당 피해 | 패턴 `damage` | **7.2** (10발 × 7.2 ÷ 3초 = **초당 24**) |
| 비행 | 탄 SO `flightMode` | 곡선 추적(`BezierHoming`) — 나방답게 흔들리며 간다 |
| 뷰 | 탄 SO `projectilePrefab` | 기존 불꽃 계열 재사용 |

**「각각 다른 적을 쫓는다」는 코드가 아니라 저작이다** — 결정론 셔플 + 발마다 재추첨의 조합이
그 그림을 만든다. 한 마리로 몰아치게 하려면 재추첨을 끄면 된다(같은 카드, 값 하나).

⚠ **주변에 적이 없으면 아무것도 안 나간다.** 스코프 안이 비면 발사가 소모될 뿐이다 —
현재 emitter 의 기존 동작이며 이 카드가 바꾸지 않는다.

⚠ **결정론.** 셔플은 시드 난수가 아니라 발사 카운터 기반이다(패턴의 기존 계약).
「같은 판이면 같은 순서」가 유지되는지 검증에 포함한다.

## 완료 기준

- [ ] Play: 3초마다 불나방 **10마리**가 **서로 다른 적**에게 날아가 터진다
- [ ] 주변에 적이 하나뿐이면 10마리가 그 하나에게 간다(빈 발사로 사라지지 않는다)
- [ ] 주변에 적이 없으면 조용히 넘어간다(콘솔 오류 0)
- [ ] 부착 유닛이 죽거나 퇴근하면 다음 발사가 없다 — **이미 나간 나방은 자기 비행을 끝낸다**
- [ ] **코드 변경 0** (변경이 필요했다면 그 사실과 이유를 handoff 에 남긴다)
- [ ] 같은 웨이브를 두 번 돌리면 같은 순서로 날아간다(결정론)
