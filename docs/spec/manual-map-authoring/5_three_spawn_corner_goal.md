# 5. 3스폰 + 모서리 골 리레이아웃 (스폰별 최소 이동거리 계약)

## 목적

스폰 3개가 세 방향에서 좌하단 모서리 골로 수렴하는 레이아웃으로 교체하고, "특정 스폰이 골까지 최소 N칸 이동" 요구를 **BFS 실측 기반 정확 튜닝**으로 만족시킨다.

## 변경 대상

- `Assets/_Project/Data/Maps/MapDocument_ArkFunnel.asset` — GUID 유지 덮어쓰기 (배선 불변)

## 구현

- **골 (0,0) 좌하단 모서리**, 트렁크 = 하단 y0 전체 폭.
- **스폰 3개 / 이동거리 (BFS 실측)**: A (0,9) 좌상 미니 스위치백 25칸 · B (14,9) 우상 대형 스위치백 33칸 · C (14,6) 우측 가장자리 하강 20칸.
- **최소 이동거리 계약**: 전 스폰 ≥20칸. 수동 맵은 경로가 곧 데이터라 스폰 위치를 세로 1칸 옮기면 정확히 ±1칸 — 프로시저럴의 `spawnToGoalMinManhattan`(직선거리 하한)과 달리 경로 길이를 직접 지정한다. authoring 시 BFS 거리 출력을 검증에 포함할 것.
- 촉포인트 2개 유지: (5,3) A→B 합류, (3,0) 간선→트렁크 합류. C 는 합류 없이 트렁크 직결(최속 러시 역할).
- 첫 시도였던 C 우하단 (14,1) 스폰은 15칸으로 미달 — 우측 세로 하강으로 재설계해 20칸을 맞췄다. 하단 우측 블록은 B 의 y3 간선에 막혀 지그재그 증설이 2×2 위반 없이는 불가능했다(가장자리 세로 루트가 정답).
