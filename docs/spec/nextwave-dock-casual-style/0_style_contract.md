# 0 — 스타일·무회귀 계약

## 정보 위계

1. 남은 시간 숫자
2. 다음 웨이브 행동 라벨과 번호
3. 프레임·하이라이트 장식

## 구현 계약

- 상단 66px 타이머 행과 하단 72px 버튼 행의 구조를 유지한다.
- 타이머에는 작은 `남은 시간` 보조 라벨과 큰 `m:ss`를 함께 배치한다.
- 버튼의 `다음 웨이브 N` / `웨이브 없음` 문구와 interactable 조건은 그대로 유지한다.
- 버튼 press는 즉시 0.94 scale, release는 1.04 overshoot 후 복원한다.
- 조기 호출 성공 시 짧은 cyan flash/punch만 추가하고 로직 호출 횟수는 1회다.
- 경고 구간은 기존 붉은 숫자와 더 강한 초 tick punch를 유지한다.

## 완료 기준

- 데이터·행동 경로 diff가 없고 View 조립/스타일 코드만 변경된다.
- 숫자와 행동 라벨이 장식보다 먼저 읽힌다.
- 각성 버튼과 색·재질은 어울리지만 동일한 원형 실루엣을 복제하지 않는다.
