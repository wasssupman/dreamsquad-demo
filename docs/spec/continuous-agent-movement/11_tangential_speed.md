# unit 11 — 접선 속도 보존 (코너 크리프 제거)

## 목적

벽에 비스듬히 붙었을 때 **실이동이 `speed · sinθ` 로 붕괴하는 것**을 없앤다 (θ = 진행 방향과 벽면이 이루는 각).

사용자 신고(2026-08-09): *"우측 끝 두 스폰에서 코너를 돌아 목표로 갈 때 적이 코너에 잠시 끼어 이동모션만 하다가 1초쯤 후에 다시 움직인다."*

원인은 unit 3 의 축 분리 충돌 해결이다. 막힌 축의 성분을 **버리기만** 하므로, 방향이 벽 법선에 가까워지면 살아남는 접선 성분이 0 으로 수렴한다. 실측 사고 지점에서 요청 변위 0.03330 에 대해 실이동 **0.00055 (1.5%)** — 눈에는 "제자리 걸음"이고, 뒤에서 다른 적이 밀어야 빠져나왔다.

> ⚠ **처음 세운 인과는 절반이 틀렸다** (사용자 "정말 이게 원인이냐" 반증 요구로 발견). "코너에서 Z 축이 막혀 느려졌다"고 썼는데, 실측하면 그 프레임 **Z 축은 요청량 100% 통과**였다. 진짜 원인은 충돌이 아니라 **애초에 z 를 0.00055 밖에 요청하지 않은 것** — 조준이 통로 건너편을 가리켜 방향이 거의 순수 벽 법선이 됐고(θ ≈ 0.9°), 축 clamp 가 그 법선 성분을 통째로 버리자 남은 게 1.5% 였다. 그래서 고칠 곳은 조준도 축 판정도 아니고 **버려진 몫의 처리**다.

이 unit 은 **증상 2(코너 크리프)만** 다룬다. 증상 1(기둥 구역 조준 진동)은 건드리지 않는다 — 아래 "이 unit 이 고치지 않는 것" 참조.

## 구현

축 clamp 결과에서 **정확히 한 축만 막혔을 때**, 잃은 몫을 살아남은 축으로 재분배해 프레임 변위 크기를 요청량까지 복원한다.

```
free² + blocked² = wantLen²   →   free = √(wantLen² − blocked²)
```

- **`‖want‖ − ‖got‖` 을 자유 축에 더하면 안 된다** — 막힌 축이 부분 통과한 몫이 이중으로 세어져 과소 복원된다.
- **`normalize(got)` 방향으로 재분배해도 안 된다** — 이미 막힌 축 성분이 섞여 그 몫이 다시 막힌다(자가 검토에서 잡은 첫 구현의 결함).
- **둘 다 막힘 = 재분배 없음.** 코너에 정면으로 박힌 상태라 살릴 접선이 없다. 억지로 방향을 만들면 벽 안쪽으로 미끄러진다.
- **접선 의도가 없으면(자유 축 요청 0) 이동 0.** `sign(0) = 0` 이 이를 자동으로 보장한다 — 없으면 유닛이 벽에 닿는 순간 옆으로 새는 유령 이동이 생긴다.
- **재분배분도 충돌 해결을 다시 태운다**(다른 벽에 부딪힐 수 있다). **재귀는 1회로 끝낸다** — 반복하면 코너에서 진동하고 프레임당 비용이 불정해진다.
- **총 변위 ≤ 요청 크기.** 재분배 예산이 "잃은 양"뿐이라 상한이 자동이다. 이게 없으면 코너에서 순간 가속이 보인다.

결정론: 순수 기하 + 고정 분기. 난수·시간·순서 의존 없음.

## 이 unit 이 고치지 않는 것

같은 하네스에서 **총회전량은 사실상 불변**이다 — (23,3) 268°→265°, (23,13) 130°→133°, (12,2) 1164°→1161°, (20,15) 96°→96°. 즉 조준 진동은 그대로다. 기둥이 흩어진 구역(스폰 (12,2))에서 13.4타일 주행에 헤딩 45°↑ 전환 6회 · 총회전 1161° 가 남는다.

이는 **다른 증상**이다. 크리프는 "결정된 방향을 못 따라간 것"이고 진동은 "방향 자체가 흔들린 것"이다. 후자의 원인은 조준 기준이 **"레이가 처음 막히는 지점"** 이라는 국소 판정이라는 데 있다 — 관찰자가 움직이면 어느 셀이 먼저 걸리는지가 바뀌고, 그때마다 다른 코너가 정당하게 뽑힌다. 해소는 조준 기준을 **전역 비용 최소**(코너 그래프)로 바꾸는 별도 작업이며, 이 spec 의 후속 후보로 둔다.

## 함께 정정한 문서 부채

독립 감사(2026-08-09)가 지적한 거짓 주장을 고쳤다. `PathSmoothing.cs` 헤더와 `10_corner_vertex_aiming.md` 가 코너 꼭짓점 조준에 대해 **"왕복이 구조적으로 불가능하다"** 고 썼는데, 참인 것은 그보다 좁다 — `(차단 셀, 코너)` **쌍이 같으면** 좌표가 관찰자와 무관하다는 것뿐이고, 그 쌍 자체는 관찰자가 고른다. 왕복은 배제된 게 아니라 **억제**됐고, 위에 적은 잔여 진동이 그 증거다.
