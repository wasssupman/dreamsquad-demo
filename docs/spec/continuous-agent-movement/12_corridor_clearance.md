# unit 12 — 복도 여유 확보 (군집 교착 제거)

## 목적

폭 1 복도에서 **적 여러 기가 코너/복도를 지날 때 서로 끼어 영구 교착**하는 것을 없앤다.

사용자 신고(2026-08-09): *"코너에 적이 몇 마리 동시에 지나가면 서로 끼어서 못 지나간다."*

## 원인

폭 1 복도(1.0)에서 몸통이 지름 0.7 이므로, **+x 로 전진하려면 몸통 z 범위가 통로 한 줄에만 걸쳐야 한다 → 중심선 ±0.15 안**. 벗어나면 몸통이 옆 벽 셀에 걸쳐 그 축이 통째로 막힌다.

그런데 겹침 해소(unit 8)는 최대 **0.35**(=반지름) 까지 옆으로 밀어낸다. 즉 **밀어냄이 유닛을 전진 불가능한 자리로 보낸다.** 앞이 비어 있으면 스스로 재정렬하지만(unit 11 의 벽면 슬라이드), **앞에 마개가 있으면 재정렬할 틈이 없어 그대로 굳는다.**

마개는 두 형태로 생긴다:

1. **교전 정지** — 적 1기가 가디언 사거리에 들어 `Standoff` 로 멈춘다. 이게 압도적으로 흔하다.
2. **대칭 병목** — 두 폭1 복도가 한 칸으로 합류하는 지점에서 위/아래 유닛이 같은 0.2폭 슬롯을 향해 정면으로 만난다. 겹침 해소는 대칭(작용-반작용)이라 **누가 먼저 갈지 결정하지 못한다.**

반지름 0.35 는 README 계약에서 *"지름 0.7 < 1.0 이라 1타일 복도 통과 가능 + 벽 여유 0.15"* 로 정한 값인데, 그 검산은 **단독 통과만** 봤다. 군집 통과는 보지 않았고, 여유 0.15 는 밀어냄 폭 0.35 보다 작다.

## 실측 (하네스: 16기 · 두 스폰 동시 · 선두 1기 경로 중간에서 영구 정지)

| 맵 | r=0.35 (현행) | r=0.30 | **r=0.25** |
|---|---|---|---|
| Coil | 12/15 · **교착** | 15/15 · 724F | **15/15 · 662F · 최장정체 1F** |
| Serpent | 13/15 · **교착** | 15/15 · 750F | **15/15 · 741F · 4F** |
| Spiral | 12/15 · **교착** | 13/15 · **교착** | **15/15 · 543F · 1F** |
| Twin | 13/15 · **교착** | 15/15 · 1028F | **15/15 · 988F · 4F** |
| Hook | 15/15 · 830F | 15/15 · 806F | **15/15 · 776F · 4F** |
| Zig | 15/15 · 752F | 15/15 · 698F | **15/15 · 713F · 5F** |

("교착" = 6000프레임(100초) 안에 후속 유닛이 통과하지 못함.)

r=0.25 는 6/6 맵에서 교착을 없애고 **최장 정체가 1~5프레임**으로 떨어진다. r=0.30 은 Spiral 이 남는다.

| 처방 | 결과 |
|---|---|
| 서열 우선권(골에 가까운 쪽 우선, 뒤가 2배로 물러남) | **전 맵 악화.** 병목 맵 6/16 → 0/16 |
| 줄서기 단독(앞이 막히면 전진 포기) | 단독으론 악화 — 뒤가 계속 밀어붙여 러닝머신 |
