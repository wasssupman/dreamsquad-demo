# unit 13 — 교전 중인 적이 군중에 밀려 나르는 것 차단

## 목적

**시뮬이 "여기서 멈춘다"고 정한 유닛을 뒤 무리가 앞으로 밀어 나르는** 현상을 없앤다.

unit 12 조사 중 별개 결함으로 발견됐다. 가디언 사거리에 들어 `Standoff` 로 멈춘 적이 뒤따르는 15기의 압력으로 **경로를 따라 4~9타일 이동한다**(Zig 9.15타일, r=0.35 기준). 멈춘 자리에서 싸우기로 한 결정이 겹침 해소에 덮인다 — 사거리 판정과 배치 의도가 함께 무너진다.

## 원인과, 통하지 않는 처방

밀림은 **한 프레임의 큰 밀어냄이 아니라 수백 프레임 누적 압력**이다. 그래서 프레임당 상한(`maxPush`)을 낮추는 것은 **아무 효과가 없다** — 실측:

| 정지 유닛 프레임당 상한 | Hook 밀림 | Coil 밀림 |
|---|---|---|
| `radius` (현행) | 6.47타일 | 0.74타일 |
| 0.05 | 6.47타일 | 0.74타일 |
| 0.02 | 6.42타일 | 0.74타일 |
| 0 (앵커) | 0.00타일 — 단 **통과 8~13/15 로 붕괴** |

실제 밀어냄 크기는 `겹침 × 0.5` 라 상한선에 애초에 닿지 않는다. 상한은 폭주 방지용이지 누적 방지용이 아니다.

앵커(밀림 완전 차단)는 밀림을 없애지만 폭1 복도에서 마개를 **진짜 벽**으로 만들어 뒤가 통과하지 못한다.

## 처방 — 전진 성분만 거부

정지한 유닛은 **자기 진행 방향(+) 성분의 밀어냄만 거부**하고, 뒤로·옆으로 밀리는 것은 그대로 받는다.

- 뒤에서 미는 힘 = "네 자리를 내놔라" → 거부한다. 이게 밀어 나르는 성분이다.
- 옆·뒤 성분은 유지 → 뭉침은 계속 풀리고, 마개가 벽이 되지 않는다.
- 전방(=진행 방향)은 그 유닛이 **서 있는 셀의 flow** 로 매 프레임 파생한다. 앵커 좌표를 저장하지 않는다 — 저장하면 무효화 시점(부활·이동 재개·필드 재빌드)이 생긴다.

### 실측 (r=0.25, 16기, 선두 1기 영구 정지)

| 맵 | 현행 밀림 → 처방 후 | 통과 |
|---|---|---|
| Hook | 6.47 → **0.46** | 15/15 |
| MovementLab | 4.70 → **0.35** | 15/15 |
| Zig | 3.34 → **0.50** | 15/15 |
| Serpent | 3.27 → **0.04** | 15/15 |
| Spiral | 1.74 → **0.50** | 15/15 |
| Twin | 1.58 → **0.13** | 15/15 |
| Coil | 0.74 → **0.73** | 15/15 |

전 맵 0.5타일 이하. 대가는 뒤 무리가 **실제로 줄을 서게 되는 것**(Serpent 전원도착 741→983F, 최장 정체 4→165F)이고, 이것이 의도한 거동이다 — 마개 뒤에서 기다리는 것은 정체(게임플레이)이지 교착(버그)이 아니다.

### ⚠ unit 12 의존 — 단독으로 적용하면 해롭다

같은 처방을 **r=0.35 에서** 적용하면 통과가 무너진다(실측):

| 맵 | r=0.35 + unit 13 | r=0.25 + unit 13 |
|---|---|---|
| Hook | **8/15 · 교착** | 15/15 · 776F |
| Zig | **8/15 · 교착** | 15/15 · 691F |
| Serpent | **8/15 · 교착** | 15/15 · 983F |
| Twin | **9/15 · 교착** | 15/15 · 1118F |

이유는 앵커 실험과 같다 — 전진 밀림을 거부하면 마개가 자리를 지키는데, **복도 여유가 없으면 뒤가 그 옆을 지나갈 수 없다.** unit 12 가 여유를 만들어야 "지키는 마개 + 옆으로 새는 줄"이 성립한다.

**되돌릴 때 순서가 있다**: unit 12(반지름)를 되돌리려면 unit 13 도 함께 되돌려야 한다. 13만 남기면 이 표의 왼쪽 열이 된다.

## 구현

### 술어를 두 벌 두지 않는다

"시뮬이 이 유닛의 자기주도 이동을 멈췄나"는 `MovementSystem` 의 제어 흐름 전체에 흩어져 있다(Standoff / Engaging-Halt / Pulse-타격중 / CC 잠금 / 순찰 dir 0 / 고립 셀). 이걸 `AgentSeparationSystem` 에서 재구현하면 **벽 술어 중복과 같은 부류의 결함**이 된다(unit 10 계약 수리 참조).

그래서 **판단한 쪽이 기록한다**: `MovementSystem` 이 매 프레임 `PathFollowState.holdingGround` 에 자기 결정을 남기고, 겹침 해소는 그것만 읽는다. 같은 맥락(Movement) 안이라 경계 위반이 아니다.

기록 방식은 **케이스 열거가 아니라 결과 관찰**이다 — 진입 시 `1`(정지)로 두고, 자기주도 변위를 **실제로 적용하는 지점에서만** `0`으로 내린다. 그러면 어떤 `continue` 경로가 새로 생겨도 자동으로 "정지"에 편입된다. 열거 방식이면 분기가 추가될 때마다 조용히 새는데, 이 방식은 새지 않는다.

### 순수 함수

```
RejectForwardPush(accumulated, forward) =
    dot(accumulated, forward) > 0 ? accumulated − forward·dot(...) : accumulated
```

`forward` 가 zero(고립 셀·필드 없음)면 원본 그대로. 결정론: 순수 기하, 분기 고정.
