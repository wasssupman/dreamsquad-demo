# unit 4 — 8-이웃 가중 다익스트라 + 코너컷 방지

## 목적

**L 자 이동을 없앤다.**

현행 `FlowFieldBuilder` 는 4-이웃 BFS 다. dist = 맨해튼 거리라 열린 공간에서 스폰→골로 가는 **모든 계단 경로의 길이가 같고**, 방향 선택 타이브레이크(`+x, -x, +y, -y` 중 첫 감소 이웃)가 그중 가장 극단인 L 자를 뽑는다. 복도 폭을 넓혀도 그대로다 — 폭이 아니라 알고리즘의 정의다.

## 구현

### 비용 모델

직교 = `1`, 대각 = `√2`. **단순 BFS 로 8-이웃을 돌리면 안 된다** — dist 가 체비셰프가 되어 대각이 공짜가 되고, 이번엔 반대로 불필요한 대각을 선호하는 왜곡이 생긴다(우회 비용을 실제보다 싸게 계산).

정수 유지를 위해 **×10 스케일 정수 비용**을 쓴다: 직교 `10`, 대각 `14`(≈10√2=14.14). `dist` 는 이미 `NativeArray<int>` 이고, 부동소수를 들이면 결정론 위험이 커진다.

⚠ **`dist` 의 단위가 바뀐다.** 소비처가 절대값을 비교하면 깨진다 — unit 6 이 전수 확인한다. 이 unit 은 `int.MaxValue`(도달 불가) 센티넬만 보존한다.

### 큐

다익스트라지만 비용이 `{10, 14}` 두 종뿐이라 **버킷 큐(Dial's)** 로 충분하다. 우선순위 큐 없이 결정론적이고, 맵이 15×12=180셀이라 비용이 무시된다.

### 코너컷 방지

대각 이웃 `(dx, dy)` 는 **인접한 두 직교 이웃이 둘 다 통행 가능할 때만** 허용한다. 아니면 유닛이 벽 모서리를 관통한다 — 타일 정렬 벽이라 눈에 잘 띈다.

### 타이브레이크 = 결정론 계약

현행 `+x, -x, +y, -y` 순서는 코드에 "결정론 계약"으로 명시돼 있다(`FlowFieldBuilder.cs:12`). 이를 **대체하는 새 계약을 명시 정의**한다: `+x, -x, +y, -y, +x+y, +x-y, -x+y, -x-y` (직교 4 → 대각 4). 직교를 앞에 두어 **동률이면 직교를 고른다** — 대각의 실제 이동 거리가 길기 때문이다.

### flow 벡터

대각 방향은 **정규화**해서 저장한다(`1/√2`). `MovementSystem` 이 `normalizesafe` 를 걸지만, 필드가 단위 벡터라는 기존 계약을 유지한다.
