# 5. 우상단 태그 칩 제거 + 카드 이름 2배

## 목적

손패에서 카드를 고르는 1차 단서는 **이름**인데, 지금 이름은 20pt(오토사이즈 14~20)로 헤더의
32px 띠(y −32~−64)에 눌려 있다. 그 위 줄은 코스트 배지(좌상)와 태그 칩(우상 96×24)이 나눠 쓴다.

태그 칩 문안("아군 부착" / "레인저 버프" / "타일 지정")은 unit 1 에서 **타입 색이 무명 코드라
칩이 해설한다**는 근거로 들어왔는데, 실사용에서 본문 첫 줄(`{클래스} 전용`, `타일 지정 → …`)과
정보가 겹친다. 칩을 걷고 그 예산을 이름에 준다.

## 사용자 결정 (2026-07-31)

1. 우상단 태그 칩 **삭제**.
2. 이름 **20pt → 32pt**.
   - 최초 지시는 "2배(40pt)" 였고 rev 0 이 그렇게 구현했다. **rev 1 에서 32pt 로 내렸다**
     (시각 확인 2026-07-31): 40pt 는 헤더가 본문 높이를 20px 먹어 긴 카드 본문이 오토사이즈
     하한 쪽으로 눌렸다. 계약 8(본문 가독 하한)이 이름 크기보다 우선한다.
3. 공간은 **헤더 확대(`HeaderH` 64 → 76)** 로 확보한다. 카드 기하(184×230)·부채 배치·취소존
   (`cancelZoneHeight` 310)·하강(`dragClearanceDrop` 210)은 **건드리지 않는다** — 그 수치들은
   "조준 중 큰 맵의 최하단 행을 드러낸다"는 실측 근거를 갖고 있어 카드 높이를 바꾸면 함께
   재계산해야 한다. 대가로 본문 영역이 154 → 142px 로 줄어든다.

> **`HeaderH` 는 이름 크기 ↔ 본문 가독의 교환비다.** 헤더를 키우면 본문 *폰트 설정*이 아니라
> *높이*가 줄고, 오토사이즈(18~24)가 긴 카드를 그만큼 아래로 내려앉힌다. 한쪽만 보고 만지지 말 것.
> 본문 높이 = `CardH − (HeaderH + 4) − 8`.

## 변경 대상

- `Assets/_Project/Scripts/UI/Dreamcatcher/DreamcatcherHandView.cs`

## 구현

- `HeaderH` 64 → 76. face 투톤 스프라이트의 헤더 비율은 `HeaderH / CardH` 파생이고 본문 rect 도
  `offsetMax = -(HeaderH + 4f)` 파생이라 **둘 다 자동 추종**한다.
- 이름 밴드 재배치: 코스트 배지(좌상 44×44, y 12~−32) 아래 **전폭** 띠로.
  `tagRt.offsetMin = (8, -HeaderH)`, `offsetMax = (-8, -34)` → 168×42px (배지와 2px 여유).
  `nameLabel.fontSize = 32`, `fontSizeMin = 24`, `fontSizeMax = 32`. NoWrap 유지 — 긴 이름은
  오토사이즈가 흡수한다(기존 규율).
- `CardSlot.tagChip / tagBg / tagLabel / tagGroup` 필드 제거 + 참조 6곳 삭제:
  `EnsureSlots` 빌드 블록 · `BindCard` · `BindEmpty` · `RestoreSlotHome` · `DealInSlot` ·
  `StartDeal`. 크럼플 페이드는 `nameGroup`/`costGroup`/`bodyGroup` 3개로 줄어든다(연출 동일).
- `_chipSprite` 동반 제거 — 태그 칩이 유일 소비처였다.
- `CardCategoryStyle.TargetTag` 와 `HandCardStyleTests` 의 태그 케이스는 **남긴다**. 아웃게임
  통일(README 후속 후보 1)의 라벨 계약이고 손패가 유일 소비처였을 뿐이다.
  ⚠ 이 커밋 이후 런타임 소비처는 0 이 된다 — 아웃게임 통일이 무산되면 제거 대상이다.

## 완료 기준

- compile 통과 · EditMode 전량 green.
- Play: 3타입 혼합 손패에서 우상단 칩이 사라지고, 카드 이름이 종전(20pt) 대비 확연히 크다.
- Play: **가장 긴 본문 카드**(현상금 계열 3줄 = 화살표 줄바꿈 후 6줄)가 142px 안에서 종전과
  같은 크기로 읽히는지. 눌려 보이면 `HeaderH` 를 더 내리고 이름 `fontSizeMax` 를 함께 낮춘다
  — 계약 8(본문 floor)이 이름 크기보다 우선한다.
- Play: 크럼플 딜인 / 사용 후 1장 재딜인에서 이름·코스트·본문 페이드가 정상(태그 트윈 제거로
  인한 누락 없음).
- Play: 드래그 · 탭 즉발 부착 · press 툴팁 무회귀.
