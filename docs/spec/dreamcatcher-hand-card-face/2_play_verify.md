# 2 — Play 시각 검증 + 튜닝

## 목적

검증 질문("드래그·press 없이 타입·대상·이름·효과가 한눈에 읽히는가")에 실제 화면으로 답한다.

## 변경 대상

- 코드 변경 없음(튜닝으로 SerializeField 기본값·색 상수 조정 가능성만).

## 구현

1. 에디터 Play → 배치/전투에서 손패 오픈. Squad·Unit·Active·무의식이 섞인 덱으로 확인
   (기본 세이브덱 + Active 2장 주입이면 자연 충족).
2. 스크린샷 확보(겹침 상태 / press-lift 상태 각 1장). Play 중 MCP 뮤테이션 불가 —
   `docs/reference/lessons/` Unity MCP 운용 규칙 준수, 필요 시 PlayMode 테스트 스크린샷 경로.
3. 점검 항목:
   - 겹침(overlap 16) 상태에서 이름·태그·본문 첫 줄이 가려지지 않는가.
   - 본문 3줄 카드(예: 현상금 계열)가 오토사이즈 하한(**16**)에서 잘리지 않는가 — 실기기
     해상도 Game 뷰에서 본문이 실제로 읽히는가(툴팁 19pt 불가 이력 기준).
   - 무의식 보라 테두리가 dim(face 틴트 + 알파 0.75) 상태에서도 식별되고, dim 카드의
     본문 텍스트가 여전히 읽히는가.
   - 크럼플 딜인 중 face 왜곡이 투톤 경계에서 어색하지 않은가(경계 하드 엣지 + 구김 허용).
4. 어긋나면 SerializeField(overlap/폰트 범위/헤더 높이)·색 상수만 조정 — 구조 변경은 spec 개정.

## 완료 기준

- 위 점검 항목 4종 통과 스크린샷 + 사용자 육안 확인.
- 콘솔 에러/워닝 0 (기존 알려진 워닝 제외).
- 기존 PlayMode 스위트 통과.
