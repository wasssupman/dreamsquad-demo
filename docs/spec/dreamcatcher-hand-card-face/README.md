# Dreamcatcher Hand Card Face — 손패 카드 시인성 개편 (아트 제거 → 타입색 + 텍스트 구조)

> 상태: 설계 승인 2026-07-24, 구현 대기
>
> 배경: 손패가 열렸을 때 "이 카드가 무엇이고 어떤 걸 써야 할지" 인지가 안 된다는 피드백 다수.
> 카드 면이 타로 아트 + 하단 네임 밴드뿐이라 타입/적용 대상 정보가 카드 위에 없고,
> 드래그를 시작해야 상단 툴팁에서 처음 보인다. 상단 툴팁 추가로도 해소되지 않았다.

## 목표

인게임 손패 카드에서 **아트를 제거**하고, 카드 면 자체가 정보를 말하게 한다:

- **헤더 밴드(타입 색)** = 카드 상단 1/3. 코스트 배지(좌상, 기존 유지) + 대상 태그 칩(우상) + 카드 이름(중앙).
- **본문 패널(어두운 중립색)** = 하단 2/3. 효과 설명 전문.
- **무의식 카드** = 카드 외곽 테두리를 보라로 교체(BG 타입 색은 유지 — "쓰는 법은 같지만 위험한 카드").
- **겹침 축소**: `cardOverlap 54 → 16` — 이름·본문이 부채꼴에서도 항상 보이게.

## 검증 질문

> 손패를 열었을 때, 드래그·press 없이도 각 카드의 타입(색)·적용 대상(태그)·이름·효과(본문)가
> 한눈에 읽히는가? 크럼플 딜인/드래그/커밋/툴팁 등 기존 손패 인터랙션이 무회귀인가?

## 사용자 확정 결정 (2026-07-24)

1. **적용 범위 = 인게임 손패만.** 아웃게임(덱빌더/브라우저/팝업)은 후속 후보.
2. **BG 색 = 타입** (Squad 블루 / Unit 골드 / Active 청록 신규), **태그 칩 = 적용 대상**.
3. **이름 = 헤더, 설명 = 바디.** 본문은 공용 포맷터(`DreamcatcherCardText`)의 효과 라인(헤더 줄 제외,
   description 폴백) — 화면 문안은 기존 description 과 동일하되 수치 드리프트 방지.
4. **무의식 = 보라 테두리** (4번째 BG 색 아님, 태그 칩 아님).
5. **카드 구조 = 헤더 밴드형** (풀 타입색 단판/인셋 패널 안 대신).

## Feature-wide 계약

1. **색·라벨 단일 소스 = `CardCategoryStyle`** (아웃게임 후속 통일 시 같은 파일 재사용). 손패 전용
   헤더색/테두리색/대상 태그 함수를 여기에 추가한다. 색은 코드 상수(기존 관례), 레이아웃 수치는
   `DreamcatcherHandView` SerializeField(기존 관례) — BattleConfig/SO 신설 없음.
2. **본문 텍스트는 `DreamcatcherCardText` 에 헤더 제외 변형을 추가**해 쓴다. description 직독 금지 —
   포맷터가 소스, description 은 포맷터 미지원 카드의 폴백(기존 툴팁과 같은 규칙).
3. **크럼플 연출 보존**: 카드 면은 `UiRoundedSprite` 신규 함수로 구운 투톤 풀렉트 스프라이트를
   `UiCardFaceMesh` 에 물린다(9-slice 금지 — 크럼플 메시는 outer UV 풀 스트레치). 텍스트/칩은
   기존 `nameGroup` 패턴대로 펴짐 후 페이드-인.
4. **`card.art` 필드·덱빌더·상세 팝업·드래그 툴팁 무변경.** 손패 렌더만 아트 참조를 끊는다.
5. **드래그/커밋/포커스/슬로모/툴팁 로직 무변경** — `BindCard`/`BindEmpty`/`EnsureSlots`/
   `RestoreSlotHome` 의 시각 요소만 교체. 신규 이벤트/큐/ECS 접점 0.
6. **Active 태그는 `SkillEffectType` 파생 순수 함수** (타일 지정/타일 2개/아군 지정, 미지원 폴백 "필드").
7. 직렬화 변경 없음(SO 필드 추가/삭제 0) — 카드 에셋 22장 그대로.

## 후속 후보

- 아웃게임(덱빌더 그리드/덱 스트립/카드 브라우저/상세 팝업)을 같은 BG·태그 문법으로 통일.
- 카드에 설명이 실리면서 상단 드래그 툴팁의 축소/존폐 재검토.
- 대상 태그의 아이콘화(색약 대응 겸), 타입 색 색약 팔레트 검증.
- 은퇴한 카드 아트 에셋/크럼플 아트 경로 정리(덱빌더가 계속 쓰므로 당장 없음).
- 부착 카드의 유닛 위 표시(뱃지) — dreamcatcher-awakening-hand 후속 후보 승계.
