# 5 — 밸런스 1패스 + 골든 코퍼스 재녹화

## 목적

**저울을 맞춘다.** 스트레스가 오르는 속도와 내려가는 속도가 3분을 긴장으로 채우는 비율인지
실제로 재고 조정한다. 그리고 이 spec 이 무효화한 **골든 코퍼스를 새 규칙 기준으로 다시 뜬다.**

## 변경 대상

- `Assets/_Project/Scripts/Data/Decks/*.asset` — `goalStabilityMax` · 회복 배율
- `Assets/_Project/Tests/Golden/*.trace.txt` + `docs/spec/battle-sim-extraction/golden-corpus.md` (자동 생성물)
- `docs/reference/ingame-flow.md` — 종료 조건 3경로
- `docs/reference/map-wave-balancing.md` — 마음 HP·회복 배율을 「자주 바꾸는 값」에 추가

## 구현

**1. 착수 전 기준선(2026-08-23 실측).**

| 항목 | 값 |
|---|---|
| 마음 HP | 1000 (라이브 덱 10종 전부) |
| `Enemy_Basic` | 공격력 20 · 쿨다운 0.5s = **DPS 40** = 스트레스 4.0/초 |
| Basic 1기 단독 | **25초**에 스트레스 100 |
| Basic 5기 | **5초** |
| `Skimmer` / `WaypointAir` | 쿨다운 0.2s = DPS 100 / 50 |
| 잡몹 킬 1회 | `awakeningReward` 2 × 배율 |

**마음 HP 1000 은 이미 무르다.** 첫 후보는 **1500**(첫 요청의 「본능(1000)의 1.5배」).
배율의 첫 후보는 **잡몹 1킬이 Basic 1타(20)를 상쇄하는 수준 = 10** — 「한 마리 잡으면 한 대 값」이
읽기 쉬운 기준점이다. 여기서 시작해 체감으로 움직인다.

**2. 재는 방법.** 「몇 마리가 몇 초 붙으면 끝나는가」는 산수지만, **실제로 몇 마리가 붙는가**는
웨이브 편성·시드·배치 실력 의존이라 산수로 안 나온다. 라이브 6맵을 같은 조건으로 돌려
「마음이 뚫리는 판의 비율」과 「뚫린 시점의 경과」를 기록한다. 목표는 **3분을 못 채우는 판이 있되
흔하지는 않은** 지점이다 — 매판 뚫리면 3분 구조가 무의미하고, 한 번도 안 뚫리면 이 spec 이 무의미하다.

**3. ⚠ 골든 코퍼스를 재녹화한다.** `battle-sim-extraction` M0 가 얼린 7종이 이 spec 으로
무효화된다. 두 갈래다: ① **종료 시점 변화** — 특히 `no_defense`(방어 0기·1800틱)는 마음이
무방비로 맞으므로 거의 확실히 조기 종료로 바뀐다. ② **`HealApplied`(TraceChannel 9)가 traced
채널이라** 마음 힐 펄스가 트레이스 이벤트를 새로 만든다.
`Wassup/Battle/Sim Harness/Regenerate Golden Corpus` 로 다시 뜨고 `golden-corpus.md`(자동 생성물)를
같은 커밋에 넣는다.
**M1(A/B 대조)은 미착수 상태로 홀드 중임을 확인했다**(사용자, 2026-08-23) — 그래서 여기서
재녹화해도 진행 중인 대조를 깨지 않는다. 재녹화본이 **M1 의 새 기준선**이 된다.

**4. 정본 문서 갱신.** `ingame-flow.md` 의 종료 조건을 3경로로. `map-wave-balancing.md` 에
마음 HP·회복 배율 위치를 추가(밸런스 손잡이가 늘었다).
