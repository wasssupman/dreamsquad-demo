# awakening-hud-resource-button

> 상태: 캐주얼 버스트 개정 완료 2026-07-18

## 목표

전투 중 얻는 각성치를 임시 막대 게이지가 아니라 **드림캐쳐 덱을 쓰기 위해 모으는 핵심
인게임 자원**으로 보이게 한다. 우하단 각성 버튼은 큰 수치를 중심으로 한 캐주얼 액션 게임의
버스트 버튼이며, 누르면 기존 Dreamcatcher 손패를 연다. 하단 액션 코너의 충돌을 없애기 위해 배치
단계에서는 각성을 숨기고 `전투 시작`을 기존 우하단에 유지한다. 전투 단계에서는
`타이머/다음 웨이브`를 좌하단, 각성을 우하단에 분리한다.

검증 질문: *"플레이어가 전투 중 각성 수치를 즉시 읽고, 이것이 드림캐쳐 덱을 여는 사용
가능 자원임을 별도 설명 없이 이해하며, 좌우 하단 조작부가 중앙 트레이나 safe area와 충돌하지
않는가?"*

## Feature-wide 계약

- **수치가 1순위**다. 장식·아이콘·충전 연출은 현재 각성치 숫자보다 강하게 보이지 않는다.
- **캐주얼 액션 버튼**이다. 두꺼운 네이비 실루엣, 통통한 보라 젤리 본체, 청록/노랑 색 블록을
  사용한다. 꿈·별·밤·달·깃털·마법·타로 등 이름에서 유추한 상징은 아트에 사용하지 않는다.
- **게이지 = 버튼 중앙의 액체 충전면**. 정확한 값은 중앙 TMP 숫자가, 비율은 아래에서 위로
  차오르는 0~100 액체면이 담당한다. 외곽 장식 링이나 별도 가로 막대는 사용하지 않는다.
- **행동 의미를 노출**한다. 최종 용어 계약에 따라 버튼 내부 라벨은 `드림캐쳐`로 통일하고 탭 시 기존
  `Toggled → DreamcatcherHandView` 경로를 그대로 사용한다.
- **Placement**: 각성 버튼을 숨기고 `전투 시작`을 우하단에 유지한다.
- **Battle**: 좌하단은 `NextWaveDock`, 우하단은 각성 버튼이 소유한다.
- ScreenSpace UI는 `UiCanvasSetup`의 1920×1080 height-match와 `SafeAreaRoot` 계약을 따른다.
- 순수 프레젠테이션이다. 게이지 경제, 카드 코스트, 사이클 덱, ECS와 이벤트 채널은 변경하지 않는다.
- 에셋이 누락되면 절차적 원형 플레이트로 폴백하되 버튼·수치·탭 기능은 유지한다.

## critic 반영 요약

- BLOCKER: `덱 열기`를 제품 용어 `드림캐쳐`로 교체했다.
- BLOCKER: 실제 15/30 소비 단위와 충돌하는 5칸 구슬 표현을 제거하고 연속형 링으로 교체했다.
- HIGH: 244px hit target/220px 버튼, 76px 숫자, 0값 휴면 상태, 획득 `+N`, 손패 open 선택 톤을 적용한다.
- HIGH: 상시 pulse는 사용하지 않고 획득·탭·open 전이에만 짧은 피드백을 사용한다.

## 2026-07-18 캐주얼 버스트 개정

- 기존 달·별·깃털 프레임을 폐기하고 상징 없는 젤리 색 블록 프레임으로 교체한다.
- 방사형 링을 제거하고 버튼 중앙 면이 아래에서 위로 차오르는 액체 게이지로 변경한다.
- 획득 시 숫자 punch와 젤리 squash, 100 도달 시 1회 burst와 느린 ready bounce를 사용한다.
- 100 이전에도 기존처럼 손패를 열 수 있다. 이번 개정은 경제/사용 가능 조건을 변경하지 않는다.

## 기존 계약 대체

`docs/spec/ingame-ui-upgrade/README.md`의 StartButton 우하단 계약은 유지한다. Battle 진입 후
NextWave만 좌하단으로 이동하고 우하단은 각성 버튼이 소유한다. Cost UI와 StartButton 아트
스타일 계약은 유지한다.
