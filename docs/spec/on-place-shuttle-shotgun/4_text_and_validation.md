# unit 4 — 설명 문안 · 시트 동기 · Play 검증

## 목적

두 유닛의 설명을 새 배치 스킬에 맞추고, **시트에도 반영**해 로비 진입 임포트가 되돌리지 않게 한다.

## 변경 대상

- `Assets/_Project/Data/Defenders/Defender_ShieldShuttle.asset` · `Defender_Shotgunner.asset` 의 `desc`
- 유닛 스탯 시트의 같은 `desc` 열 (**SO 만 고치면 로비 진입 임포트가 덮는다**)

## 구현

기존 3줄 형식(`기본 기능 / 배치 스킬 / 특수 효과`)을 유지한다.

| 유닛 | 줄 | 문안 |
|---|---|---|
| 실드셔틀 | 배치 스킬 | `주변 아군 전원에게 보호막` |
| 샷건맨 | 배치 스킬 | `가까운 적 쪽으로 충격파 · 밀어냄` |

- 실드셔틀의 나머지 두 줄은 그대로(`단일 근접 공격` / `도발 · 체력 낮은 아군 주기 실드`).
- ⚠ **한 줄 28자 제한**(`CatalogDescriptions_UseThreeFixedSections` 가 고정). 「크게 밀어냄」은
  29자라 빨개진다 — 실측으로 잘렸다.
- 「겨눈 방향으로」라고 쓰지 않는다 — 샷건맨에는 조준 UX 가 없다. 없는 조작을 약속하는 문안이 된다.
- 샷건맨은 `특수 효과: 없음` 유지 — 밀어냄은 배치 스킬의 성질이지 상시 효과가 아니다.

## 완료 기준

**시트 규율**: 시트 확인은 읽기 전용으로 하고(임포터는 dry-run 이 없어 돌리는 즉시 에셋에 쓴다),
값 수정은 시트 → 임포트 순서로 한다. Play 중에는 에셋 파일 직접 수정이 조용히 무시될 수 있다.

**Play 육안 검증 (한 판에서 연속으로)**
- [ ] 아군이 붙어 있는 자리에 실드셔틀 배치 → 주변 아군 실드 게이지 동시 상승 + 각자 위치에 부여 VFX
- [ ] 적 무리 앞에 샷건맨 배치 → 그 무리 쪽 산탄 + 적들이 뒤로 밀림
- [ ] 두 유닛의 평타가 평소대로 동작(실드셔틀 근접 + 4초 캐스트 / 샷건맨 10발 ±30°)
- [ ] 콘솔 경고·에러 0
- [ ] 선택 패널의 유닛 설명이 새 문안으로 뜬다
      ⚠ **blocker: 시트 반영 전에는 검증할 수 없다.** SO 의 `desc` 만 고친 상태이고 로비 진입
      임포트가 시트 값으로 되돌린다 — 시트를 먼저 갱신해야 이 항목이 의미를 갖는다. 시트는
      공유 데이터라 **푸시는 사용자 승인 후**. spec 종료 전 필수 항목이다.
