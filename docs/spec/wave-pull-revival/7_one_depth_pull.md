# 7 — 원뎁스 당김 + HUD 색 통일 (예고 은퇴)

## 목적

당김 버튼을 **탭 1회 = 즉시 투입**으로 만들고, 도크 색을 상단 HUD(점수·시간·웨이브)와 한 벌로
맞춘다.

rev 7 의 투뎁스(1탭 = 예고 말풍선, 2탭 = 당김)는 「확인시키려고」가 아니라 **자리가 없어서**
생긴 구조였다. 배치 트레이 클램프 때문에 도크 예산은 **좌측 0~320** 뿐이고, 그 폭에 예고를
상시로 두면서 읽히게 만들 방법이 없었다(`NextWaveDock.cs` rev 7 주석 ①②). 그래서 정보를 탭
뒤로 숨겼고 두 번째 탭은 그 파생이었다. 비직관의 원인은 확인 단계가 아니라 그 앞의 은닉이다.

## 이 unit 이 뒤집는 것 (사용자 결정 2026-08-21)

**예고를 없앤다.** 계약 4 와 PRD §6.3(「예고는 당김과 동일 릴리즈」)의 **미채택**이며 누락이
아니다. 근거: 예고가 판단 재료가 되려면 상시로 읽혀야 하는데, 상시로 두려면 폭 256 에 3~5줄을
쌓아야 하고 그건 rev 1~6 이 반복 반려된 「맵을 가린다」로 되돌아간다. **폭 예산은 영구적이다**
(슬롯이 늘어도 클램프가 같다). 즉 이 레이아웃에서 「예고 유지」와 「원뎁스」는 양립하지 않고,
조작의 직관을 골랐다.

**되살릴 때**: 도크로 되돌리는 선택지는 위 제약 때문에 없다. 자리를 옮기는 것이 선행이다 —
상단 바(읽기 값은 읽기 영역에) 또는 스폰 지점 옆 보드(「무엇이」에 「어디로」가 붙는다).

## 구현

**1. 탭 = 당김.** `OnPillClicked` 의 첫 분기(`if (!_calloutOpen) { OpenCallout(); return; }`)를
지우면 바로 `TryPullNextWave()` 다. 플레이어 경로는 여전히 여기 하나뿐 — `ForceNextWave`(기제)를
직접 부르면 겹침 상한이 우회된다.

**2. 말풍선과 `Armed` 연출 은퇴.** `Armed` 는 「한 번 더 누르면 당겨진다」는 신호였으므로
원뎁스에서 의미가 없다. 연출은 한 단계(화살표 오르내림 + 광택)만 남고 잠기면 멈춘다.

**3. 잠금 사유를 라벨이 인수한다** — 계약 3 유지.

| 상태 | 문구 | 버튼 | 연출 |
|---|---|---|---|
| 당길 수 있다 | `다음 웨이브` | 눌림 | 구동 |
| 상한 소진 | `정리하면 다시` | **안 눌림** | 정지 |
| 더 없다 | `마지막 웨이브` | 안 눌림 | 정지 |

잠겼을 때 눌리지 않게 한 이유: 눌리는데 아무 일도 안 일어나면 「고장났나」가 된다.

**4. 색 정본은 `ScoreHudView` 다.** HUD 판은 전부 «어두운 판 + 금테» 이고 금색이 채워진 건
캡션 탭뿐이다. 도크가 그 **금색 채움**을 가져가면 화면에서 「금색 = 누르는 것」이 색만으로 갈린다.

| | 이전 → 지금 | 출처 |
|---|---|---|
| 면 | `0.13,0.46,0.86` → `1,0.78,0.28` | `tabColor` |
| 글자 | 흰색 → `0.1,0.08,0.04` | `tabTextColor` |
| 테두리 | `0.55,0.88,1` → `1,0.9,0.66` | `waveValueColor` |
| 립 | `0.05,0.20,0.44` → `0.42,0.28,0.06` | 면의 그늘 |
| 광택 | 흰색 → `1,0.96,0.82` (a .22) | `shineColor` |

⚠ **색은 씬에 직렬화돼 있다.** C# 기본값만 바꾸면 화면은 안 바뀐다 — `BattleScene.unity` 의
`NextWaveDock` 블록도 같이 바꿔야 한다(이번에 함께 했다). 잠금 색 4개는 이전 값 유지.
크기(256×96)·위치·`panelOffset.x + pillSize.x ≤ 300` 예산은 건드리지 않는다.

**5. 테스트는 살리고 이름만 고친다.** 그 테스트는 브리지를 안 쓰고 `GeneratedWave.groups` ==
`ExpandWave(wave)` 를 유닛별 수량까지 대조한다 — 예고 UI 가 아니라 **생성기 불변식**이라 예고가
사라져도 산다(groups 는 저작·로그·컨셉 검증이 읽는 「이 웨이브가 무엇인가」의 정본).
