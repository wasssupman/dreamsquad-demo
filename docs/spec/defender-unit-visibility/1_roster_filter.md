# 1. 스쿼드 페이지 유닛 목록에서 숨김 유닛 제외

## 목적

`visible == 0` 인 유닛이 스쿼드 페이지 유닛 그리드에 나타나지 않게 한다.

## 변경 대상

- `Assets/_Project/Scripts/UI/Outgame/SquadCharacterPageController.cs` — `BuildLists` + `ToggleUnit`

## 구현

`BuildLists` 가 카탈로그를 훑어 `_units` 를 채우는 그 자리에 한 줄을 더한다:

```csharp
if (u.visible == 0) continue; // 저작으로 숨긴 유닛 — 목록에 노출하지 않는다
```

`_units` 는 그리드 소스(`SortedUnits` → `browser.ShowUnits`)이자 "고를 수 있는 유닛" 목록이므로
이 한 지점이 **보이지도 않고 넣을 수도 없다**를 동시에 만든다. 드림캐쳐 카드의 `BuildPool`
필터와 같은 형태다.

### 넣는 경로에도 같은 불변식을 건다

필터만으로는 부족하다. 상세 패널은 `catalog.ById` 로 유닛을 푸는데 그건 **후보 판정이
아니라 저장된 id 해석기**라 숨김 유닛도 계속 풀어준다(그래야 이미 편성된 숨김 유닛이
헤더 슬롯에 그려진다). 그래서 숨긴 유닛을 [편성 해제]하면 상세는 그 유닛을 계속 붙들고
버튼만 [출전]로 바뀐다 → 그리드에서 사라진 유닛을 다시 넣을 수 있는 **뒷문**이 열린다.

`_units`(= 필터를 통과한 목록)가 「고를 수 있는 후보」의 단일 정의다. 두 곳에서 그것을
쓴다:

- `ToggleUnit` 의 **추가** 분기: 후보가 아니면 넣지 않는다.
- `ToggleUnit` 의 **제거** 분기: 뺀 유닛이 후보가 아니면 선택을 후보로 옮긴다
  (죽은 [출전] 버튼을 남기지 않는다).

제거 자체는 언제나 허용된다 — 그러지 않으면 이미 편성된 숨김 유닛이 영영 안 빠진다.

### 건드리지 않는 것

- **`catalog.ById` 는 그대로다.** 상세 패널·헤더 슬롯·전투 반입이 전부 이 경로로 id 를 푼다.
  숨김 유닛도 계속 해석되므로, 이미 편성돼 있으면 헤더 슬롯에 정상적으로 그려지고 탭하면
  상세가 뜬다(→ [편성 해제] 가능). 이것이 "카탈로그에서 뺀다"와 다른 점이다.
- **`EnterUnitMode` 의 재선택 가드는 그대로다** (`catalog.ById(...) == null` = stale id 판정).
  후보 판정으로 바꾸면 안 된다 — 숨김 유닛이 편성된 채 페이지에 들어왔을 때 선택이
  그 유닛에서 튕겨 나가, 헤더 슬롯 탭으로는 볼 수 있는데 진입 시엔 못 보는 모순이 된다.
  규칙은 「선택이 후보여야 한다」가 아니라 「**편성에 넣는 것만** 후보로 제한한다」다.
- **`SortedUnits` 는 그대로다.** 편성-먼저 정렬의 앞부분은 `_workingUnits` 를 `catalog.ById`
  로 풀어 붙이므로, 숨김 유닛이 편성돼 있으면 **그리드 맨 앞에 남는다**. 이 정렬을 고치면
  "편성된 것은 항상 목록 앞에 보인다"는 unit 10 의 계약이 깨진다. 목록의 필터는 _추가할 수
  있는 후보_ 에 대한 것이지, 이미 편성된 것을 지우는 규칙이 아니다.
- **`FirstWorkingUnitOrDefault` 의 `_units[0]` 폴백**은 이제 자동으로 "보이는 첫 유닛"이 된다
  — 별도 처리 불필요.

### 경계 조건

전 유닛을 숨기면 `_units` 가 비어 그리드가 빈 화면이 된다. 편성이 비어 있으면 상세 패널도
빈다(`detailView.Show(null, …)` 는 이미 정상 입력). 저작 실수는 저작으로 되돌린다 — 코드에
"최소 N개는 남긴다" 같은 방어를 넣지 않는다.

## 완료 기준

- [ ] 컴파일 통과
- [ ] 유닛 하나를 `visible = 0` 으로 두고 Play → 그리드에서 그 셀이 사라지고 나머지 수 = 27 − 숨김
- [ ] 그 유닛이 편성돼 있던 프리셋을 열면 헤더 슬롯에 그대로 있고, 슬롯 탭 → [편성 해제]로 뺄 수 있다
- [ ] 한번 빼고 나면 그리드에 다시 나타나지 않는다(재편성 불가)
- [ ] `visible` 을 `1` 로 되돌리면 그리드에 다시 나타난다
