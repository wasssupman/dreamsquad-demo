# 7 · 누운 자세 낙하 + 강조 20 + "이거 눌러봐" 어필

## 목적

사용자 피드백 3건: (1) 피규어가 딱 서있는 고정 자세로만 떨어짐 → **자연스럽게 누워도**
떨어지게(자세 변화). (2) 강조 시점을 100(가득)이 아니라 **20(첫 사용 가능 = 최소 코스트)**로.
(3) 강조 상태에 **"이거 눌러봐!!!"** 감성(주의 유도) 추가.

## 변경 대상

- `JarFigurePile.cs` — 피규어별 회전 상태(`_rot`/`_rotVel`) + `RestRot(i)`. 낙하 시 텀블 →
  rest 각으로 감쇠 스프링 정착. 뷰 매핑에 localEulerAngles.z 적용.
- `AwakeningGaugeView.cs` — rim 골드 강조를 `_normalized>=0.999`(100) 대신 `_ready`(≥최소코스트)로.
  "이거 눌러봐" 어필 루프(`AttentionRoutine`) + "눌러!" 탭 힌트 칩 + `UpdateAttention` 게이트.

## 구현

- **누운 자세 낙하(#1)**: 각 피규어에 `_rot`(현재각)·`_rotVel`(각속도). SpawnAtTop 시 인덱스
  결정론 초기 각속도(±140~230°/s)로 텀블. 매 고정스텝 감쇠 스프링(`rotK=55, rotDamp=7.5`)으로
  `RestRot(i)` 로 정착. RestRot = 인덱스 결정론 변주(살짝 기욺/기울어짐/누움 ≈ 30/35/35%).
  Jostle 이 회전에도 미세 킥. **순수 물리 검증**: 텀블→정착 수렴(|Δ|≈0, NaN 없음), 44개 분포에
  누움/기울음 다수.
- **강조 20(#2)**: `_readyThreshold` 는 이미 `minCost/max`(=0.2). rim 색 분기만 `_ready ? 골드 :
  보라` 로 바꿔 **20 에서 골드 강조**, 100 은 특별 강조 없음(오버플로우 낭비 색은 별개 유지).
- **어필(#3)**: **텍스트 라벨 금지**(사용자: "눌러!" 텍스트는 초보 UX) → **비주얼 언어**로 탭
  지점 유도. `_ready && !_open && 패널활성` 동안 `AttentionRoutine` 지속 — (a) 독이 주기적 통통
  바운스(`attentionPeriod` 기본 1.5s, `_visualRoot` 스케일 솟음), (b) 골드 림 알파 브리딩, (c)
  **소나 펄스 링** — 항아리 테두리에서 밖으로 퍼지며 페이드하는 골드 hollow 링 2개(위상 스태거 =
  물결 연속 방출). 가운데는 비어 숫자 안 가림. 랜드스케이프 양손 플레이에서 독은 트레이 우측(엄지
  리치) → 펄스 링이 그 위치에서 시선/엄지를 끄는 모바일 보편 "탭" 신호. 손패 열림/ready 해제/패널
  꺼짐 즉시 정지·복원. ReadyPulse(임계 진입 한방)와 스케일 안 겹치게 양보. (설계-리뷰 "상시 pulse
  금지"는 사용자 명시 요청으로 갱신 — 절제된 주기 강조로 유지.)
- **어필 강도 추가(rev, 사용자 요청)**: (d) **넛지** — 튀는 순간 독이 중앙(엄지 접근 경로) 쪽으로
  살짝 기울었다 스프링백(`attentionLean` 기본 5°) = "이리로!" 몸짓(손 위치 고려). (e) **피규어 홉**
  — 바운스 리듬에 맞춰 1회/주기 전 피규어에 위 임펄스 + 회전 킥(`JarFigurePile.Hop`) = 갇힌
  꿈-피규어가 "꺼내줘" 하듯 들썩(주기적이라 상시 노이즈 아님). Play 라이브 검증: 홉 위속도 반전
  (-3.17→1.87), 넛지 진동(0→0.88→0°).
