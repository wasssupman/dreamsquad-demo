## 목표

우하단 각성 버튼을 제거하고, 통합 트레이 오른쪽에 **인접하되 분리된 드림캐쳐 항아리 독**을
신설한다. 항아리(세로 컨테이너) 안에 스러진 유닛들의 미니 피규어(Spine 프리즌, 스케일 ~0.2)가
차오르며 **fill 질감**이 되고, 게이지 판독은 **세로 채움 높이 + 큰 숫자 + 코스트 눈금**이
책임진다. 피규어는 "몇 개인지 세는" 판독 부담을 지지 않는다. 항아리 탭=손패 열기, 손패 바깥
탭=닫기. 킬/아군 사망 위치에서 항아리로 날아오는 흡수 비행이 도착하는 순간 피규어가 떨어져
축적의 인과가 눈에 보인다.

검증 질문: *"모바일 가로 양손 그립 플레이 중, 시선·엄지 동선 위에서 (a) 지금 각성치와 (b)
어떤 카드를 지금 낼 수 있는지를 힐끗 보고 즉답할 수 있고, 드림캐쳐 덱 열기/닫기가 코너 조준
부담·오발 없이 되는가?"*

## Feature-wide 계약

### 위치·구조
- **독은 유닛 트레이와 분리된 형제 오브젝트**다. 트레이 우측 가장자리에 인접(작은 갭)하되,
  손패 플립에 불참하고 손패 열림 중에도 같은 자리에 상주한다. Battle 페이즈 전용 노출과
  튜토리얼 `SetSuppressed` 경로는 기존 버튼에서 승계한다.
- **트레이 폭·유닛 슬롯을 침범하지 않는다.** 코너 버튼 은퇴로 비는 우측 예약 여백
  (`cornerReservedWidth`)에 독을 얹고, 트레이 자체 폭은 불변으로 유지한다. 배치 슬롯이
  좁아지면 안 된다.
- **탭 히트존은 시각 아트와 분리**해 최소 ~140px 이상 확보한다(세로 항아리라 세로 히트
  면적이 자연스럽게 확보됨). 최우측 슬롯과 fat-finger 오발을 막기 위해 갭을 둔다.
- **엄지 그림자 대응**: 핵심 판독 요소(큰 숫자·ready 림·상단 눈금)를 항아리 상단부에 두어
  엄지가 트레이 우측을 조작할 때 덜 가려지게 한다. 최종 배치는 실기기 그립 테스트로 검증.

### 게이지 판독 (리뷰 핵심 수정)
- **큰 숫자가 1순위 판독**이다. `awakening-hud-resource-button`의 "수치 1순위" 계약을
  **되돌리지 않고 유지**한다. 소형 병기가 아니라 힐끗 읽히는 크기.
- **세로 채움 높이 = 2순위 판독**. 피규어가 차오른 높이가 막대처럼 레벨을 전달한다. 값의
  source of truth 는 항상 `DreamcatcherHandController.Gauge`이며 숫자가 exact 값을,
  채움 높이는 근사 질감을 담당한다(비행 지연으로 인한 미세 어긋남은 숫자가 흡수).
- **코스트 눈금**: 항아리 측면에 덱의 카드 코스트(현재 15/20/30) 위치에 틱 마커를 얹는다.
  마커 값은 `AwakeningConfig`에서 파생(하드코딩 금지). 채움면이 틱을 넘으면 그 등급 카드를
  낼 수 있음을 직접 보여준다 — "몇 개인지 세기" 없이 affordability 즉답.
- **피규어는 fill 질감으로 강등**한다. 개수 판독 기대를 걸지 않는다. 1피규어=N 이산 pip을
  판독 단위로 쓰지 않는다(직전 spec critic이 BLOCKER로 제거한 5칸 표현의 재발 금지).

### 상태 신호 (1차 출시 필수 — 후속 금지)
- **ready(affordability)**: `Gauge ≥ 덱 최저 코스트`가 되는 순간 항아리 림이 발화 상태로
  전환(색 + 저진폭 bounce), 그 이하는 잠잠. MAX만이 아니라 "쓸 수 있게 된 순간"을 알린다.
- **오버플로우 경고**: MAX(100) 상태에서 킬이 계속 들어와 재화가 소멸 중이면 시끄러운 손실
  신호(림 맥동/넘침 연출). 손실 회피를 위해 이 신호는 **1차 출시에 포함**한다.

### 연출 절제 (unit-5 critic 준수)
- **물리는 드롭 임팩트 순간에만 짧게 살아나고 빠르게 정지**한다. 정적 상태의 상시 진동
  금지(직전 spec unit-5 critic이 HIGH로 금지한 "상시 pulse"의 재위반 방지). MAX도 상시
  진동이 아니라 간헐 저진폭 tremor로.
- **흡수 비행은 다발 킬 시 배칭/코얼레스**해 파티클 폭주를 막는다. 주변시 모션 총량을 물리
  임팩트와 함께 관리한다.

### 인터랙션
- **항아리 = 열기 스위치**. 탭 시 기존 `Toggled → DreamcatcherHandView` 계약을 그대로
  사용하고, open/close 상태 소유자는 변함없이 `DreamcatcherHandView`다.
- **닫기 = 손패 부채꼴 바깥 탭(grace 마진 포함)** 단일 규칙. 항아리 재탭 토글은 두지 않는다
  (최우측 카드 인접 오발 방지). 손패 열림 중에는 배치 스트립이 플립되어 사라져 배치가
  불가하므로, 바깥 탭 dismiss 가 배치 드래그와 충돌하지 않는다.
- **드래그 실패 복귀는 취소**로 유지(닫힘 승격 금지). 카드 근접 탭은 grace 마진으로 닫힘
  승격하지 않는다.

### 발견성
- **항아리에 상시 소형 라벨/카드 아이콘을 병기**한다(직전 spec이 BLOCKER로 박은 `드림캐쳐`
  라벨 계승 — 없애지 않는다). 첫 플레이 1회 coach mark로 탭 어포던스를 가르친다.

### 렌더링·성능
- **피규어 = 스러진 유닛의 미니어처**. 스폰 시 사망 애니 마지막 프레임을 1회 적용 후
  `UpdateMode.Nothing`으로 동결. 전투 시작 시 풀에 선생성, 상한 20개. 실기기 드로우콜 문제
  확인 시에만 스틸 베이크로 후퇴(후속 후보).
- **물리는 순수 함수 시뮬** (제약 10). 세로 경계 + 원-원 충돌 + settle 의 plain step 함수와
  결정론적 레벨 질의를 EditMode 테스트한다. Physics2D·UGUI Mask 금지 — 클리핑은 물리 경계와
  항아리 림/유리 오버레이가 대신한다(코스트 물통 스텐실 사고 전례).
- **게이지 값 source of truth 는 `DreamcatcherHandController.Gauge`** 그대로. 뷰는
  `GaugeChanged`를 구독해 목표 레벨을 맞출 뿐, 경제(획득량·코스트·상한)를 변경하지 않는다.

### 경계
- **우하단 코너는 비운다**. `AwakeningGaugeView`는 은퇴시키고, Placement 의 `전투 시작`
  우하단 계약(`ingame-ui-upgrade`)과 좌하단 `NextWaveDock`은 변경하지 않는다.

## 리뷰 반영 (2026-07-23, 2-페르소나)

UX 디자이너·미드코어 게이머 두 리뷰가 독립적으로 수렴한 지적:
- **BLOCKER**: "피규어 부피=1차 게이지"가 계획 크기에서 성립 불가(판독 불가·비단조·비결정론,
  코스트 임계가 구분 불가 구간에 몰림). → **항아리형으로 전환**: 채움 높이+큰 숫자+코스트
  눈금이 판독, 피규어는 fill 질감으로 강등.
- **BLOCKER/HIGH**: affordability·오버플로우 신호 부재, 직전 spec이 이미 고친 이산 표현·상시
  pulse 의 재발. → ready/오버플로우 신호를 **1차 필수**로, 물리 **임팩트-only**, 이산 pip
  판독 폐기.
- **HIGH**: 닫기 오발(재탭+바깥탭, 유닛 배치 드래그 미정의). → **바깥 탭 단일 규칙**+grace,
  손패 열림 중 배치 불가라는 기존 상호배타 구조로 충돌 해소.
- **HIGH/MEDIUM**: 탭타겟 축소, 발견성(라벨 제거), 트레이 폭 경합. → 히트존 분리, 라벨/coach
  mark 계승, 트레이 폭 불변·여백 오버레이.

세부 리뷰 원문은 대화 로그 참조. 슬로모(현행 `Open()`의 TimeManager 0.3x)는 본 spec 스코프
밖의 기존 동작이며, "즉발 캐스트" 니즈는 후속 후보로 둔다.

- **unit 2b — Spine 피규어 스킨** (보류): 20단계 granularity 피규어(~24px=실기 1.4mm)에선
