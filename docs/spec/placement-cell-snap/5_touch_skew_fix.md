# 5 — 터치 판정 퍼스펙티브 수평 스큐 제거

**작업 구분**: bugfix · 의존: 없음(키링 오프셋 기하 독립 수정)

## 목적

드래그 배치에서 손가락이 가리키는 지점과 판정 타일의 **좌우 관계가 화면 위치(카메라)에 따라 달라지는**
어색함을 제거한다. 실측(Play, 카메라 60° 틸트·FOV 43° 퍼스펙티브): 손가락→판정 타일 수평 오프셋이
좌 0.89 → 중앙 0.70 → 우 0.50 셀로 변동(깊이 오프셋은 2.78셀로 일정).

## 원인

타일은 `feet = ring − camUp × totalDrop`(유닛이 화면상 손가락보다 totalDrop 아래 매달리는 지점)에서 판정한다.
이 화면-세로(camUp) 오프셋을 기울어진 보드 평면에 투영하면 **수평(카메라 right 투영) 성분이 화면 x 에 따라
달라진다**(퍼스펙티브 수렴). 깊이 성분은 일정. → 좌우 판정이 카메라 위치/틸트에 의존.

## 변경 대상

- Modify: `Assets/_Project/Scripts/UI/DefenderDragPlacementController.cs` (`TryComputeRingUnit`)

## 구현 (보드공간 정렬 — 옵션 A)

`feet` 계산 후, **보드-수평 성분을 손가락 직접 히트와 정렬**:

```
sf = -(dot(N, camPos) + plane.d) / nd;         // 손가락 ray 의 보드 직접 히트
pFinger = camPos + rayDir * sf;
boardRight = ProjectOnPlane(camRight, N).normalized;   // 화면-수평의 보드 축
feet -= boardRight * dot(feet - pFinger, boardRight);  // 수평 성분만 손가락과 정렬
```

- 깊이(보드 depth) 오프셋은 **유지**(유닛이 손가락보다 앞/아래에 매달리는 키링 시각 보존).
- 수평만 손가락 열에 맞춤 → 손가락이 가리키는 열에 정확히 판정, 화면 어디서나 일관.
- 검증(Play 실측): 보정 후 수평 오프셋 dX = 0.000 (좌/중/우 동일), 깊이 dY = −2.785 유지.

## 완료 기준

- 시각 확인: 유닛이 손가락 열에 정렬돼 매달림(스큐로 인한 좌우 어긋남 사라짐). 키링 줄이 약간 기울 수 있음 — 자연스러운지 육안 확인.
