# unit 1 — Serpent «굽이 합류» (컨셉 원형)

## 목적

Serpent 를 개편 컨셉의 원형으로 재저작한다. 여기서 확정되는 감각 기준(광장 포켓 밀도 D1, 폭2 체감)이 units 2~5 에 복제된다.

## 구현 — 확정 레이아웃 rev 2 (15×11)

> rev 1(직선 파이프 2줄 + 광장)은 사용자 리뷰로 기각 — «ㄷ자지 뱀이 아니다». rev 2 는
> 거울 S 반쪽 둘이 중앙 허리를 감싸는 형태로 굽이 정체성을 실제로 세운다.

```
y10 □□□□□□□□□□□□□□□
y9  S......♣♣♣□□□□□     ← 상단 스트로크(폭2) → 우측에서 ↓
y8  .......♣♣♣□□□□□
y7  □♣♣♣♣.........□     ← 중단 스트로크(폭2) → 광장으로
y6  □♣♣♣♣.........□
y5  □♣♣♣♣♣♣♣♣♣....□     ← 중앙 허리(♣) — 지상 분리 · 공중 일직선 관통
y4  □♣♣♣♣.........□     ← 하단 레인의 중단 스트로크(거울)
y3  □♣♣♣♣.........□
y2  .......♣♣♣□□□□□
y1  S......♣♣♣□□□□□
y0  □□□□□□□□□□□□□□□
```

- **S 굽이 실체화**: 위 레인 = 우→하→우, 아래 레인 = 우→상→우. 두 레인은 허리(♣)로 분리돼
  **광장(x10..13, y3..7)에서만 합류** — 갈래가 지형으로 성립(계약 4).
- **마음 1개** (12,5) 광장 안 (계약 3).
- **Air 경로 = 허리 일직선**: `(2,5)→(7,5)` — 지상은 뱀처럼 감아 가는데 비행은 그 허리를
  직선으로 관통한다. 지상/공중 대비가 이 맵의 정체성.
- **배치 포켓(D1 개선)**: NE(x10..14, y8..9)·SE(x10..14, y1..2) 큰 포켓이 광장 남북을 내려다보고,
  좌측 숲 프레임·상하 프레임이 스트로크를 덮는다. rev 1 의 «서벽·동벽뿐» 문제 해소.
- placeMask 파생 리셋 · waveSeed·덱·스폰 무변경은 rev 1 과 동일.
