# unit 1 — Serpent «굽이 합류» (컨셉 원형)

## 목적

Serpent 를 개편 컨셉의 원형으로 재저작한다. 여기서 확정되는 감각 기준(광장 포켓 밀도 D1, 폭2 체감)이 units 2~5 에 복제된다.

## 변경 대상

- `Assets/_Project/Data/Maps/MapDocument_Serpent.asset` — 지형·골·Air 경로 재저작
- 코드 0줄 (unit 0 의 가드로 검증만)

## 구현 — 확정 레이아웃 (15×11)

```
y10 □□□□□□□□□□□□□□□
y9  S.............□      ← 상단 복도 폭2 (y8·y9)
y8  ..............□
y7  □□□♣♣♣♣♣♣□....□     ← 숲 6×5 = 공중 대륙 (x3..8, y3..7)
y6  □□□♣♣♣♣♣♣□....□
y5  □□□♣♣♣♣♣♣□..G.□     ← 광장 4×5 (x10..13, y3..7), 마음 (12,5)
y4  □□□♣♣♣♣♣♣□....□
y3  □□□♣♣♣♣♣♣□....□
y2  ..............□      ← 하단 복도 폭2 (y1·y2)
y1  S.............□
y0  □□□□□□□□□□□□□□□
```

- **정체성 유지**: S자 굽이 = 상·하 두 복도가 우측에서 꺾여 광장으로 «합류». 스폰 (0,9)/(0,1) 불변.
- **마음 1개** (12,5) — 기존 2개((7,6)/(7,4)) 은퇴 (계약 3).
- **Air 경로 재저작**: `(3,6)→(5,5)→(7,4)` — 숲을 대각으로 질러 광장 서편으로 진입. 두 스폰 어느 쪽에서도 숲 진입이 자연스럽다.
- **placeMask = 파생 리셋** — 재저작 전 기존 마스크가 파생과 동일함을 확인하고(손저작 소실 방지) 파생으로 굽는다.
- **waveSeed·덱 무변경** (계약 8).
