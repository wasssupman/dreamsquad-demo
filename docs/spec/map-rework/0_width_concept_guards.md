# unit 0 — 컨셉 가드 (폭1 경고 · 광장 부재 경고)

## 목적

개편 컨셉(복도 폭≥2 · 광장 1+)을 **저작 시점 경고**로 세운다. 에러가 아니다 — 비개편 맵(Hook·Test·MovementLab)의 bake 를 막지 않는다(계약 1).

## 변경 대상

- `Assets/_Project/Scripts/Data/MapGrid/MapConceptRules.cs` — 신규(순수 static)
- `Assets/_Project/Editor/MapPainterWindow.cs` — 경고 박스에 합류
- `Assets/_Project/Tests/EditMode/MapConceptRulesTests.cs` — 신규

## 구현

**폭1 판정(순수)**: Walk 셀에서 **한 축의 양옆이 모두 비-Walk** 이면 그 축으로 폭1이다 — 가로 복도의 위·아래가 다 막혔거나, 세로 복도의 좌·우가 다 막혔거나. 폭2 복도의 셀은 복도 방향 이웃 + 폭 방향 이웃이 있어 안 걸리고, L자 코너 셀도 안 걸린다. 경고는 **요약 1줄**(개수 + 좌표 최대 5개) — 셀당 1줄이면 레거시 맵을 열었을 때 경고 박스가 무너진다.

**광장 판정(순수)**: 4×4 전부 Walk 인 블록이 1개 이상 존재하는가. 없으면 경고 1줄.

**배선은 페인터 경고 박스만.** `OnValidate` 에는 넣지 않는다 — 임포트마다 콘솔을 울려 비개편 맵 5장이 상시 소음이 된다. 계약 1의 의도는 «저작 중 가드»이고 페인터 경고 박스가 그것이다(README 표현과의 차이는 이 사유로 확정).
