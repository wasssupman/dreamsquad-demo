# Battle HUD Layout — 하단 손패 중앙 통일 Spec

**작성일**: 2026-07-11
**상태**: 완료 2026-07-11 (`9e6895fd`)
**목표**: 유닛 배치 스트립을 하단 좌측에서 하단 중앙으로 옮겨 드림캐쳐 카드 핸드와 **동일 footprint 플립**을 성립시키고, 코스트 표시를 스트립에 동반 이동시켜 "손패 + 경제" 클러스터를 화면 하단 중앙 한 곳으로 통일한다.

## 배경 (결정 근거 요약)

TD 장르 전문가 × 캐주얼 모바일 UX 전문가 2-패널 교차 검증(2026-07-11)으로 수렴:

- **현 좌측 배치 기각(만장일치)**: 드래그-투-배포 손패를 좌측 코너에 둔 성공작 없음.
- **중앙 채택 근거**: ① 드림캐쳐 핸드가 이미 StS식 중앙 손패로 커밋됨(같은 카드 문법을 쪼개지 않는다) ② 드래그 정밀성은 시작점이 아닌 종점(중앙 보드)에서 소진 + 키링 오프셋이라 우세손 이점 미발동 ③ 드래그-투-배포 손패 성공작(CR/Random Dice/Rush Royale/StS) 전원 bottom-center ④ 이동 요소 최소(스트립+코스트만, 웨이브 독 불변) ⑤ 좌우 대칭이라 왼손잡이 옵션 불필요.
- **중앙안의 유일 실비용**: 상시 footprint 가 중앙 하단 보드를 가림 → Battle 페이즈 슬림 모드로 상쇄(unit 2).

## 공통 원칙 (feature-wide 계약)

- **동일 footprint 플립**: 유닛 스트립과 드림캐쳐 핸드는 같은 bottom-center 축, 같은 anchoredPosition y(32) 에서 X-회전 플립으로 전환한다. 좌표 점프 없는 "정직한 제자리 플립"이 이 spec 의 정의적 산출물.
- **앵커 side 는 페이즈와 무관하게 고정**. 페이즈 차별화는 크기/부각만 (좌↔우 순간이동 금지).
- **웨이브/START 독(bottom-right)과 타이머는 건드리지 않는다.**
- **코스트-스트립은 한 클러스터**: "코스트 확인 → 슬롯 선택 → 드래그"가 한 시선 안에서 돌아야 한다 (CR 엘릭서 바 관례).
- 드래그 상호작용(DefenderDragSlot / DefenderDragPlacementController / 키링 오프셋)은 **변경하지 않는다**. 이 spec 은 순수 레이아웃.
- **핸드 오픈 = 스트립+코스트 배지 동반 퇴장**: 배지 표시는 `CostDisplay` 가 페이즈 × 억제 플래그(`SetSuppressed`) 결합으로 단독 결정, HandView 는 신호만 보낸다.
- 레퍼런스 해상도 1920×1080 (CanvasScaler ScaleWithScreenSize) 기준 좌표로 기술한다.

## 후속 후보 (범위 밖)

- **7슬롯 첫 세션 게이팅**: 초반 3~4 슬롯 → 점진 해금 (캐주얼 인지 부하; 전문가 패널 공통 권고)
- **슬롯 시각 변별 강화**: 역할군별 프레임 색/아이콘 등
- **긴 유닛명 슬롯 이름 겹침**: 포이즌캐스터/파이어캐스터/아이스캐스터 3연속 시 이름 오버플로우 겹침 — 오토사이징 or 축약 검토
- **스트립 배경 플레이트**: 현재 스트립은 투명 슬롯 나열 — 핸드(어두운 배킹)와 플립 시 시각 무게 차이가 크면 배킹 통일 검토
- 좌우 반전(왼손잡이) 옵션: 중앙 대칭 채택으로 **불필요 판정** — 기록만 남김
