# 3 — 비율형 수치 (코어 · U7)

## 목적
효과 수치를 「고정」 또는 「소유자의 특정 스탯 × 비율」로 저작할 수 있게 한다. 값은 **시전 순간**의 소유자 **최종 스탯**(버프·모디파이어 반영)으로 고정해 싣는다.

## 변경 대상
- `EffectDef` — 수치 방식(닫힌 enum: `Flat` · `OwnerStatRatio`) + 기준 스탯(닫힌 enum: 초안 `Attack` · `MaxHealth`) + 비율.
- 시전 지점 — 효과가 발동하는 드레인(`TriggerDispatcher` → 스킬 입력)에서 소유자 최종 스탯 × 비율을 **한 번** 계산해 효과 수치로 싣는다. 투사체·장판은 그 값을 그대로 나른다(착탄 때 소유자를 되묻지 않는다 — 사건·요청은 값 스냅샷).
- 기준 스탯의 뜻을 한 곳에 — 최대 체력 = `Unit.MaxHealth`(모디파이어 반영값) · **공격력 = 평타 한 발의 피해 출력 합 × 공격자 쪽 배율**(U11 — 대상 조건 배율 · 강타 제외). **새 순수 함수** — `ShotDamage`(`CombatPhase.cs:836`)는 피해자 인수를 받고, 강타(`AttackMod.cs:121`)는 카운터를 전진시키므로 재사용 금지.
- 비율 적용 칸은 unit 0 의 「비율 적용 칸 표」가 정한다(`tables.md` §9 — 피해 · 실드량. 회복 종류는 오늘 없다).
- 시전 순간 = README 계약 9. 사망·퇴근 발동은 감지자가 **스탯 스냅샷**을 사건(`TriggerEvent`)에 싣는다. 주인 없는 시전의 비율형은 `EffectComboRule` 에서 거절(사유 「원점을 못 낸다」와 별개 — 「비율 기준이 없다」 사유 추가 여부는 구현 판단).
- 계산은 순수 함수(제약 10) + 단위 테스트.
