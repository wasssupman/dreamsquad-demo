# 3 — 비율형 수치 (코어 · U7)

## 목적
효과 수치를 「고정」 또는 「소유자의 특정 스탯 × 비율」로 저작할 수 있게 한다. 값은 **시전 순간**의 소유자 **최종 스탯**(버프·모디파이어 반영)으로 고정해 싣는다.

## 변경 대상
- `EffectDef` — 수치 방식(닫힌 enum: `Flat` · `OwnerStatRatio`) + 기준 스탯(닫힌 enum: 초안 `Attack` · `MaxHealth`) + 비율.
- 시전 지점 — 효과가 발동하는 드레인(`TriggerDispatcher` → 스킬 입력)에서 소유자 최종 스탯 × 비율을 **한 번** 계산해 효과 수치로 싣는다. 투사체·장판은 그 값을 그대로 나른다(착탄 때 소유자를 되묻지 않는다 — 사건·요청은 값 스냅샷).
- 기준 스탯의 뜻을 한 곳에 — 최대 체력 = `Unit.MaxHealth`(모디파이어 반영값) · **공격력 = 모든 공격력 변형 효과가 반영된 평타 1회 피해의 최종값**(출력 목록 `AttackState.Outputs[]` 합 × 공격 쪽 배율 전부 — 정확한 합산 규칙은 기존 평타 피해 계산을 재사용해 한 곳에서).
- 계산은 순수 함수(제약 10) + 단위 테스트.

## 완료 기준
- 라이브 전량 `Flat` → 굽기 스냅샷 무변.
- 새 테스트: 비율형 피해가 시전 순간 최종 스탯을 따른다(버프 전후 비교) · **발사 뒤** 걸린 버프는 착탄 피해에 반영되지 **않는다** · 비행 중 소유자가 사라져도 피해는 그대로.
