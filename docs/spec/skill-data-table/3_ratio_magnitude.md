# 3 — 비율형 수치 (코어 · U7)

## 목적
효과 수치를 「고정」 또는 「소유자의 특정 스탯 × 비율」로 저작할 수 있게 한다. 값은 **착탄 순간**의 소유자 **최종 스탯**(버프·모디파이어 반영).

## 변경 대상
- `EffectDef` — 수치 방식(닫힌 enum: `Flat` · `OwnerStatRatio`) + 기준 스탯(닫힌 enum: 초안 `Attack` · `MaxHealth`) + 비율.
- 착탄 · 즉시 적용 지점 — 투사체 착탄(`TickProjectilePhase` 피해 지점)과 즉시 피해 의도에서 소유자를 찾아 최종 스탯으로 계산. 발사 요청은 방식·기준·비율을 **값으로** 싣는다(소유자 참조는 id).
- 기준 스탯의 뜻을 한 곳에 — 최대 체력 = `Unit.MaxHealth`(모디파이어 반영값), 공격력 = 아래 미결.
- 계산은 순수 함수(제약 10) + 단위 테스트.

## 미결 (착수 전 사용자 확인)
- **「공격력」의 정의**: 유닛 공격은 출력 목록(`AttackState.Outputs[]`)이라 값이 여럿이다 — 첫 피해 출력 × 피해 배율? 피해 출력 합? 
- **착탄 순간 소유자가 없으면**(비행 중 사망·퇴근): 발사 순간 값 / 0 / 효과 취소 중 무엇.

## 완료 기준
- 라이브 전량 `Flat` → 굽기 스냅샷 무변.
- 새 테스트: 비율형 피해가 버프 전후 착탄 시점 값으로 바뀐다 · 발사 뒤 버프가 걸리면 착탄 피해에 반영된다 · 미결 2 의 답대로.
