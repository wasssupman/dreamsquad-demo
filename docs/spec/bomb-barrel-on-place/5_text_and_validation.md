# 5 — 설명 문안 + 시트 + 최종 검증

## 목적

배치 스킬이 카드/스쿼드 화면에서 **무슨 일이 일어나는지 한 줄로** 읽히게 하고, 시트 정본을
맞춘다.

## 변경 대상

- `Assets/_Project/Scripts/Data/UnitKitSummary.cs` — 배치 규칙 문안 절
- `Assets/_Project/Data/Defenders/Defender_BombMan.asset` — `desc`
- 구글 시트 `Defenders` 탭 — `desc` (정본)

## 구현

- **문안 절**: `OnPlaceRuleClause` 의 `EmitProjectilePattern` 분기는 지금 탄의 **궤적**으로
  갈린다(방향 발사 ↔ 미사일 낙하). 배럴은 세 번째 그림이므로 착탄 payload 가
  `SpawnBlocker` 인 경우를 갈라 「배치 시 가까운 적에게 폭탄 배럴」 계열 문안을 낸다.
  ⚠ 배선 안 된 조합은 조용히 문안이 비고, **전수 테스트가 그걸 실패로 잡는다**(실드셔틀 선례).
- **줄 길이 규율**: 카탈로그 설명은 3줄 고정이고 **한 줄 28자 이하**여야 한다
  (`UnitKitCatalogTests`). 폭탄맨 2번째 줄이 「배치 스킬: 없음」에서 바뀌므로 길이를 센다.
- **시트가 정본이다**: `desc` 는 시트 소유라 에셋만 고치면 다음 로그인 임포트가 되돌린다.
  시트 반영은 **사용자 승인 후** push 하거나 사용자가 직접 넣는다.
