# 3 — Play 검증

## 목적

전체 경로를 Play 로 검증한다.

> **시즌 배경 와이어링 폐기(2026-07-08)**: 배경을 dim 오버레이로 되돌리며 씬 스프라이트 배선 불필요. `ResultScreen` 직렬화 필드 0 → BattleScene diff 0. cosmic 텍스처 임포트도 원복(Texture2D).

선행: unit 1~2.

## 완료 기준

Play 검증(로그인 상태):
- [ ] 배틀 종료(승/패) → 결과 팝업이 dim 오버레이 + 네이비/골드 프레임으로 뜸 (배틀 보드는 dim 아래로 어두워짐, 아트 풀스크린 아님)
- [ ] 봇 리스트 → 서버 랭킹으로 교체, 본인 행 골드 강조 + 서버 점수 일치
- [ ] TOP3 배지 금/은/동, 미배정 슬롯 `WAITING...` 회색
- [ ] RESTART 하단 고정 — 리스트와 겹침 없음, 탭 시 재시작 정상
- [ ] 게스트 스킵: 봇 리스트 유지(교체 없음)
- [ ] DEFEAT: 헤더 탭 붉은색(`defeatColor`)
- [ ] `read_console` 에러 0

확인: 2026-07-08 — 인게임 1차(사용자 스크린샷): 패널/행/배지/RESTART 하단 고정/DEFEAT 붉은 탭/서버 랭킹 교체 렌더 확인. 배경만 풀스크린 아트 → dim 오버레이로 번복. dim 팝업은 프리뷰 하네스 재캡처로 확인, 사용자 마무리 승인.
