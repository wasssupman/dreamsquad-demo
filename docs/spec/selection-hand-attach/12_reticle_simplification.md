# 12 — 리티클 간소화 (선택 모드 콜아웃 생략)

> 추가 2026-07-30 (사용자 결정). unit 11 선행 — 패널이 이름을 나르기 시작한 뒤에 지운다.

## 목적

선택 리티클은 **"이 유닛이 대상"만** 말한다. 이름과 부착 개수를 나르던 콜아웃은 패널(unit 11)이
같은 정보를 더 크게 나르므로 중복이다. 선택 모드에서만 콜아웃을 생략하면 리티클 위 겹침이
통째로 사라진다.

## 변경 대상

- `Assets/_Project/Scripts/UI/Dreamcatcher/DreamcatcherFocusPresenter.cs`

## 구현

콜아웃 갱신부(`_callout.position = p` 블록)의 표시 조건에 **`AimKind` 분기**를 넣는다:

- `AimKind.Selected` → 콜아웃 **비표시**(`_calloutTarget = 0`). 리티클 프레임·링은 그대로.
- 그 외(카드 조준 / `EnemyMark` 등) → **현행 그대로**.

**조준 콜아웃은 지우지 않는다.** 그건 손가락에 가린 대상의 정체를 알리는 다른 역할이다
(dreamcatcher-attach-lockon: "콜아웃이 손가락 밖 정체 주신호"). 선택은 손가락이 이미 떠난
상태라 그 역할이 없다 — 두 경우를 한 규칙으로 묶지 말 것.

주의:

- `AimKind.Selected` 는 `BeginSelection` 이 세운다. 분기는 **표시 단계**에 두고 콜아웃 텍스트
  갱신 로직 자체는 건드리지 않는다 — 조준 경로가 같은 코드를 계속 탄다.
- `_calloutTarget = 0` 으로 두면 기존 페이드가 그대로 돌아 사라진다. 노드를 비활성화하거나
  생성을 건너뛰지 말 것(조준으로 전환될 때 되살릴 경로가 없어진다).
- 리티클 프레임의 크기·펄스·링은 **불변**이다. 이 unit 은 콜아웃 하나만 만진다.

## 완료 기준

- [ ] compile 클린
- [ ] Play: 유닛 선택 → 리티클 프레임만 뜨고 **콜아웃 없음**, 이름은 좌측 패널에서 읽힌다
- [ ] Play: 선택 중 카드를 끌어 다른 유닛 조준 → **콜아웃이 정상 등장**(이름 + N/3)
- [ ] Play: 조준 취소 → 콜아웃이 사라지고 선택 리티클이 재주장된다(unit 4 경로 무회귀)
- [ ] Play: 적 표식 카드 조준 → 콜아웃 문안("표식 가능" 등) 정상
- [ ] Play: 선택 → 조준 → 커밋 → 선택 복귀 전 구간에서 콜아웃 잔상 없음
