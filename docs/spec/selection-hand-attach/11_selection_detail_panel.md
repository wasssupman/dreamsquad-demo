# 11 — 선택 상세 패널 재설계 (좌측 고정 도킹 + 스탯 + 델타)

> 추가 2026-07-30 (사용자 결정). 시안: 대화 중 published artifact 참조. unit 10 선행 필수.

## 목적

유닛 옆을 따라다니며 리티클을 가리던 `460×296` 부착 패널을 **화면 좌측 고정 도킹**으로 옮기고,
실효 스탯 3종 + 델타 표기를 얹는다. 앵커 추종을 버리는 것이 요점 — 그래야 초점 침범이
0 이 된다(현행은 콜아웃 87px + 리티클 20px 침범이 기하학적으로 확정이었다).

## 변경 대상

- `Assets/_Project/Scripts/UI/Dreamcatcher/DcInspectPanelView.cs`
- `Assets/_Project/Scripts/UI/Dreamcatcher/DcInspectController.cs` — readout 전달 + 표시 조건

## 구현

### A. 배치 — 앵커 추종 제거

`Follow()`(매 프레임 `WorldToScreenPoint` + 좌우 플립 + 세로 클램프)를 **삭제**하고 safe-area
좌측 고정 앵커로 바꾼다. `LateUpdate` 자체가 불필요해진다(카메라 포즈 의존이 사라짐).

- 앵커 좌상단, `x = 24`(MenuButton 과 같은 좌측 정렬), `y` 는 MenuButton 아래 `120` 부터.
- 폭 `360`, 높이는 내용 기반. 실측 가용 세로 대역은 **730px**(MenuButton 아래 ~ 트레이 위).
- 세로로 세우는 것은 의도다 — 좌측 대역은 세로로 열려 있고 가로로 좁다. 보드를 가로로
  잠식하지 않으면서 스탯·부착이 한 열로 정렬돼 훑기 쉬워진다.
- 수치는 전부 `[SerializeField]`(제약 6).

### B. 내용

1. **헤더** — 포트레이트 + 유닛 이름 (콜아웃이 나르던 이름이 여기로 온다 — unit 12 의 근거)
2. **스탯 3행** — 체력(현재/최대 + 게이지) · 공격력 · 공격속도. 값은 `UnitStatReadout`.
3. **부착 목록** — 아이콘 + 이름 + 종류 + **효과 설명**(rev 2026-07-30 사용자 결정).

### B-1. 폰트는 크게 (rev 2026-07-30 사용자 결정)

**플레이어층에 40대가 포함된다.** 모바일에서 작은 글자는 그냥 안 읽힌다. 초판 크기(이름 30 /
스탯 라벨 21 / 값 26 / 설명 17)를 전면 상향하고, 값을 **전부 SerializeField 로 뺐다**(제약 6 —
읽기 편한 크기는 취향·기기 의존이라 코드 리터럴로 박으면 안 된다).

- 이름 38 · 섹션 라벨 21 · 스탯 라벨 27 · 값 34(autosize 하한 20) · 칩 23 ·
  부착 이름 27 · 종류 22 · 설명 22
- **텍스트 상자 높이는 전부 폰트에서 파생**한다(`fontSize × 1.3`). 상수로 두면 폰트를 키울 때
  글자가 잘리거나 겹친다.
- 폭 `360 → 430`: 폰트가 커진 만큼 넓혀야 설명이 덜 접힌다(**줄 수가 곧 패널 높이**다).
  좌측 대역은 비어 있어 가로는 여유가 있고 아낄 것은 세로다.
- **종류·코스트를 이름과 같은 줄 오른쪽으로** 옮겼다. 줄을 따로 쓰면 부착 3장에서 그것만으로
  ~90px 를 먹는데, 종류는 테두리 색(골드/청록)이 이미 나르는 정보다.
- `dockTop 120 → 96`(MenuButton 하단 88 바로 아래) · `sectionGap 14 → 10` · 포트레이트 84.

### C-1. 설명은 `항상 →` 만 뗀다 (rev2)

카드 문안은 `트리거 → 효과` 구조다. 부착 셀에는 **`"항상 → "` 접두만 떼고 나머지 트리거는
남긴다**. 구현은 `DreamcatcherCardText.EffectOnly` — **문안 소유는 포매터 하나다**(사본 금지,
손패 툴팁과 어긋나면 안 된다).

**rev1 은 화살표 뒤를 전부 취했다가 되돌렸다.** 조건부 카드의 뜻이 무너졌기 때문이다 —
궁지폭발 `HP 30% 이하일 때 2번째 피격마다 → 반경 1칸 피해 20` 이 `반경 1칸 피해 20` 만 남고,
시한폭탄의 `3번째 공격마다 → 피해 x2` 는 `피해 x2` 가 돼 **상시 효과처럼 읽힌다**.
"언제"가 곧 그 카드의 정체인 경우가 많다. `항상` 은 정보가 0 인 유일한 트리거라 이것만 뗀다.

- `AlwaysPrefix` 는 **생산자와 소비자가 공유하는 상수**다. 문안을 만드는 3곳이 리터럴
  `"항상 → "` 을 쓰고 있었는데, 소비자가 생기면서 어긋날 수 있어 상수로 묶었다.
- 부착 제한 줄("레인저 전용")은 계속 버린다 — 효과가 아니라 조건 표기다. 판별은 휴리스틱이
  아니라 그 줄을 만든 `AttachRequirementLine` 과 **직접 대조**한다.
- 트리거가 남아 줄이 길어지므로 `descMaxLines`(2) 말줄임에 걸리는 카드가 늘어난다.
  효과가 3개인 카드(시한폭탄)는 첫 효과만 보인다 — 전문은 손패 툴팁이 나른다.
- **줄 수 상한(`descMaxLines`, 기본 2 · 초과분 말줄임)**: 부착은 최대 3장이고 시한폭탄처럼
  효과가 3줄인 카드가 있어, 묶지 않으면 패널이 트레이까지 자란다(상한 없이 실측 717px).
  행 높이는 측정 기반이라 카드마다 다르다.

### C. 델타 칩

`ResolveDelta`(unit 10) 결과로 그린다.

- 상승 = 골드 `#FFD159` / 하락 = 코랄 `#FF7A6B` — 게임의 기존 색 언어 그대로.
- **sign 0 이면 칩을 그리지 않는다.** 항상 `▲0` 을 띄우면 노이즈가 되고, 변화가 있을 때만
  눈에 들어와야 부착의 피드백 루프가 닫힌다.

### D. 갱신 주기

- **기본값은 선택 시 1회 캐시** — SO 는 전투 중 바뀌지 않는다.
- **실효값은 매 프레임 갱신.** 대상이 1 엔티티라 비용이 무시할 만하고(`TickSelectionAnchor` 가
  이미 매 프레임 앵커를 조회한다), HP 가 뚝뚝 끊기지 않는다.
- `TryGetUnitStatReadout` 이 `false` 면 그 프레임 스탯 행만 생략한다(패널은 유지) — 사망은
  unit 1 의 앵커 liveness 가 이미 닫는다.

### E. 표시 조건 변경 (기존 계약 개정)

지금은 `_cards.Count > 0` 일 때만 `Show`, 아니면 `Hide`("빈 상태 UI 는 만들지 않는다 — 없는 게
정직하다"). **스탯이 생기면서 부착 0장이어도 보여줄 것이 있다** → 선택되면 항상 띄우고,
부착 목록 섹션만 0장일 때 접는다. 그 주석은 이 unit 에서 개정한다.
