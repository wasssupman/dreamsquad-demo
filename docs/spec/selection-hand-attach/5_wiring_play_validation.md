## 구현

- 배선 확인: 이 spec 은 **신규 SerializeField 씬 배선을 요구하지 않는다** — 새 참조가
  생겼다면 설계 위반이므로 되돌린다. (catcher/움찔 노브는 런타임 생성 컴포넌트의 SerializeField
  기본값 — 씬 배선 아님.)
- Play e2e 시나리오(에디터 → 실기기 스모크):
  1. 유닛 탭 → 줌+리티클+패널+플립북+손패 딜인 동시 등장(Pulse 없음)
  2. 카드 탭 즉발 → 부착·재딜인·손패 유지 → 다른 유닛 탭 → 선택 전환 → 다시 탭 즉발
     (연속 부착 흐름 — 이 feature 의 핵심 체감)
  3. 카드 D&D 로 제3 유닛 부착 → 리티클 재주장 확인
  4. 빈 보드 탭 → 전부 해제 → **침강 중 즉시 재선택**(unit 1 래치) / 재탭 토글 / **각성 버튼 탭
     → 손패+선택 동시 해제**(unit 9 개정 — 원문은 "손패만 닫힘 → 리티클 생존" 이었다) 각 1회
  5. 사용 가능 0장 자동 닫힘 → **선택도 함께 해제**(unit 8 개정 — 원문은 "선택·리티클 유지 →
     게이지 회복 → 항아리 재오픈 → 즉발 재개" 였다). 게이지 회복 후 항아리 오픈은 무선택 모드
  6. 이동모드 진입 → 손패+선택 해제 → 이동 커밋 정상 · **이동모드 중 항아리 오픈 → 목적지
     지정 동작**(unit 2 C)
  7. 포탈 카드: 선택 중 입구/출구 커밋 → **출구 릴리즈가 선택을 안 건드림**(H1) + 손패 유지 +
     리티클 복귀
  8. ActiveTile 카드: 선택 중 드래그 → 조준 중 줌 해제(M4) → 커밋/취소 후 줌 복귀
  9. **부착 0장 선택 유닛 사망** → 선택·손패·슬로모 전부 해제(M3)
  10. 보드 스와이프(>임계) → 탭 오인 없음(M2)
  11. 페이즈 이탈(Result) → 전부 강제 해제, lease 누수 없음(콘솔 0)
  12. 첫 세션 튜토리얼 경로: 선택 기인 오픈이 `HandOpened` 원샷 힌트를 소진하는지 확인만
      (문안 개정은 후속 후보 — 기록용)
- **카메라 체감**: 인스펙트 줌 + 손패 헤드룸 동시(줌인+피치) 과다 여부. 과하면 config 노브
  (`inspectDolly`/`handHeadroomPitchDeg`) 튜닝만 — 코드 분기 금지(계약 9).
- **원격 검증 폴백의 한계(critic L7)**: 이 spec 의 핵심 결함 축은 **EventSystem 클릭의 프레임
  순서**(H1/M1)인데 PlayMode 테스트는 EventSystem 경유 클릭을 재현하지 못한다 — reflection
  구동 폴백(`remote-play-verification-playmode-tests`)은 상태 머신(게이트/래치/수명)까지만
  믿고, **탭/클릭 계열 판정은 반드시 실기기 또는 에디터 실포인터로** 검증한다.
