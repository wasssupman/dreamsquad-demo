# instinct-content — 본능이 판에 선다 (거점 시스템의 첫 라이브 콘텐츠)

> ## 목표 3줄
>
> 1. **battle-structures 가 만든 본능(3×3 공격 거점)을 라이브 맵에 처음 올린다** — 기계만 있고 콘텐츠 0인 상태의 해소.
> 2. **저작 수치 모순을 정식 SO 로 해소한다** — 배치 배제 여유 4 vs 시험용 사거리 4 = 아무도 못 쏘는 포탑(battle-structures unit 11 발견).
> 3. Coil 동쪽에 1기 쇼케이스 — «동쪽 절반은 본능의 사정권. 서반구에서 싸우거나, 장거리로 부수거나.»

상태: **작성됨 2026-08-12** · unit 0 진행

## 결정 (착수 시 확정분)

- **맵은 Zig 가 아니라 Coil** — A안 제안은 Zig 였으나 실측 결과 **3×3 footprint + 9×9 배제가 들어갈 자리가 없다**(능선 1줄·어깨 2×1·고개 위는 통행 차단이라 갈래가 죽는다). Coil 동쪽 포켓(x10..11, y3..8)이 적지다.
- **사거리 5** — 배제 여유가 체비셰프 4라 합법 배치는 거리 5부터. 방어 사거리 지도(Artillery 7·Sniper 6·Cannon/BombMan 5)와 맞물려: **5거리 = 링에서 맞대결 · 6~7거리 = 안전 포킹 · 그 외 = 드림캐쳐**. 시험용 SO(사거리 4)의 «못 쏘는 포탑» 모순 해소.
- **배치 배제는 정적**(맵 빌드 시 CloseCellLayers) — 본능을 부숴도 배치 구역은 안 열린다. 이번 정체성은 «파괴 = 사격 위협 제거»까지. 동적 해제는 후속 후보.
