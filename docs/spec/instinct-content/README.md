> 1. **battle-structures 가 만든 본능(3×3 공격 거점)을 라이브 맵에 처음 올린다** — 기계만 있고 콘텐츠 0인 상태의 해소.

> 3. Coil 동쪽에 1기 쇼케이스 — «동쪽 절반은 본능의 사정권. 서반구에서 싸우거나, 장거리로 부수거나.»

## 결정 (착수 시 확정분)

- **맵은 Zig 가 아니라 Coil** — A안 제안은 Zig 였으나 실측 결과 **3×3 footprint + 9×9 배제가 들어갈 자리가 없다**(능선 1줄·어깨 2×1·고개 위는 통행 차단이라 갈래가 죽는다). Coil 동쪽 포켓(x10..11, y3..8)이 적지다.
- **사거리 5** — 배제 여유가 체비셰프 4라 합법 배치는 거리 5부터. 방어 사거리 지도(Artillery 7·Sniper 6·Cannon/BombMan 5)와 맞물려: **5거리 = 링에서 맞대결 · 6~7거리 = 안전 포킹 · 그 외 = 드림캐쳐**. 시험용 SO(사거리 4)의 «못 쏘는 포탑» 모순 해소.
- ~~배치 배제는 정적~~ → **rev(사용자 결정 2026-08-12): 본능 주변 배치 배제 폐지**(`HostileInstinctPlacementPadding` 3→0, 기계는 유지). 금지는 footprint 3×3(건물 자리)뿐. «링 결투» 구배는 «인접 러시 vs 반격» 트레이드로 대체 — 사거리 5는 이제 «광장 절반을 덮는 위협 범위»로서 유지.
- **프랍 스케일 knob 신설**(`StructureData.viewScale`, 제약 6) — 시험용 프리팹이 과대(사용자 지적), 파수 본능 0.4 저작.
- **본능은 벽이 아니다 — 통행·배치 둘 다 안 막는다**(사용자 결정 2026-08-12, unit 1): 지시는 «배치 불가»였고 «통행 불가»는 아니었다. 배제 여유(0으로 폐지)에 이어 **분기 자체를 삭제** — 본능은 자기 3×3 만 차지한다. 뿌리는 «다중 셀 점유»와 «통행 차단»이 `BlockingHazardCellsBuffer` 하나에 겸직한 것이라, 축을 버퍼(점유)/컴포넌트(차단)로 가른다. 계약 12 폐기.
