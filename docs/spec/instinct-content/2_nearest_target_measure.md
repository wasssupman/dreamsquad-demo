# unit 2 — 「가까운 거점부터 팬다」 가 저절로 되는지 실측

## 목적

사용자 질문: **«오른쪽 끝에서 스폰된 적이 가까운 본능을 먼저 패고, 본능이 다 부서지면
마음을 패는 구조가 쉽게 가능한가?»** 그리고 이어진 판단: **«별도의 웨이포인트가 필요한 게
아니라고 생각. 마음 1 + 본능 N(2~3)이다.»**

이 unit 의 결론은 «기능을 만든다» 가 아니라 **«만들 필요가 있는지 잰다»** 다.

## 왜 저절로 될 수 있나

두 사실이 이미 성립한다:

1. **타게팅은 이미 거리순뿐이다.** `AttackSystem` 은 마스크에 든 후보를 `d2 < bestSq` 로만
   고른다 — 거점이라고 우대하거나 미루는 코드가 없다(battle-structures unit 0 계약).
   마음이 우선처럼 보인 건 **타게팅이 아니라 이동** 때문이다: 흐름장이 늘 골로 흐른다.
2. **unit 1 이후 본능은 통행을 안 막는다.** 그래서 적의 골 직행 경로가 본능 셀을
   **지나가거나 스쳐** 사거리에 들어온다. 근접 적(사거리 1)도 3×3 의 바깥 칸에 인접하면
   닿는다 — 다중 셀 거리(`DistanceSqToTarget`)가 이미 그렇게 잰다.

즉 지형이 본능을 경로 위/옆에 놓기만 하면 «가까운 것부터» 는 **창발**한다.
웨이포인트도, 목적지 선택 기계도 없이.

## 실측 (Coil + Duel)

| 잴 것 | 방법 | 기대 |
|---|---|---|
| 적이 본능 셀을 **통과**하는가 | 통과 셀 로그 | footprint 9칸 중 1+ |
| 지나가며 **때리는가** | 본능 피격 카운터 | 0 아님 |
| 본능 파괴 후 **마음으로 가는가** | 파괴 시각 vs 골 도달 시각 | 파괴 후 진행 재개 |
| **경로 밖 본능**을 무시하는가 | 경로에서 먼 본능의 피격 카운터 | **여기서 0 이 나오면 unit 3 승격** |

Duel 은 마음 1 + 본능 2 의 표준 형태다 — 중앙 통로(y5)가 양측 본능 footprint(y2~4·y7~9)와
한 칸 인접이라 근접 적도 사거리에 든다. 이 기하가 «저절로» 의 전제다.

**대조군 필수**: 이전 실측 사고(마음사냥꾼 도발 0회가 사실은 배치 미활성)를 되풀이하지
않는다. 본능 없는 맵에서 같은 카운터가 0 인지 먼저 확인하고 잰다.

## 분기

- **저절로 된다** → 기능을 만들지 않는다. 이 unit 이 결론이고 다음은 handoff.
- **경로 밖 본능을 무시한다** → unit 3 승격. 규칙은 사용자가 이미 답했다:
  **«스폰 시 1회 → 부서지면 재선정»**. 기계는 흐름장 슬롯이 이미 N 목적지를 지원한다
  (`FlowFieldSingleton.destCells[]` · `SlotFor(destCell, unitLayers)`). 남는 함정은
  **죽은 목적지**(파괴된 본능으로 계속 걸어감) — 붕괴 골 라우팅과 같은 계열의 결함이라
  재선정이 그 답이다.
