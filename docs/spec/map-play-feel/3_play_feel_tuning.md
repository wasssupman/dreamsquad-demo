# 2. Play 체감 검증 + 리터치

## 목적

Hook 이 실제로 "다른 맵"으로 느껴지는지, 그리고 15폭 축소본 5장이 회귀 없이 도는지 확인한다. 느껴지지 않으면 **레인 길이와 명당 텍스처** 두 노브로 조정한다. 이 spec 의 검증 질문에 답하는 단계.

## 확인 항목 (사용자 Play)

**Hook — 이 spec 의 본론**

1. **초반 압박이 러시 레인에 쏠리는가** — 1웨이브에서 러시(우측) 적이 먼저 도착해 "여기부터 막아야 한다"는 결정이 강제되는가. 두 레인에 고르게 까는 기존 습관이 손해가 되는가.
2. **롱 레인의 유예가 체감되는가** — 좌측 적이 오는 동안 경제/배치를 정비할 시간이 실제로 있는가. 반대로 너무 길어 지루하지 않은가.
3. **합류점이 주인공인가** — 공유 꼬리(`(9,4)~(9,0)`) 근처 자리가 "계속 쏘는 자리"로 인지되는가. 웨이브가 겹치는 중반 이후 꼬리에 밀도가 생기는가.
4. **다른 맵과 다르게 플레이되는가** — Hook 한 판과 Serpent/Twin 한 판이 서로 다른 배치 순서를 만드는가, 아니면 결국 같은 손버릇으로 끝나는가. **이게 최종 판정 질문이다.**

**축소본 5장 — 회귀 확인**

5. **가독성** — 15폭에서 유닛 크기·레인 구분이 기존 20폭보다 나은가. 이 축소의 유일한 목적이다.
6. **난이도 무드리프트** — 레인 길이를 ±10% 안에 맞췄으므로 체감 난이도가 예전과 비슷해야 한다. 눈에 띄게 어려워졌으면 레인이 더 짧아진 맵(Spiral −10%)부터 의심한다.
7. **Serpent 형태 변경 수용 여부** — 직선 2줄에서 되돌아오는 훅으로 바뀌고 골이 우측 끝→중앙으로 이동했다(레인 길이 보존 때문). 괜찮은지 판단.

## 튜닝 노브 (이 순서로만)

- **레인 비율** (Hook) — 롱 레인 길이. S2 를 좌측 세로(`col x=1`)에서 아래로 내리면 1칸당 −1. 현재 1.92. 너무 극단이면 1.5까지, 밋밋하면 2.4까지.
- **공유 꼬리 길이** (Hook) — M 을 스파인 위/아래로 옮긴다. 길수록 "전 트래픽 커버" 자리의 가치가 커지고 레인 고유 구간은 짧아진다. 현재 5칸.
- **명당 마스킹** — 너무 자명한 자리를 Deco 로 덮는다.
- **배치칸 희소성** — Hook 의 Place 42 는 여유 있는 편. 압박을 원하면 롱 레인 초반부터 줄인다.

> 레이아웃 실루엣은 노브가 아니다. 실루엣을 다시 그릴 거면 그건 유닛 3(변형)이다.

## 판정

- **체감됨** → 완료 처리, 유닛 3(변형 1~2장) 진행 여부 판단.
- **체감 안 됨** → 항목 1~4 중 어디가 죽었는지 특정해 기록한다. 비대칭이 안 느껴지면 레인 비율을, 합류가 안 느껴지면 꼬리 길이를 먼저 올린다. 두 노브를 다 밀었는데도 같으면 **비대칭·합류가 이 게임에서 약한 축**이라는 결론이므로 그대로 적고 다른 축(웨이브 리듬·레인 분리 거리)으로 넘어간다.
