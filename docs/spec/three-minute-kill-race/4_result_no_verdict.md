# 4 — 결과 화면: 승패 표기 없음 · 중복 줄 통합

## 목적

결과 화면에서 **승/패라는 말과 그 색을 지우고**(unit 0 이 이미 입구를 하나로 합쳤다),
unit 1 이 만든 **같은 숫자 두 줄**을 정리한다.

`총점` 과 `처치 N기` 는 이제 **정확히 같은 수**다. 두 줄로 두면 화면이 «다른 두 지표»를
약속하는데 실제로는 같은 값이라, 읽는 사람이 차이를 찾느라 시간을 쓴다.

## 변경 대상

- `UI/ResultScreen.cs` — 스탯 3줄 → 2줄, 히어로 숫자에 단위 부여

## 구현

**1. 「처치」 줄을 뺀다.** 히어로 숫자가 곧 처치 수이므로 아래에서 반복하지 않는다.
남는 두 줄은 **총점이 아닌 것들**이다 — 얼마나 버텼고 어디까지 갔나:

```
        47          ← 히어로. 잡은 마리 수 = 총점 = 서버에 올라간 수
   남은 마음   12 / 20 (60%)
   도달 웨이브  14
```

**2. 히어로 숫자에 단위를 붙인다.** 라벨이 `결과` 하나뿐이라 `47` 이 무엇인지 화면에서
안 읽힌다. 숫자 뒤에 작게 `기` 를 붙여 **「몇 마리 잡았나」** 로 곧장 읽히게 한다.
`점` 이 아니라 `기` 인 이유: 이 판의 규칙이 «1킬 1점» 이라 마리 수가 곧 점수이고,
플레이어가 세는 단위는 마리다.

**3. 「남은 안정도」 → 「남은 마음」.** 「안정도」는 게이지가 있던 시절의 계기판 어휘다.
게이지가 사라졌으니(unit 2) 화면에는 게임 언어로 남긴다.
