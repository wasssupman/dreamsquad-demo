# 3. 공성 3덱 시드 재선정 + 본편 다양성 술어

## 목적

laneCount 1→2(siege-lane-spawn unit 0)로 공성 덱 편성이 재추첨된 중간 상태에 새 baseline 을
박는다. 시드가 고정이라 «본편(w1~15) 다양성»은 확률이 아니라 **검색 가능한 술어**다 —
조건을 만족하는 시드를 골라 pin 한다.

## 변경 대상

- 공성 3덱 `waveSeed`: Duel 20260841→**20260868** · Ford 20260842→**20260880** ·
  Isle 20260843→**20260890** (기존 값은 라이브 시드 재사용이라 어차피 떼는 게 맞았다)
- `WaveConceptAuthoringTests` — 본편 다양성 술어 + 시퀀스 상이 pin + 시드 유일성 확장 +
  시드 스캐너(`Scan_SiegeSeedCandidates`, Explicit)

## 구현

- **오프라인 포트는 시드 선정에 못 쓴다(실측 교훈)**: `PickConcept` 룰렛의 float32 누적
  경계에서 시드별로 실제 생성기와 갈린다 — 포트로 고른 첫 후보 3개 중 2개가 실 생성기
  술어에서 빨강이었다. 그래서 스캐너를 **실제 생성기 위에** 두고(Explicit 테스트) 그
  출력에서 선정했다. 향후 재선정도 반드시 스캐너로.
- 선정 시드는 셋 다 w1~15 에 **컨셉 5종 전부** 등장(실 생성기 블록: Duel 평소>공습>벌떼>
  원거리>중장 / Ford 평소>공습>원거리>벌떼>중장 / Isle 평소>벌떼>중장>공습>원거리). 단
  **pin 은 spec 술어(4종+ 및 공습 포함)로 건다** — 5 를 못박으면 풀/컨셉 후속 편집이 이유
  없이 깨진다(밸런스 리터럴 금지 규율).
- 시퀀스 pairwise 상이 + 전 덱 시드 유일성(기존 유일성 pin 에 공성 3덱 편입).

## 완료 기준

- 결정론 pin(같은 시드 3회 signature 동일)은 기존 테스트가 자동 커버
