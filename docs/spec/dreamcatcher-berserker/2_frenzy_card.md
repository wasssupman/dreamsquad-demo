# 2 — 광란 카드

## 목적

게임에서 이렇게 보인다: **공격할 때마다 점점 빨라진다. 손을 멈추면 통째로 식는다.**
파도가 몰아치는 동안 혼자 가속하다가, 파도가 끝나면 원래 속도로 떨어진다.

## 구현

**저작값 (초안 — 밸런스는 시트에서 최종 결정)**

| 칸 | 값 | 뜻 |
|---|---|---|
| 트리거 | 공격 N회, 주기 **1** | 공격이 성사될 때마다 |
| payload | 자기 버프 · 스탯 = 공격속도 | |
| 배율 | **8** | 1중첩당 +8% |
| 최대 중첩(`tileRange`) | **10** | 상한 +80% |
| 지속 | **4** | 마지막 공격 후 4초면 통째로 식음 |

부착 제한은 **걸지 않는다**. 컨셉은 광전사지만 제한을 걸 근거가 밸런스뿐이고, 실제로
누구에게 강한지는 붙여봐야 안다. 근접 전용으로 좁히는 건 체감 후 결정한다.

**문안.** 자기 버프의 기존 문안에 「최대 중첩」이 없다. 최대 중첩이 0 이면 지금 문장
그대로, >0 이면 중첩과 상한을 말하게 한다. 수치는 문자열에 박지 말고 에셋에서 읽을 것
(제약 6) — 시트가 값을 덮으면 문안도 같이 따라가야 한다.

목표 문장: `공격마다 → 공격속도 +8% 중첩 (최대 10중첩 · 4초)`

## ⚠ 시트가 이 값들을 소유한다

`DcMechanics` 탭이 발동 주기·배율·**최대 중첩(`tileRange`)**·지속을 **로비 진입마다
덮어쓴다.** 에셋만 고치면 되돌아간다(content-5 부메랑에서 실제로 겪었고, 만든 적 없는
행이 이미 시트에 있었다). 임포터는 dry-run 이 없어 검증은 **읽기 전용 curl 로만** 한다.

**2026-08-17 확인**: `DcCards` 50행에 `frenzy` 는 **없다** → 지금은 에셋 값으로 동작하고
`visible` 도 에셋 기본값 1 이다.

**⚠ `visible 0` 은 「일단 안 쓴다」는 뜻이다**(사용자 규칙). 자동 push 로 `frenzy` 행이
생기면 그 칸이 **1 인지 확인**한다 — 0 이면 만들어놓고 덱에 안 뜬다. 빈 칸은 해제가
아니라 「그대로 둠」이라, 켜려면 1 을 **명시**해야 한다.
