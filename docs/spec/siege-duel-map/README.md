# siege-duel-map — 듀얼 아레나 (공성 모드의 첫 라이브 맵)

> ## 목표 3줄
>
> 1. **공성 모드가 처음으로 판에 선다** — 적 마음 1개 저작 = 모드 파생(battle-structures unit 6), 그 셀이 스폰지점.
> 2. **클래시 로얄 문법의 대치 구도** — 내 마음 ↔ 적 마음 좌우 미러, 각 진영 본능 1기가 서로 다른 레인을 감제.
> 3. **방어측 본능의 첫 라이브** — «미래의 방어 본능도 코드 변경 0» (파이프라인 맵 주장)의 검증.

상태: **작성됨 2026-08-12** · unit 0 진행

## 구조 rev 3 — 클래시 로얄 하프코트 (15×12)

> rev 1(링 복도·테두리 배치)·rev 2(포켓 7칸)는 사용자 리뷰로 기각 — «맵에 다른 유닛도 배치
> 가능하게 마스킹 처리 / 맵 모양이 CR 과 전혀 다르다». rev 3 은 **오픈 필드 + 중앙 강 + 다리 2개**.

```
y11 ▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒          ▒=테두리(Deco) ~=강(Env) ·=오픈필드(Walk)
y10 ▒······~······▒          내 진영 x1..6 / 강 x7 / 적 진영 x8..13
y9  ▒······█······▒          █=다리(Walk)
y8  ▒··╋···█···╋··▒          ╋=본능 3×3 중심 (4,8)(10,8)
y7  ▒·············▒
y6  ▒·············▒
y5  ▒·♥··········♥▒          ♥ 내 마음(2,5) ↔ 적 마음(12,5)=스폰
y4  ▒·············▒
y3  ▒··╋···█···╋··▒          (4,3)(10,3)
y2  ▒······█······▒
y1  ▒······~······▒
y0  ▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒
```

- **오픈 필드**: 복도가 사라졌다. 양 진영 전체가 Walk — 배치·전투가 넓은 면에서 일어난다.
- **중앙 강 + 다리 2개**(y2..3 / y8..9) — CR 의 레인 병목. 좌우 미러 축 x=7.
- **본능 4기 = 프린세스 타워**: 내 (4,3)·(4,8) / 적 (10,3)·(10,8). 3×3 이 통행을 막아 다리
  건너온 적이 마음까지 **중앙 통로(y5~6)로 몰린다**. 마음 = 킹 타워 위치(중앙 후방).
- **배치 = 내 진영 전체 60칸**(계약 핵심):
  `placeMask` 를 **손저작**해 내 진영 Walk 칸에 `Ground|Path` 를 **둘 다** 연다.
  placement-mask spec 의 «타일 종류와 직교» 를 처음으로 실제 사용한 사례.
  - ⚠ **이걸 안 하면 가디언은 아예 못 놓는다** — `Defender_Guardian.placementLayers = Path`(2)
    이고 나머지 25종은 Ground(1). Place 타일(Ground 만)로 만든 포켓은 **가디언 배치 불가**였다(rev 2 결함).
  - 적 진영·다리·강·테두리 = `Path|Air`(통행만) 또는 `Air` → 배치 0칸.

### ⚠ 저작 함정 (실제로 밟음)

`MapDocument_Serpent` 계열에는 **`placeMask` 필드 자체가 없다**(파생 폴백). 복사본에 정규식
치환으로 마스크를 쓰면 **매치 실패 → 조용히 무시**되고 파생값(Walk→Path 만)이 그대로 남는다.
증상은 «Ground 배치칸 0» — 필드가 없으면 **삽입**해야 한다.

## 후속 후보

- **라이브 풀 편입** [S] — 시드 맵 배정 재편 동반, 사용자 결정.
- **레인 갈래 저작** [M] — 공성 스폰 1개는 필드가 한 레인만 고른다. 상·하 레인 분산은 웨이포인트 경로 저작(지상 경로 적) 또는 스폰 분산 규칙.
- **적 본능의 마음 사냥꾼 상호작용** 등 emergent 확인.
- **본능 프랍 진영 구분** [S] — 4기가 전부 같은 빨간 시험 프랍이라 화면에서 아군/적이 구분 안 된다. viewPrefab 분리 또는 진영 틴트. **rev 3 에서 4기가 되며 체감 우선순위가 올라갔다.**
- **강 시각 표현** [S] — Env 타일이 렌더에서 빈 공간으로 나온다(구멍처럼 보임). 물 타일/프랍이 필요하다. `traversal-layers` §6 의 물타일 3줄과 합류 가능.
