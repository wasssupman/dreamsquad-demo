# 1. 공성 맵 가족 — 여울목·섬 (제작 철학의 두 변주)

## 목적

Duel 하나였던 공성 모드에 맵 2장을 더한다. **좌표를 베끼지 않는다** — Duel 에서 제작 철학을 뽑아 원칙으로 고정하고, 그 원칙 위에서 **중앙 구조만** 다르게 만든다.

## Duel 에서 뽑은 제작 철학 7개

데이터 실측으로 뽑았고, `SiegeMap_KeepsDuelDesignPhilosophy` 가 이 일곱을 회귀선으로 지킨다.

| # | 원칙 | 이유 |
|---|---|---|
| 1 | **적 마음 정확히 1기** | 그 존재가 곧 공성 모드 파생(`battle-structures` unit 6) |
| 2 | **`spawns` 저작 0** | 적 마음 셀이 스폰이다. 저작하면 파생이 덮어 «저작해도 아무 일이 없는 필드»가 된다 |
| 3 | **마음이 좌우 미러** (`goal.x + heart.x == W-1`, 같은 행) | 공성은 HP 레이스라 비대칭이면 판정이 불공평해진다 |
| 4 | **배치는 내 진영만** (`placeMask` 손저작, 미러축 왼쪽 0 위반) | 전선이 지형에 고정된다. 파생 폴백은 `Walk→Path` 만 열어 Ground 배치칸이 0 이 되므로 **손저작 필수** |
| 5 | **강(`Env`)이 지상을 가른다** | `Derive(Env)` = `Air` 만. 「떠 있는 적은 강을 무시한다」가 규칙으로 읽힌다 |
| 6 | **21×12** | 카메라 불변 상한(fov 36 실측) |
| 7 | **적 마음 → 골 연결** | `MapConnectivity.AllSpawnsReachGoal` 로 판정(재구현 금지) |

**철학의 핵심은 「총 통행 폭을 좁게 두고 그 폭을 어떻게 분포시키냐」다.** Duel 은 지상 통행 5줄을 세 곳(y=2·3 / y=5 / y=8·9)에 쪼갰다. 두 신규 맵은 그 분포만 바꾼다.

## 세 맵의 대조

| | **Duel** (기존) | **Ford** 여울목 | **Isle** 섬 |
|---|---|---|---|
| 강 | x=10 (1칸) | x=9~11 (**3칸**) | x=8·x=12 (**2줄기**) |
| 지상 통행 | 3곳 × 총 5줄 | **1곳** × 4줄 12칸 | 건널목 2곳 × 2줄기 |
| 경로 수 | 3 | **1** | **4** (2×2 조합) |
| 결정축 | 어느 다리로 오나 | **언제 얼마나 막나** | 짧고 위험 vs 길고 안전 |
| 배치칸 | 90 | 80 | 70 |
| Walk 칸 | 184 | 172 | 174 |
| 보스 | 짱쎈 | 마메모 | 나이트메어 |

### Ford — 전선 1곳

```
y10 ▒········~~~········▒     ~ 강(지상 불가·비행 통과)
y 8 ▒····╋···~~~···╋····▒     ╋ 본능 (5,8)(15,8)
y 7 ▒···················▒  ┐
y 5 ▒·♥·······w·······♥·▒  │ 여울 y=4~7 (x=9~11)
y 4 ▒···················▒  ┘ = 유일한 건널목
y 3 ▒····╋···~~~···╋····▒     ╋ 본능 (5,3)(15,3)
```

통행 폭을 한 곳에 모은다. 「어느 레인으로 오나」 판단이 사라지고 **「언제 얼마나 막나」**로 바뀐다. 벌떼 컨셉이 한 점에 쏟아져 처리량 압박이 커지고, 본능 4기가 여울을 **교차 감제**해 건너는 동안 계속 맞는다.

### Isle — 중앙 점거

```
y10 ▒·······~···~·······▒     강 2줄기 x=8·x=12
y 8 ▒····╋··~···~··╋····▒
y 7 ▒···················▒     ← 건널목 (양 줄기 동시 개방)
y 5 ▒·♥·····~·w·~·····♥·▒     중앙 섬 x=9~11
y 4 ▒···················▒     ← 건널목
y 3 ▒····╋··~···~··╋····▒
```

x=8 을 y=4/7 로 건너 섬에 들어가고, x=12 를 y=4/7 로 건너 나간다 → **경로 조합 4개**. 섬은 중립이라 배치칸이 없고, 섬을 지나는 동안 양쪽 본능 사거리에 노출된다. 「짧고 위험 vs 길고 안전」이 결정축이고, **분기 밀도가 높아 적 SO 축 경로 저작이 실제로 먹히는 첫 공성 맵**이다(README 후속 후보 「레인 갈래 저작」의 무대).

## 변경 대상

- **신규** `MapDocument_{Ford,Isle}.asset` + `.meta`
- **신규** `Deck_{Ford,Isle}.asset` + `.meta` — `Deck_Duel` 복제 + `waveSeed`·보스만 변경(세대 동일)
- `MapDocumentPool.asset` — `devEntries` 에 2장 추가 → **dev 슬롯 10(Ford)·11(Isle)**
- 테스트 2종을 3맵으로 일반화

**본편 `entries` 가 아니라 `devEntries` 다.** 본편에 넣으면 `Count` 가 6→8 이 되어 라이브 6맵의 시드·토너먼트 배정이 전부 재추첨된다.

> **2026-08-17**: 라이브 풀이 Duel 한 장이 되면서 슬롯이 밀렸다 — Ford·Isle 은 10·11 그대로지만 나머지는 전부 이동(`duel-live-focus` README 의 슬롯 표).

- **오프라인 검증** — 적 마음→골 연결 100%(Walk 전 칸 연결) · 배치칸 전부 미러축 왼쪽

  - Isle: 섬을 지나는 적을 양쪽에서 때리는 그림이 성립하는가 · 우회를 택하게 되는가
  - 강이 「비행만 건넌다」로 읽히는가(스키머가 여울/건널목을 무시하고 직진)
