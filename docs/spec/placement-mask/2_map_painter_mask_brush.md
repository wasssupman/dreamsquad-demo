# 2. Map Painter 마스크 브러시

## 목적

마스크를 손으로 저작할 수 있게 한다 — Walk 셀 위 배치 허용은 이 도구로만 만들어진다(런타임 규칙이 아니라 저작 데이터). 페인터가 마스크를 모르면 베이크가 authored 마스크를 날리므로, 이 유닛으로 저작·보존 루프를 닫는다.

## 변경 대상

- `Assets/_Project/Editor/MapPainterWindow.cs`

## 구현

1. **마스크 레이어 상태**: `bool[] _placeMask` (셀 수와 동일). 로드 시 doc.PlaceMask 채택(부재·길이 불일치면 `tiles==Place` 파생), New 시 파생 초기화.
2. **브러시**: `Tool` enum 에 `PlaceMask` 브러시 추가 — 타일 종류는 불변, 마스크만 편집. 드래그 시맨틱은 "**드래그 시작 셀의 반전값으로 set**"(같은 셀 MouseDrag 반복 이벤트 재토글 깜빡임 방지 — 기존 토글류 Spawn/Goal 이 click-only 인 이유와 동일 함정).
3. **stale mask 방지 계약**: 타일 브러시(Road/Buildable/Deco)가 셀 타입을 바꾸면 **그 셀 마스크를 파생값으로 추종**시킨다(Buildable→mask 1, Road/Deco→mask 0). 파생과 상이한 마스크는 **PlaceMask 브러시로 칠한 셀에만 생존**한다 — 안 그러면 재베이크된 맵에서 타일만 고쳐도 ① 새 Place 셀이 배치 불가로 남고 ② Deco 로 바뀐 셀이 배치 가능으로 잔존하고 ③ 커빙이 의도 없이 꺼진다(unit 1 intent 규칙). 보조로 "마스크를 파생값으로 전체 리셋" 버튼 1개.
4. **오버레이 표시**: 마스크 on 셀에 반투명 시안 테두리(하이라이트 색과 동일 계열) — 파생값과 상이한 셀은 강조색(예: 노랑)으로 구분해 "이 맵은 수동 배치판(커빙 skip)" 상태를 저작 중에 인지시킨다.
5. **베이크**: `Bake()` 의 GeneratedMap 조립부에 `placeMask` 포함 → `WriteToDocument` 경유 직렬화. 베이크 로그에 "파생값과 상이한 마스크 셀 n개" 1줄 출력(수동 배치판 여부 최종 인지). Validate 에 마스크 **에러**는 추가하지 않되(마스크는 무제약 — 빈 마스크 맵도 유효, 배치 불가 맵일 뿐), spawn/골 셀 mask=1 은 **warning** 1줄(sim 은 무영향이나 저작 실수 가능성).

## 완료 기준

- 에디터에서: Walk 셀에 마스크 칠하고 베이크 → asset 의 `placeMask` 직렬화 확인 → 창 재로드 시 왕복 보존.
- 마스크를 건드리지 않은 기존 맵 재베이크 → placeMask ≡ 파생값으로 저장되고, Play 에서 커빙 동작 불변(unit 1 의 상이-셀 없음 조건).
- 파생과 상이한 셀의 강조 오버레이가 육안 확인됨(스크린샷).
