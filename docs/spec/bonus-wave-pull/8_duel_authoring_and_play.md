- `Assets/_Project/Data/Maps/MapDocument_Duel.asset`

## 구현

1. Duel(23×10, 골 (2,4), 공성 모드 — 스폰은 적 마음에서 파생)에 보너스 포탈 **2칸**을 찍는다.

   두면 버튼이 안 뜬다(계약 8) — 정상 동작이다.
