# 7 — 도크 두 번째 알약

## 목적

보너스 당기기 버튼을 일반 알약 **바로 위**에 세로로 쌓고, 조건 충족 시에만 보이게 한다.

## 변경 대상

- `Assets/_Project/Scripts/UI/NextWaveDock.cs`
- BattleScene — 신규 SerializeField(색·간격)

## 구현

1. 같은 컴포넌트 안에 둔다. 두 알약이 **같은 자리 예산**(x ≤ 300)을 공유하므로 자리 계약이
   한 곳에 있어야 하고, 알약 빌더(모서리·립·샤인)를 그대로 재사용한다.

2. 기하: 같은 `panelOffset.x`, 같은 `pillSize.x`(256). y 는 일반 알약 위 + 간격.
   **가로 확장 금지** — 배치 트레이가 x 320~1600 을 항상 먹는다(계약 11).

3. 색은 금색과 갈린다. 금색 = 일반 당김이라는 학습을 깨지 않기 위해 다른 계열을 쓴다.
   ⚠ **신규 SerializeField 는 씬 YAML 에 없어 C# 기본값이 그대로 적용된다** — 기존 필드
   재사용 시에만 「씬에 직렬화돼 있어 안 바뀐다」 함정이 적용된다.

4. 등장/퇴장: 슬라이드 + 페이드. `BonusPullAvailable` 이 상태원이고, 도크는 매 프레임
   그것만 읽는다(도크가 임계를 다시 계산하면 두 곳이 갈린다).

5. 누르면 `bridge.TryBonusPull()` **하나만** 부른다(계약 9).
