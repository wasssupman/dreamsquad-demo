# retire-button-reach — 퇴근 버튼 도달성

> 상태: **완료 2026-08-20** — units 0~2 구현 + 사용자 Play 확인.
> 커밋 `a1a87a63`(units 0·1 + 버튼 라벨·튜토리얼 문구) · `d22bd9aa`(카드 문안·에셋).
> 사용자 발의 2026-08-19. 기능을 바꾸지 않는다. 철수라는 **같은 조작을 눌리게** 만드는 UI spec 이다.
> 인계는 [`3_handoff_summary.md`](3_handoff_summary.md).

## 검증 질문

> 판이 바쁜 와중에 유닛을 선택했을 때, 퇴근 버튼이 **눈에 먼저 들어오고**, **한 번에 눌리고**,
> **부착 카드가 몇 장이든 같은 자리에** 있는가?

## 문제 (실측)

사용자 보고: "버튼 높낮이가 작아서 터치가 잘 안 되고, 빗나가면 UI 바깥을 눌러 선택이 해제된다."

**1. 높이가 권장치의 절반이다.** 6.5인치 폰 가로에서 1920 캔버스 = 실물 약 144mm →
1 캔버스 단위 ≈ **0.075mm**.

| | 캔버스 | 실물 | 판정 |
|---|---|---|---|
| 현재 높이 60 | 60 | **4.5mm** | Apple 44pt(≈7mm)·Material 48dp(≈7.6mm) **미달** |
| 현재 폭 394 | 394 | 29.6mm | 충분 — 폭은 남는다 |

**2. 위치가 412px 표류한다.** 액션 버튼이 부착 카드 목록 **뒤에** 흐름 배치돼 있다
(`DcInspectPanelView.cs:404`). 패널 상단은 y88 고정인데 버튼만 떠다닌다.

| 부착 | 버튼 상단(화면 y) |
|---|---|
| 0장 | 423 |
| 1장 | ~549 |
| 3장 | 836 |

**3. 미스의 대가가 크다.** 패널 배경은 `raycastTarget=false`(485행 — 카드 드롭·조준 비간섭
계약)이고 **버튼 하나만 `true`**(570행). 선택 중에는 전화면 투명 캐처가 깔려 있어 버튼을
빗나간 탭은 `CloseByIntent()` 로 간다. 즉 패널 전체가 해제 구역이고 그 안에 버튼 하나가 섬이다.

> **바깥 탭 해제는 유지한다**(사용자 결정 2026-08-19) — 해제 직관이 그 자체로 가치가 있다.
> 그래서 이 spec 은 **해제를 막는 대신 미스를 줄인다.** 버튼을 크게, 자리를 고정으로.

## feature-wide 계약

1. **기능은 하나도 바뀌지 않는다.** 퇴근의 조건·연출·쿨타임·ECS 는 전부 불변. 이 spec 은
   `DcInspectPanelView` 의 레이아웃과 시각만 만진다.
2. **바깥 탭 = 해제를 유지한다.** 레이캐스트 계약(`panelBg.raycastTarget=false`)도 그대로 —
   카드 드롭·조준이 좌측 패널을 통과해야 한다.
3. **액션 슬롯은 기능 이름을 갖지 않는다.** `defender-clock-out` unit 2 계약 유지 — 뷰는
   켜짐/꺼짐과 문자열만 받고 라벨은 컨트롤러가 만든다. 아이콘도 같은 규율을 따른다.
4. **버튼 위치는 부착 상한에 흔들리지 않는다.** 부착 상한은 시트가 저작하는
   `AwakeningConfig.maxAttachPerUnit`(기본 3)이다. 버튼을 목록 **위**에 두면 상한이 4가 되든
   패널이 아래로 자랄 뿐 버튼은 그 자리다 — 칸 수를 코드에 박을 일도 없다.
5. **패널은 아래로 자라도 된다.** 선택 중에는 트레이가 접혀 사라지고 손패는 x470~1450 이라
   패널(x24~454)과 가로로 겹치지 않는다. 바닥은 트레이 상단 912 가 아니라 **화면 하단 1080**
   이다. 이 전제가 깨지면(트레이와 패널 동시 노출 경로 신설) `descMaxLines` 2→1 로 회수한다.
6. **값은 전부 `[SerializeField]`.** 매직 넘버 금지(제약 6).

## 남은 일

- **시트의 카드 `description` 갱신.** 「인수인계」·「퇴직위로금」 에셋은 옮겼지만 이 필드는
  시트가 소유한다 — 시트를 고치지 않으면 다음 로비 진입의 임포트가 「퇴근」으로 되돌리고
  `DreamcatcherCardAssetTextTests` 가 다시 빨개진다.
- **`actionIcon` 스프라이트 저작.** 비어 있어 지금은 라벨만 나온다.

## 후속 후보 (현 스코프 밖)

- **퇴근 오조작 방지(홀드 게이지 등)** — 이번엔 넣지 않는다. "빠르게 눌러야 한다"와 정면 충돌하고,
  버튼이 커지면 오탭 자체가 줄어든다. 실기기에서 잘못 퇴근시켰다는 보고가 나오면 승격.
- **UI 문안 "퇴근" → 다른 말** — 시즌 기믹 "집에 가도 되나요?"(clock-out)와 화면에서 겹친다.
  `defender-clock-out` 후속 후보에 이미 있는 항목(후보: 철수·복귀·해산).
- **손가락 이동 경로의 근본 단축** — 선택 입구는 하단 트레이 셀인데 패널은 좌측 상단이라 가로
  이동이 남는다. 좌측 고정 도크는 `selection-hand-attach` unit 11 에서 확정된 계약이라
  이 spec 에서 뒤집지 않는다. 재검토하려면 별도 spec.
