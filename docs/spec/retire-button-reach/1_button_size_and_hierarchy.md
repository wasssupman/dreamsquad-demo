# 1 — 버튼을 키우고 정보에서 떼어낸다

## 목적

두 가지를 고친다.

**터치**: 높이 60 = 실물 **4.5mm**(6.5인치 폰 가로에서 1 캔버스 단위 ≈ 0.075mm).
Apple 44pt(≈7mm)·Material 48dp(≈7.6mm) 어느 기준에도 못 미친다. 빗나가면 패널 배경
(레이캐스트 비대상)을 눌러 선택이 통째로 해제되므로 미스 1회의 대가가 "다시 누르기"가 아니라
"트레이 셀부터 다시"다.

**인지**: 지금 버튼 색은 `unitBorder` 청록인데 이건 **부착 카드 테두리와 같은 색**이다.
게다가 채움 없는 반투명 테두리라 「읽는 것」처럼 보인다. 패널에서 유일한 조작 요소가
정보와 같은 옷을 입고 있다.

## 변경 대상

- `Assets/_Project/Scripts/UI/Dreamcatcher/DcInspectPanelView.cs`
- `Assets/_Project/Scripts/UI/Dreamcatcher/DcInspectController.cs` (아이콘 전달 시)

## 구현

0. **씬의 직렬화 값도 같이 바꾼다.** `BattleScene.unity` 에 `actionButtonHeight: 60` ·
   `fontActionButton: 26` 이 이미 박혀 있어 **코드 기본값만 바꾸면 아무 일도 일어나지 않는다.**
   신설 필드(색·아이콘)는 YAML 에 없으므로 코드 기본값이 그대로 들어온다.
1. **`actionButtonHeight` 기본값 60 → 120.** 실물 9.0mm — MIT Touch Lab 의 「안정적으로
   눌리는」 구간이다. 면적 394×60(23.6k) → 394×120(47.3k), 2배.
2. **폭은 건드리지 않는다.** 씬 실제 inner = 432 = 32.4mm 로 이미 충분하다. 세로만 부족했다.
3. **채움 버튼으로 바꾼다.** 테두리만 있던 것을 solid fill 로. 패널에서 **유일한 채움 요소**가
   되어 훑을 때 먼저 걸린다.
4. **색을 정보에서 뗀다.** `actionFill` / `actionText` 를 `[SerializeField]` 로 신설한다.
   기본값은 코랄 계열(`deltaDownColor` 와 같은 계열 — 「전력이 줄어드는 조작」이라는 뜻이
   이미 팔레트 안에 있다). 골드(`squadBorder`)·청록(`unitBorder`)과 겹치지 않는다.
   캐주얼 디펜스 톤이라 경고 적색까지 가지 않는다 — 퇴근은 사고가 아니라 전술이다.
5. **아이콘을 라벨 왼쪽에 둔다.** 글자를 읽기 전에 식별되게. 스프라이트는 `[SerializeField]`
   로 받고 미할당이면 라벨만 — `defender-clock-out` unit 2 계약을 지켜 **뷰가 「퇴근」을 알지
   못하게** 한다.
6. **`fontActionButton` 26 → 32.** 높이가 2배가 됐는데 글자가 그대로면 빈 상자로 보인다.
7. **잠금(흐림) 표현은 유지한다.** 채움이 생겼으므로 알파를 fill 에도 적용한다. 숨기지 않는
   규율(`defender-relocation` unit 10)은 그대로 — 왜 못 누르는지가 읽혀야 한다.

## 세로 예산

버튼이 60 만큼 커지면 패널도 그만큼 자란다. 부착 3장 기준:

```
14 + (84+10) + (213.3+10) + (120+10) + 402.2 + 4 = 877.5   → 패널 하단 화면 y965.5
```
(씬 실제 값 `pad 14` 기준. 코드 기본값 18 이면 875.5 → y963.5 로 2px 차이뿐이다.)

**트레이 상단 y912 를 넘지만 문제가 되지 않는다** — 선택 중에는 트레이가 접혀 사라지고
(`DreamcatcherHandView.OpenRoutine` 이 strip 을 fold 후 `SetActive(false)`), 그 자리에 뜨는
손패는 x470~1450 이라 패널(x24~454)과 가로로 겹치지 않는다. 화면 하단 1080 까지 여유 116.

⚠ 이 여유는 「선택 중엔 트레이가 없다」에 의존한다. 트레이와 패널이 동시에 보이는 경로가
생기면 무너진다. 그때의 회수 수단: `descMaxLines` 2 → 1(부착 행 118.3 → 90, 3행에서 84.9 절약,
패널 하단 880.6). 지금 미리 줄이지 않는다 — 설명 2줄은 정보다.

버튼 좌표는 unit 0 대로 **화면 y419.3 상단 고정**, 하단만 479.3 → 539.3 으로 내려온다.
