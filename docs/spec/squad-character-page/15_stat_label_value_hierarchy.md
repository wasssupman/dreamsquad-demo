# 15 — 스탯 라벨/수치 타이포 위계

## 목적

unit 11 이 스탯을 2열로 압축하면서 한 행에 `라벨 값 라벨 값` 네 조각이 들어갔는데, 넷 다 동일 스타일(26 / Normal / 흰색)이라 **어디까지가 한 쌍인지 눈으로 갈라지지 않는다**. 라벨을 한 단 낮추고 수치를 강조해 위계를 만든다.

> unit 11 의 행 간격 44 는 **칸 사이**를 벌린 것이고, 이 작업은 **칸 안에서** 라벨과 수치를 가르는 것이다. 두 조치가 같이 있어야 2열이 읽힌다.

## 변경 대상

- `Assets/_Project/Scripts/UI/Outgame/SquadUnitDetailView.cs` — `MakeStatCell()`, `StatLabelColor` 상수

## 구현

| | 이전 | 이후 |
|---|---|---|
| 라벨 | 26 · Normal · `#FFFFFF` | **24 · Normal · `#99A3B8`** |
| 수치 | 26 · Normal · `#FFFFFF` | **30 · Bold · `#FFFFFF`** |

- **크기·굵기·명도 세 축을 동시에** 쓴다. 한 축만(예: 색만) 쓰면 2열의 네 조각이 여전히 뭉쳐 읽힌다.
- 행 높이 38 은 불변 — 수치 30 의 줄높이 ≈ 35 < 38 이라 레이아웃 영향 없음. **카드 예산 442+130 = 572/572 유지**(unit 11 과 동일).
- 라벨 색은 `StatLabelColor` 상수로 뽑아 `CardBg` 등 기존 색 상수와 같은 자리에 둔다.

**후보 비교**(Play 스크린샷 3종 중 사용자 선택): A = 24/30 대비(**채택**) · B = 둘 다 26, 색+굵기만(수치 존재감 약함) · C = 22/32 + 따뜻한 흰(위계는 최강이나 라벨이 실기기에서 희미할 우려).

## 완료 기준

- compile 클린.
- Play 실측: 라벨 `24/Normal/#99A3B8`, 수치 `30/Bold/#FFFFFF` 5개 전부. 카드 합계 572/572.
- Play 육안: 2열에서 `라벨—수치` 짝이 시각적으로 묶여 읽히고, 수치가 먼저 눈에 들어온다.
- 스톤 모드 무영향(스탯 행 은닉 경로는 unit 11 그대로).
