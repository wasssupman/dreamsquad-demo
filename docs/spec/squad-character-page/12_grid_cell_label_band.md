# 12 — 그리드 셀: 아이콘/라벨 컬럼 분리 + 라벨 배경

## 목적

컬렉션 그리드 셀의 **이름 텍스트가 초상화 위에 배경 없이 얹혀** 있어 밝은 아트에서 묻힌다. 아이콘과 라벨을 진짜 2밴드 컬럼으로 분리하고, 라벨에 어두운 배경 밴드를 깔아 시인성을 확보한다.

## 현재 상태 (측정값)

셀 150×178 → inner(6px 인셋) = 138×166. inner 상단 기준:

| 요소 | 위치 | 근거 |
|---|---|---|
| portrait | 8 → **134** | `SquadRosterBrowser.cs:144-146` (126×126, y −8) |
| label | **118** → 160 | `SquadRosterBrowser.cs:151-153` (h 42, 하단 +6) |

→ **16px 겹침**. 게다가 라벨 배경이 없어 흰 글씨가 아트에 직접 닿는다. 컬럼이 아니라 오버레이였다.

`cellSize` 는 SerializeField 지만 `SquadCharacterPage.cs:96` 에서 **런타임 `AddComponent`** 로 생성되어 씬 직렬화 값이 없다 → **코드 기본값이 곧 실제 값**이고 코드에서 자유롭게 조정 가능하다.

## 변경 대상

- `Assets/_Project/Scripts/UI/Outgame/SquadRosterBrowser.cs` — `cellSize` 기본값, `AddCell()` 의 portrait/label 배치 + 라벨 밴드 bg

## 구현

```
┌────────────────┐ ← rarity frame (6px 테두리)
│  ┌──────────┐  │
│  │  아이콘   │  │  126×126 (현재 크기 유지)
│  └──────────┘  │  inner 6 → 132
│                │  gap 10
│▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓│  라벨 밴드 46px (142 → 188)
└────────────────┘
```

- **셀 150×178 → 150×200**. 아이콘을 줄이는 대신 셀을 키운다 — 로스터 그리드는 아이콘 판독성이 본질이라 겹침 해소 비용을 아이콘에 물리지 않는다. inner = 138×188.
- **portrait**: 126×126 유지, top-center, `anchoredPosition (0, −6)` → inner 6..132.
- **라벨 밴드**: `CreateImage(inner, LabelBandColor, false)` 를 하단 stretch(anchor (0,0)–(1,0), pivot (0.5,0), height 46, y 0)로 깔고, 그 자식으로 라벨 텍스트를 full-stretch 중앙 정렬. 색 = `new Color(0f, 0f, 0f, 0.72f)` 상수로 선언(`CellBg` 등 기존 상수와 같은 자리).
- **라벨 폰트** 23 → **24**. 유닛 이름(`displayName`)과 스톤 요약(`DreamstoneStyle.Summary` = `"ATK +7.5%"`) 양쪽 모두 한 줄에 들어가 밴드 높이가 안정적이다.
- **뱃지·선택 오버레이는 불변**: "편성중" pill(155행)은 `root` 기준 우상단 유지 — 자체 배경이 있는 의도된 오버레이다. 선택 오버레이(167행)도 셀 전체 틴트 유지.

**그리드 영향**: 브라우저 폭 `(1 − 0.34) × 1920 − 패딩 24` = 1243px → `(1243+14) / (150+14)` = **7열 유지**. 뷰포트 높이 `(1 − 0.14) × 1080` = 929px → 보이는 행 4.8 → **4.3행**. 유닛 17종은 3행이라 무영향, 스톤 64종만 스크롤이 약간 늘어난다.

## 완료 기준

- compile 클린.
- Play(유닛 모드): 이름 텍스트가 초상화와 **겹치지 않고**, 어두운 밴드 위에서 밝은 아트 유닛(가장 밝은 포트레이트 기준)도 또렷하게 읽힌다.
- Play(스톤 모드): 같은 셀 기계장치로 스톤 아이콘 + `"ATK +7.5%"` 요약이 밴드에 한 줄로 들어간다.
- 그리드 7열 유지, "편성중" 뱃지와 선택 하이라이트가 이전과 동일하게 동작.

> 검증 시 주의: `ScreenSpaceOverlay` 캔버스는 게임뷰 스크린샷에 안 잡힌다. Play 중 잠깐 `ScreenSpaceCamera` 플립(저장 금지).
