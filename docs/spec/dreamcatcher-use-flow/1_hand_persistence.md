# 1 — 사용 후 손패 유지 + 빈 슬롯 재딜인 + 자동 닫힘

## 목적

카드 2~3장을 몰아 쓸 때 `자동 닫힘 → 항아리 탭 → 딜 대기` 재열기 사이클을 없앤다.
2장째부터는 드래그 1회가 전부다.

## 변경 대상

- `Assets/_Project/Scripts/UI/Dreamcatcher/DreamcatcherHandView.cs`

`DreamcatcherHandController`/`DreamcatcherCycleDeck` 은 불변 — 큐 규칙(Unit 이탈,
Squad/Active 재순환)은 그대로고 View 의 반응만 바뀐다.

## 구현

### A. `HandChanged(Used)` 핸들러 — Close 를 조건부로

현재 `Refresh(); Close();` 를 다음으로 바꾼다:

1. 게이지 차감이 반영된 상태에서 **사용 가능 카드가 남는지 먼저 판정** — 새로 손패에
   들어올 카드 포함, `CanUse`(게이지) 기준. 전부 dim 이거나 손패가 비면 "자동 닫힘 확정".
2. 자동 닫힘 확정이면: 사용된 슬롯만 비우고(`BindEmpty` — 새 카드 pop-in 도, 소모된 카드
   재표시도 없이) 기존 `Close()` (침강). **재딜인 생략** (계약 3).
3. 유지면: `Refresh()` 로 손패 재바인딩 + 사용된 슬롯 자리에 **새 카드 1장 딜인 연출**.

### B. 재딜인 연출

내려가 있던 손패가 스프링 복귀(release 라 hand-drag-clearance 가 이미 처리)하는 것과
동시에, 빈 슬롯에 다음 큐 카드가 하단 덱에서 올라온다 — 기존 딜 트윈
(`dealDurationSec`/`dealRise`/`dealTiltX`/구김 풀림)을 **1장에 재사용**, stagger 없음.
"재장전" 감각이 목표다.

- 딜인 중에도 다른 카드는 즉시 조작 가능해야 한다 (`Transitioning` 전역 게이트에 걸지
  말 것 — 걸면 연속 사용이 딜인 시간만큼 다시 막혀 이 unit 의 목적이 죽는다).
- 딜인 중인 슬롯 자체는 집기 불가(트윈 소유) — 기존 `OwnedByInteraction`/딜 소유 규칙 재사용.

### C. 닫히는 트리거 정리 (이 unit 이후)

| 트리거 | 동작 |
|---|---|
| 바깥 탭 / 페이즈 이탈 / 리셋 | 기존 그대로 |
| 커밋 성공 | **닫지 않음** (사용 가능 카드가 남으면) |
| 커밋 성공 + 사용 가능 0장 | 자동 닫힘 (재딜인 생략) |

ESC 는 기존대로 드래그 취소만.
