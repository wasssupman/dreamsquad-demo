# 4 — Play 검증

> 검증 질문: **부착을 확정하기 전에, 이 카드가 이 유닛에서 어디에 작용하는지를 화면이 판정과
> 같은 자로 말하는가.** 대표 카드는 2026-09-02 코드 대조 결과(오늘 공간 카드 4장)로 교체했다.

## 목적

unit 0~3 을 실제 손패 흐름에서 한 번에 확인한다. Editor Play 1회 + 실기기(Android) 1회.
스크린샷은 `Assets/Screenshots/darp_*.png`(비추적 스크래치).

## 체크리스트

### A. 공간 카드 — 원 (unit 0·1·2·3)
- [ ] **궁지폭발**(`SelfTileAoe` × OnDamagedN, r = 1.5): 락온 순간 host 몸 중심에 원. 부착 후 피격 N회
      발동 시 **원 가장자리에 그림자가 걸친 적까지** 맞는다(가장자리 = 판정, 계약 2).
- [ ] **진동갑주**(× HealthThreshold, r = 1.5): 라우팅 폴스루(`SkillIdForPayload`) 경로도 원이 뜬다.
- [ ] **실드폭발**(× OnShieldBreak, r = 1.5): 가디언 host 에서 원.
- [ ] **자장가**(`AreaSleep` × OnShieldBreak, r = 1.5): **unit 0 의 사각→원 전환 확인** — 부착 후
      파열 시 잠드는 적이 원 안이고, 옛 3×3 모서리(대각 1.414 → 원 1.5 안)는 여전히 걸린다.

### B. 비공간 — 표시 0 (계약 3)
- [ ] 광란(`SelfStatBuff`, tileRange 10) · 서리 화살(`ApplyStackToTarget`, 5) · 니들(`ProjectileToTarget`, 4)
      — 어느 유닛 락온에도 링 없음. 폭탄맨 host 에 니들을 붙여도 없음(Q6).
- [ ] 살찐 제물(`EnemyMark` 모드) — 부착 경로에 들어오지 않음, 링 없음.
- [ ] 불나방떼(`EmitProjectilePattern`, 시트 range 0) — 링 없음. ⚠ 시트가 range 를 올렸다면 원이
      떠야 한다(반경 = N, 칸 반폭 없음) — 값은 로그인 후 런타임 payload 로 확인.

### C. 락온 흐름 (unit 3)
- [ ] 유효 → 유효 이동: 링이 새 host 로 옮겨간다(히스테리시스 뒤라 밀집에서 튀지 않는다).
- [ ] 유효 → full 3/3: 링 소멸, 리티클 invalid 폼.
- [ ] 손 떼기 3종(커밋·손패 안 취소·보드 밖 취소) 즉시 소멸.
- [ ] 드래그 중 항아리 토글/페이즈 전환 → 잔류 0.

### D. 액티브 조준 (unit 0 표기)
- [ ] 액티브 셀 조준 카드(`TileStatBurst` 계열) 조준 중 **원 링**(반경 N + 0.5)이 조준 셀 중심에 뜬다.
      옛 사각 채움 없음. 발동 결과가 링과 일치.
- [ ] 포탈(range 0)은 종전대로 단일 셀 점등(그 경로는 `SetSkillAimCells`, 무변).

### E. 채널 경합·정렬
- [ ] 카드 드래그 직후 배치 드래그 시작 → 배치 링이 정상 소유(잔류 없음).
- [ ] 링·채움이 유닛 **아래**(정렬 −8 유지), 밀집에서 끊김은 채움이 흡수.
- [ ] Subway 맵에서 host 중심 일치 확인(StreetDay 만으로 통과 판정하지 않는다).

### F. 색
- [ ] 카드 범위 링이 배치 사거리 링(라임)과 **색상으로** 갈린다. 실기기 야외 밝기에서 읽힘.
