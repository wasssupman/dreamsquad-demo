# dreamcatcher-attach-range-preview — 부착 단계에서 카드의 적용 범위를 보여준다

> 상태: **결정 확정 — 미착수** (2026-09-01). 다음 세션은 이 README 만 읽고 unit 0 부터 시작하면 된다.
> 발원: `distance-based-range` 종료 시 사용자 제안. 그 spec 의 표기 계약(판정과 1:1)을
> **소비**하는 후속이며, 판정 자체는 건드리지 않는다.

## 배경

드림캐쳐를 유닛에 부착할 때 화면은 「누구에게 붙나」(락온)만 말하고 **「붙으면 어디에
작용하나」는 말하지 않는다.** 자장가(반경 N)·착지충격(사각 M)·오라처럼 공간 카드는 부착을
확정하고 발동을 본 뒤에야 범위를 알게 된다 — 배치 유닛의 사거리 링이 해결한 것과 정확히
같은 문제가 부착 단계에 남아 있다.

재료는 이미 있다:
- **판정 자**: 전투 판정은 전부 거리 기반이다(`distance-based-range` units 12~19 — 원/사각
  SDF + 몸 걸침). 표기가 복사할 값이 하나로 정리돼 있다.
- **표기 어휘**: 원 = 링 셰이더(`PlacementRangeRing`) · 칸 도형 = 채움
  (`SetPlacementRange(squareShape)`) · 소유권 = `RangeDisplayOwner` 채널.
- **카드 공간성 분류**: `distance-based-range/18` 전수조사 표(카드 47종 × 페이로드 33종).

## 검증 질문

> **부착을 확정하기 전에, 이 카드가 이 유닛에서 어디에 작용하는지를 화면이
> 판정과 같은 자로 말하는가.**

## 카드 공간성 분류 (unit 18 전수조사에서 파생)

| 표기 클래스 | 페이로드 | 표기 |
|---|---|---|
| 호스트 중심 **사각**(칸 도형) | AreaCc(진동갑주·궁지폭발) · AreaSleep(자장가) · AreaDot · AreaApplyStack · AreaTaunt · SelfTileAoe(반격류) · TileStatBurst | 채움(`squareShape`) — 호스트 몸 중심 |
| 호스트 중심 **원** | StatAura · GrantShield(실드 뿌리기) · AllyMoveSpeedAura · EmitPattern(range>0) | 링 — 사거리와 같은 자 |
| **부채꼴** | AreaBreath | **제외 확정** — 사용 카드 0장(보스 전용 페이로드). 첫 부채꼴 카드가 생기면 그때 어휘 신설 |
| 죽은 자리/조건 발동 장판 | SpawnHazard · OnDeath 계열 | **노출 X 확정** — 부착 시점에 위치가 없으므로 비공간으로 접는다 |
| 대상 기준/비공간 | ApplyCc/StackToTarget · HeavyStrike · 스탯/코스트/쿨다운류 | **표시 0** — 없는 범위를 지어내지 않는다 |
| ⚠ 겸직 `tileRange` | 살찐 제물(30 = −30%) · 광란(10 = 잔존값) | **표시 금지 가드 필수** — 공간값이 아니다 |

## Feature-wide 계약 (초안)

1. **표기는 판정 입력의 복사본이다.** 링/채움 호출부가 술어에 넣는 값을 그대로 넣는다 —
   여기서 모양을 다시 그리지 않는다(`distance-based-range` unit 5 규율 승계).
2. **몸 걸침 관용 승계** — 표시는 표준 상대 기준이고 몸이 큰 대상은 더 넓게 걸린다.
   표시보다 넓게만 맞으므로 무통보 관용(unit 14 결정 그대로).
3. **비공간 카드는 아무것도 그리지 않는다.** 겸직 `tileRange` 2장이 공간값으로 새는 것을
   카탈로그(unit 0)가 타입으로 막는다.
4. **소유권 한 채널** — `RangeDisplayOwner` 에 부착 프리뷰 owner 를 추가하고, 배치 프리뷰·
   스킬 조준과의 우선순위를 그 enum 의 기존 규칙(획득 시 덮어쓰기 + Placement 면제)대로 따른다.
5. **판정 무변.** 이 spec 은 sim 파일을 한 줄도 바꾸지 않는다 — 골든 무변이 완료 기준.

## 작업 단위 (초안)

| 파일 | 작업 구분 | 목적 |
|---|---|---|
| 0 | 공간성 카탈로그 | 페이로드 → 표기 클래스 순수 매핑(+겸직 가드) · EditMode 고정 |
| 1 | 부착 프리뷰 채널 | 브리지 API + owner — 호스트(중심·몸)에 원/사각을 그린다 |
| 2 | 락온 연동 | 카드 드래그 중 락온 대상 변경/이동을 프리뷰가 따라간다(배치 마크 라이브 추적 관용) |
| 3 | Play 검증 | 공간 카드 대표 3종(자장가·오라·발사명세) + 비공간 3종 무표시 확인 |

## 사용자 확정 결정 (2026-09-01)

1. **표면 = 카드 드래그 중 락온이 성립한 순간에만** 뜬다. 드래그 시작 시 후보 전원 점등은
   기각(밀집 소음), 인스펙트 재열람은 후속 후보로.
2. **부채꼴(AreaBreath) 제외** — 사용 카드 0장(보스 전용). 표기 어휘를 미리 만들지 않는다.
3. **공간이 필요 없는 카드는 노출하지 않는다** — 비공간(스탯·코스트·대상형)은 물론,
   부착 시점에 위치가 정해지지 않는 조건 발동 장판(OnDeath 계열)도 노출 X 로 접는다.
   없는 범위를 지어내는 표시가 이 spec 최대의 금기다(겸직 tileRange 가드 포함).

## 파이프라인 커버리지

새 플레이 오브젝트 없음 — 기존 표기 정거장(링 스프라이트·range 타일맵) 재사용.
스폰·bake·시스템·VFX 전부 **N/A**(표기 전용, sim 무변).

## 후속 후보

- 인스펙트 패널에서 부착된 카드의 범위 재열람(결정 1 에서 후속으로 이관).
- 부채꼴 표기 어휘 — 첫 부채꼴 카드가 생기는 날 이 spec 에 unit 으로 추가.
- 조건 발동 장판의 「크기만 안내」 — 결정 3 이 노출 X 로 접었으나, 플레이어 혼란이 실측되면 재론.
- 전투 중 오라/장판 상시 시각화와의 통합(현재 오라는 자체 VFX 만).
