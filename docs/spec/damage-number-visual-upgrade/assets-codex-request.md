# 코덱스 에셋 요청서 — damage-number-visual-upgrade

> 이 문서는 작업 단위(0~N)가 아니라 **코덱스에게 넘길 에셋 요청 명세**다. 코드(unit 0·1)는 이 에셋 없이 선행 가능하며, 아래 에셋이 도착하면 unit 2·3 이 슬롯에 꽂는다.
>
> 배경: 참고 이미지 = "Sword x Staff" 데미지 폰트 (청록 페이스 + 하프톤 점 패턴 + 흰 외곽선 + 글로우 + 스파크). 우리 렌더는 **월드 스페이스 TextMeshPro (SDF)** + 머티리얼 중심. 타겟은 **Android 실기기**.

---

## 항목 1 — 하프톤 페이스 텍스처 (필수, unit 2)

TMP `Distance Field` 머티리얼의 `_FaceTex` 슬롯에 타일링될 점 패턴.

- **용도**: 숫자 면에 팝아트 하프톤 점 패턴. TMP 가 face 색과 곱하므로 텍스처는 **색 없는 명암 패턴**이어야 함(팔레트 색이 곱해짐).
- **포맷**: PNG, **seamless 타일링**(상하좌우 이음매 없음), 정사각.
- **해상도**: 256×256 (또는 512×512).
- **패턴**: 규칙적 하프톤 점 그리드. 점 = 밝음(흰~밝은 회색), 간격 = 어두움(중간 회색). 대비는 과하지 않게(점이 살짝 도드라지는 정도).
- **밀도 변형**: 가능하면 밀도 2~3종(성김/보통/촘촘) 제공 → Play 에서 타일링으로 고르지 않고 소스 선택 여지.
- **알파**: 불투명(알파는 SDF 글리프가 담당). 알파 채널 불필요.

## 항목 2 — 임팩트 스파크 파티클 (선택, unit 3)

타격 지점에 클러스터당 1회 튀는 스파크/파편.

- **용도**: Shuriken(내장 파티클) 원샷 버스트. 숫자마다가 아니라 스폰 클러스터당 1회.
- **저작 경로**: `unity-vfx-authoring` 스킬 규격의 `_SKELETON` 프리팹 + 텍스처. 모바일 세이프(파티클 수·오버드로 최소).
- **텍스처**: 작은 스파크/별/파편 스프라이트(흰색, additive 전제). 32~64px, 알파 포함. 필요 시 4~8프레임 스프라이트시트.
- **동작**: 짧은 수명(~0.3s), 방사형 튀김, additive, 중력 소량. 색은 흰~연노랑(런타임 tint 여지).
- **금지**: 라이트/트레일 과다, soft particle 강제. 실기 드로우콜 부담 항목 배제.

## 항목 3 — 백-글로우 스프라이트 (선택 폴백, unit 2)

TMP 내장 글로우가 부족할 때만.

- **용도**: 큰 히트 숫자 뒤 은은한 방사형 광채(빌보드 쿼드에 얹는 스프라이트). 기본은 TMP `_GlowPower` 로 처리하고, 부족 시에만 사용.
- **텍스처**: 부드러운 방사형 그라데이션(중심 흰색 → 가장자리 투명), 128×128, additive, 알파 포함.

---

## 우선순위

1. **항목 1 (하프톤 텍스처)** — unit 2 블로커. 가장 먼저.
2. **항목 2 (스파크)** — unit 3, 선택. 룩 확정 후.
3. **항목 3 (백-글로우)** — TMP 글로우로 부족할 때만.
