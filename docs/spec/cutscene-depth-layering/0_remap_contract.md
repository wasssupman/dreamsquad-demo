# 0 — 리맵 산식 · 파라미터 계약

## 목적

계단 리맵의 산식·파라미터·불변식을 못박는다. unit 1(툴)이 이 파일만 보고 구현 가능해야 하고,
unit 2(자산)는 여기 적힌 수치를 재현해야 한다.

## 변경 대상

이 문서만(코드 없음). 계약 소비자 = `1_baker_remap_option.md`.

## 구현

### 형태: 재bake 가 아니라 **후처리** (하드 결정)

리맵은 `(기존 뎁스 PNG, 같은 유닛 색 프레임) → 리맵된 뎁스 PNG` 인 **순수 이미지 연산**이다.
모델 재추론을 하지 않는다. 근거: ① **Ranger 뎁스는 툴 산출물이 아니라 사용자 제공**
(`Ranger_003-depth` 640×360 + threshold-pivot·contrast 2.2 —
`depth-parallax/10_handoff_summary.md`)이라 재bake 하면 **손으로 만든 뎁스가 소실**된다.
② torch/transformers 불필요(numpy+PIL) → 튜닝 반복이 싸다. ③ 4종(툴 bake 3 + 사용자 제공 1)을
**균일하게** 다룰 수 있다.

### 산식

입력: `d` = 기존 뎁스 [0,1] · `a` = 색 프레임 알파 · 마스크 `m = a > 0.5`.
모든 연산은 **뎁스맵 자체 해상도**에서 한다(색 해상도로 올리지 않는다).

```
1) 캐릭터-only 정규화      p2,p98 = percentile(d[m], [2,98])
                           r = clip01((d - p2) / (p98 - p2))
2) 근경/몸통 분리          near = r >= near_keep
3) 근경(손) — 연속 유지     out = near_lo + (near_hi-near_lo) * (r-near_keep)/(1-near_keep)
4) 몸통 — L단 계단          q   = floor(r/near_keep * L) / (L-1)        # L개 이산 레벨
                           out = body_lo + (body_hi-body_lo) * clip01(q)
5) 경계만 완화             out = gaussian_blur(out, blur_sigma)
6) R8 양자화               기존 quantize_r8(dither) 재사용
```

### 파라미터 · 기본값

| 이름 | 기본 | 의미 |
|---|---|---|
| `L` (levels) | **4** | 몸통 계단 수 (사용자 결정 2026-07-16) |
| `near_keep` | 0.80 | 이 위 = 손(근경), 아래 = 몸통 |
| `near_lo`/`near_hi` | **0.40** / 1.00 | 손 대역. `near_lo == body_hi`(간극 0). rev2: 0.80→0.40 |
| `body_lo`/`body_hi` | 0.02 / **0.40** | 몸 대역 — 힌지에서 **멀리**. rev2: 0.44→0.40 |
| `blur_sigma` | **1.2 (색px)** | **색 텍스처 px 기준**. 툴이 뎁스/색 배율로 환산. rev2 |
| `dither` | 0.5 | 기존 툴 기본값 유지 |

### rev 2026-07-16 — 접힘(잔상) 수정 · 2회 반복

**증상**: 사용자 Play 에서 "손·발에 스와이프하면 잔상". 원인은 초기값의 경계 점프였다 —
`body_hi 0.44` / `near_lo 0.80` 이라 `r=0.79→0.44`, `r=0.81→0.80` 으로 **출력이 0.36 점프**했고,
그 인위적 절벽이 손가락 뿌리에서 샘플 좌표를 접었다(grad 1.17). 원본은 0.90 으로 아슬아슬
통과하던 것을 **리맵이 넘긴 것 — 이 spec 이 만든 결함**이다.

**1차 시도(폐기)**: 간극만 0.04 로 좁힘(`body_hi .48`/`near_lo .52`). 접힘은 잡혔지만 두 대역이
힌지에 바짝 붙어 **픽셀이 다시 힌지에 주차**됐다(Ranger 9.1%→16.7%) — spec 의 목적을 되돌림.

**2차(채택)**: 간극 0(`near_lo == body_hi == 0.40`) + 몸 대역을 힌지에서 **멀리**.
**손 뿌리는 몸과 같이 움직이고 손끝만 힌지를 넘어 반대로** 간다(물리적으로도 자연스럽다).
극적임은 `near_hi`(손끝)가 만들지 `near_lo`(손 뿌리)가 만드는 게 아니다 — **이 구분이 rev 의
핵심 교훈**이다.

**blur 기준 정정**: `blur_sigma` 를 뎁스 텍셀 기준으로 뒀더니 유닛마다 실효 완화가 달랐다 —
Ranger 뎁스만 full-res(640=색폭)라 0.6텍셀=0.6색px, Cannon 은 half-res 라 0.6텍셀=**1.2색px**.
Ranger 가 절반만 완화받아 홀로 접힘이 악화됐다. → **색px 기준으로 정의**하고 툴이
`sigma = blur_colorpx × (뎁스폭/색폭)` 로 환산한다.

**채택안 실측** (대역 .02/.40 + blur 1.2색px):

| 유닛 | 계단보존 | 접힘 base→ | 변위 base→ | 주차 base→ |
|---|---|---|---|---|
| Ranger | 90.1% | 0.33→0.32% | +14% | 9.1→6.1% |
| Archer | 97.4% | 0.28→0.22% | +14% | 1.1→0.6% |
| Guardian | 94.7% | 0→0% | +15% | 4.4→0.5% |
| Cannon | 94.1% | 0→0% | **+61%** | 19.7→1.2% |

접힘 회귀 0, 계단 90%+ 유지. blur 를 3.0색px 까지 키우면 Ranger 접힘이 0.09% 로 더 좋아지나
계단이 82.6% 로 뭉개져 **1.2 를 채택**했다.

**Ranger 는 접힘 0 이 불가능하다**: 사용자 제공 뎁스에 threshold-pivot 이 얹혀 1px 하드 엣지
(원본 grad 12.59)가 있고, `amp×W_color=14.08` 이라 Δd 0.07/px 만 넘어도 접힌다. baseline 대비
악화만 없으면 통과로 본다.

### 불변식 (하드)

- **힌지 분리 (rev2 재정의)**: `body_hi <= depthCenter(0.5) < near_hi`. 즉 **몸통 전체는 힌지
  아래, 손'끝'은 힌지 위**. 초기 계약은 손 대역 *전체*를 힌지 위로 요구했으나(`near_lo > 0.5`),
  그게 경계 절벽을 강제해 접힘을 만들었다. 손 뿌리(near_lo)는 힌지 아래여도 된다 — 손목·주먹이
  몸과 같이 움직이는 건 물리적으로 옳다. **반대 운동은 손끝 vs 몸통이면 성립한다.**
- **경계 연속 (하드, rev2)**: `near_lo == body_hi`(간극 0). 두 대역 사이 점프가 있으면 손/몸
  경계(=손가락 뿌리)에 절벽이 생겨 접힌다. 극적임은 `near_hi`(손끝)가 만들지 `near_lo`(손 뿌리)
  가 만드는 게 아니다 — **이 구분이 rev 의 핵심 교훈**이다.
- **몸 대역은 힌지에서 멀리 (rev2)**: `body_hi <= 0.42` 권장. 힌지에 붙이면(0.48 등) 몸통 픽셀이
  다시 힌지에 주차돼 변위가 0 이 된다 — spec 의 목적 자체를 되돌린다(1차 시도 실패 사유).
- **접힘 금지 (하드, rev 2026-07-16)**: 셰이더는 `_MainTex` 의 UV 공간에서 샘플하므로
  `uv_sample = uv + tilt*(depth-0.5)*amplitude` 이고, 기울기가 뒤집히면 이미지가 접혀
  **잔상**으로 보인다. 판정식:

  ```
  g = |Δdepth/Δpx(색 해상도)| × amplitude × W_color     →  g >= 1 이면 접힘
  ```

  **문턱이 유닛별로 다르다** — `W_color` 가 다르기 때문이다(`amplitude × W_color`:
  Cannon 276 → 6.07 · Ranger 640 → **14.1**). 즉 **고해상도 유닛일수록 접힘에 취약**하다.
  뎁스 해상도가 아니라 **색 텍스처 폭**이 기준임에 주의. 툴이 `--stats` 로 측정·경고한다.
- **amplitude 불변**: `DepthParallaxSettings.amplitude`(0.022)를 올리지 않는다. 모바일 ≤4%.
- **`--contrast` 와 상호배타**: 기존 `--contrast` 도 0.5 힌지 기준으로 near/far 를 벌리는
  같은 목적의 노브다. 리맵과 **겹쳐 쓰면 이중 계산**된다. 리맵을 쓰는 유닛은 contrast 를
  적용하지 않는다(리맵의 1단계 renorm 이 선행 contrast 를 일부 흡수하므로, Ranger 처럼 이미
  contrast 2.2 가 구워진 자산은 unit 2 에서 실측 후 판단).
- **평탄면 보존**: blur 는 계단 경계만 눕히고 평탄면은 남겨야 한다. sigma 를 키워 계단이
  램프로 뭉개지면 이 spec 의 목적이 사라진다 — unit 2 에서 계단 수를 실측 검증한다.
- **자산 관례**: R8 · linear · no-mip · 무압축 · Clamp · **흰=near**. 극성은 여전히 전역
  `depthSign`.

## 완료 기준

- 위 산식·파라미터·불변식이 확정돼 unit 1 이 이 파일만으로 구현 가능하다.
- unit 1 구현은 **README 실측표를 재현**해야 한다(허용 오차 ±2%p):
  힌지 주차 Ranger 9.1→1.0% · Archer 1.1→0.6% · Guardian 4.3→0.8% · Cannon 19.7→1.6%,
  변위 +19% / +14% / +13% / +53%.
- 재bake 가 아닌 후처리라는 형태 결정과 그 근거(Ranger 사용자 뎁스 보존)가 문서에 남는다.
