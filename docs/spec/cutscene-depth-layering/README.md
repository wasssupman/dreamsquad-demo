## 상위 목표

배치 컷신 4종(Ranger/Archer/Guardian/Cannon)의 뎁스맵을 **근경 과장 + 몸통 4단 계단**으로
리맵해서, 패럴랙스가 연속 램프로 뭉개지지 않고 **이산 평면(디오라마/페이퍼컷)**으로 읽히게
한다. Marvel Snap 카드류의 레이어드 뎁스 감각.

동기: 4종 다 "손/발이 카메라로 튀어나오고 몸이 뒤로 길게 붙는" 공통 구도인데, DA-V2 원본
출력은 매끄러운 그라디언트라 **튀어나온 부분의 극적임과 뒷부분의 대비가 죽는다.**

## 검증 질문

- 컷신을 드래그해 스와이프하면 **손(근경)이 몸과 뚜렷이 반대로** 밀리고, 몸통이 **하나의 판이
  아니라 여러 단**으로 층져 움직이는가?
- 계단 경계에서 실루엣이 늘어지거나 찢어지지 않는가(depth 절벽)?
- 이미 Play 검증된 Ranger/Archer/Guardian 이 **더 나빠지지 않았는가**?
- `amplitude`(모바일 ≤4%)를 올리지 않고 달성했는가?

## 실측 근거 (2026-07-16, 4단 시안 시뮬레이션)

리맵 전후. **힌지 주차** = 캐릭터-only renorm 후 depth 가 `depthCenter`(0.5)±0.05 라
변위가 사실상 0인 픽셀 비율. **변위** = `|depth-0.5| × amplitude` 평균.

**rev2 확정치** (2026-07-16 — 초기 시안은 접힘/잔상을 만들어 폐기. `0_remap_contract.md` rev2):

| 유닛 | 불투명 | 힌지 주차 → | 변위 → | 증가 | 접힘 → |
|---|---|---|---|---|---|
| Ranger | 29.2% | 9.1% → 6.0% | 0.0057 → 0.0065 | +13% | 0.33 → 0.33% |
| Archer | 39.4% | 1.1% → 0.6% | 0.0086 → 0.0098 | +14% | 0.29 → 0.24% |
| Guardian | 100% | 4.3% → 0.5% | 0.0081 → 0.0093 | +14% | 0 → 0% |
| **Cannon** | 36.3% | **19.3% → 1.2%** | **0.0041 → 0.0066** | **+60%** | 0 → 0% |

- **Cannon 이 이상치**: 캐릭터의 37.4%가 힌지 바로 위(raw 128~159)에 주차돼 몸통이 거의
  안 움직였다. 리맵 이득이 가장 크다.
- **나머지 3종의 변위 이득은 +13~19% 로 완만하다.** 이들에게 이 작업의 값어치는 변위 크기가
  아니라 **질적 변화**(연속 → 이산 계단)이며, 그건 위 숫자로 안 잡힌다. → unit 3 이 판정한다.
- 시뮬레이션은 프래그먼트 산식(`UvOffset`)만 재현했고 사다리꼴·하이라이트 큐는 제외.

## 공통 원칙 / Feature-wide 계약

- **선형성 활용 (핵심)**: `DepthParallaxMath.UvOffset = tilt × (depth − depthCenter) ×
  amplitude × depthSign` 은 **depth 에 선형**이다. 따라서 **뎁스 PNG 에 구운 모양이 곧 변위
  프로파일**이다 → 셰이더/모듈/런타임 **코드 0줄 변경**, 런타임 비용 0. 리맵은 순수하게
  **자산 오써링**이다.
- **amplitude 불변 (하드)**: 모바일 제약(peak UV 오프셋 ≤4%, dependent read 1회)을 위해
  `DepthParallaxSettings.amplitude`(현 0.022)를 **올리지 않는다.** 리맵은 [0,1] 안의 *분포*만
  바꿔 같은 amplitude 로 더 큰 체감을 얻는다.
- **캐릭터-only 정규화**: p2/p98 을 `alpha>0.5` 마스크 안에서만 계산한다. 투명부/배경이
  정규화 범위를 잡아먹지 않게. (`depth_bake.py` 현재는 전체 이미지 기준.)
- **힌지 인지 설계**: `depthCenter=0.5` 는 **전역 설정**이라 유닛별로 못 바꾼다. 그러므로
  몸통을 힌지 **아래**(`[0.02, 0.44]`)로 몰고 손을 **위**(`[0.80, 1.00]`)로 밀어 **서로 반대
  방향**으로 움직이게 한다 — 이게 "튀어나온 건 극적, 뒤는 대비"의 실제 구현이다.
- **계단 경계만 blur**: 평탄면은 유지해 이산감을 보존하고, 경계만 ~1.2px blur 로 완화한다.
  하드 계단은 depth 절벽 → 패럴랙스 시 실루엣 늘어짐(`depth-parallax` unit 8 "경계 급락" 경고).
- **자산 관례 불변**: R8 · linear · no-mip · 무압축 · Clamp · non-atlased · **흰=near**.
  극성은 여전히 `DepthParallaxSettings.depthSign` 전역 노브.
- **회귀 위험 명시 (하드)**: Ranger/Archer/Guardian 은 **이미 Play 검증·출시된** 연출이다.
  리맵은 그 체감을 바꾼다. unit 3 에서 4종 전부 재검증하고, 특정 유닛이 나빠지면 그 유닛만
  **opt-out**(리맵 전 뎁스 유지)한다. 일괄 적용을 완주 조건으로 삼지 않는다.
- **Guardian 특수 — 해소됨** (unit 2 실측 2026-07-16): 투명부 0%라 캐릭터-only 마스크가 사실상
  전체지만, **뎁스 자체가 이미 장식 배경을 분리**한다(원본의 65.5%가 far 0.00~0.12). 리맵은 그
  배경을 최하단 계단으로 밀 뿐(평균 0.021)이라 무해하고, 실제 캐릭터는 4단에 퍼지며 17.4%가
  손 대역(뻗은 부츠 밑창)에 든다. → **4종 동일 파라미터. opt-out 하지 않는다.**

## 리맵 산식 (unit 0 에서 확정, 현 시안)

```
r      = clip01((d - p2) / (p98 - p2))          # 캐릭터-only 정규화
near   = r >= near_keep(0.80)
out[near] = 0.80 + 0.20 * (r - 0.80)/0.20        # 손: 연속 유지, 힌지 반대편 최대
out[body] = 0.02 + 0.42 * floor(r/0.80 * L)/(L-1)  # 몸: L(=4)단 계단, 전부 힌지 아래
out    = gaussian_blur(out, 1.2)                 # 경계만 완화
```

파라미터: `L`(계단 수, 기본 4) · `near_keep`(0.80) · `blur`(1.2) · 몸통 대역 `[0.02, 0.44]` ·
손 대역 `[0.80, 1.00]`. 전부 unit 1 에서 CLI 옵션으로 노출.

- **드림캐쳐 손패 카드**에 동일 리맵(`depth-parallax` 의 두 번째 소비처 상정).

  지금은 굽기(코드 0줄·비용 0)가 우선. 튜닝 반복이 잦아지면 승격 검토.

- **`depthCenter` 유닛별화**: 지금은 전역 0.5. 유닛마다 힌지를 다르게 두고 싶어지면 별도 결정
  (모듈 계약 변경이라 무겁다).
