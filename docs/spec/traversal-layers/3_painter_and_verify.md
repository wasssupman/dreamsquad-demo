# 3. 페인터 통행층 브러시 + 검증

## 목적

통행 층을 손으로 저작하고, 층이 다른 적 2종이 실제로 다른 길을 타는지 확인한다.

## 변경 대상

- `Assets/_Project/Editor/MapPainterWindow.cs` — 통행층 브러시(배치층 브러시와 같은 문법: 층 선택 + 토글, 파생 추종, 오버레이)
- 검증용 적 SO 1종(통행 층이 다른 적) — 풀 미등록, dev 진입
- `Assets/_Project/Tests/EditMode/` 또는 PlayMode — 경로 분기 회귀

## 구현

1. **브러시**: `Tool` 에 `TraverseMask` 추가. 배치층 브러시와 동일한 규칙 — 드래그는 시작 셀 반전값으로 set, 타일 브러시는 통행 마스크도 파생값으로 추종(stale 방지), `파생 리셋` 버튼이 두 마스크를 함께 되돌린다.
2. **오버레이**: 배치층과 구분되는 표기(예: 대각선 해치 또는 셀 내부 점). 두 마스크가 한 화면에 겹치므로 **동시에 읽히는지**가 판정 기준 — 안 되면 층 표시 토글(배치/통행 보기 전환)을 둔다.
3. **검증 규칙**: 스폰·골 칸의 통행 층이 닫히면 **에러**(Bake 차단, 계약 6). 배치 마스크가 warning 인 것과 달리 여기는 판이 성립하지 않으므로 에러다.
4. **검증 맵·적**: 도로 + 배치지면 일부를 통행 가능하게 연 맵, 그리고 그 층을 가진 적 1종. 기존 적은 무변경(지상 층).

## 완료 기준

- 페인터: 통행층 저작 → Bake → 왕복 보존, 스폰/골 통행 차단 시 Bake 불가.
- Play: 층 다른 적 2종이 같은 웨이브에서 **다른 경로**로 이동, 기존 적 경로는 불변, 콘솔 에러 0.
- 회귀: 통행층 미저작 맵 + 미저작 적에서 판이 이전과 동일(도달 시간 축).
