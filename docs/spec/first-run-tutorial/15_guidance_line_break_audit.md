# 15 — 안내 문구 줄바꿈 전수 점검

## 범위

첫 실행 흐름에서 `TutorialGuidanceView`로 표시되는 로비·전투 안내 문구 전체를 점검했다.
안내 패널은 42pt 글꼴과 약 824px의 유효 텍스트 폭을 사용하므로, 한국어 20자 안팎을 넘으며
두 의미 단위가 있는 문구에는 명시적 줄바꿈을 둔다.

회귀 검증은 `Assets/_Project/Tests/EditMode/TutorialGuidanceCopyTests.cs`가 담당한다.

## 적용 원칙

- 행동 대상 또는 원인 설명을 첫 줄에 둔다.
- 실제 행동 지시는 둘째 줄에 둔다.
- 동적 유닛 이름이 들어가는 문구는 이름 뒤 행동 구절이 밀리지 않도록 미리 끊는다.
- 목표 라벨, 버튼명, 짧은 한 문장처럼 한 줄에서 읽히는 문구는 바꾸지 않는다.
- 자동 줄바꿈에 맡겼을 때 조사나 동사 앞에서 끊길 수 있는 긴 문구만 수정한다.

## 점검 결과

- 전투 안내: 제한시간 목표, 방어 목표, 말파이트 스킬·배치·철수, 샷건맨 선택, 배치 스킬 요약,
  유닛 재선택, 드림캐쳐 선택·부착, 1분 생존 안내에 줄바꿈을 적용했다.
- 1분 생존 안내도 두 줄 안에서 도구와 목표가 나뉘도록 배치한다.
- 로비 안내: 첫 START 안내를 목표 설명과 행동 제안 사이에서 나눴다.
- 짧은 목표·영역·항아리·샷건맨 스킬/배치 문구는 한 줄을 유지했다.
