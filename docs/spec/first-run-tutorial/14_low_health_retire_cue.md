# 14 — 낮은 체력으로 철수 이유 보여주기

## 목적

첫 실행 튜토리얼에서 말파이트를 배치한 직후 체력바를 낮춰, 다음 단계의 「철수」가
임의의 조작이 아니라 체력이 적은 유닛을 보드에서 빼는 선택임을 화면으로 설명한다.

## 동작

- 첫 유닛인 말파이트에만 배치 직후 최대 체력의 90%에 해당하는 피해를 한 번 요청한다.
- 정확한 잔여 체력 수치는 계약이 아니다. 낮은 체력바가 식별되면 충분하다.
- 수치는 `FirstRunTutorialConfig.primaryPostPlacementDamageRatio`가 소유한다.
- 튜토리얼 MonoBehaviour는 ECS에 직접 접근하지 않는다. `BattleBridge`가 배치 Entity를 찾고
  Units 소유의 `IncomingDamage` 버퍼에 요청을 추가한다.
- 피해 요청이 실패하면 저체력 문구를 거짓으로 띄우지 않고 해당 블록을 미완료로 남긴다.
- 두 번째 유닛인 샷건맨과 일반 전투 배치에는 적용하지 않는다.

## 안내 문구

- 배치 관람 뒤: `말파이트 체력이 낮아졌습니다.\n철수시켜 보세요`
- 철수 버튼 포커스: `체력이 적거나 재배치가 필요한 경우,\n철수시켜 전략적으로 활용할 수 있습니다.`

## 완료 기준

- 말파이트 배치 및 활성화 뒤 체력바가 낮아진다.
- 철수 안내가 낮은 체력과 「철수」 버튼을 같은 흐름으로 설명한다.
- 샷건맨 배치에는 추가 피해가 없다.
- 튜토리얼 외 전투에는 영향이 없다.
