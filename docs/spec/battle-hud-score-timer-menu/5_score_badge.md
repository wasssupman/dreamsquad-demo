# 5 — 점수 UI 배지/플레이트화

## 목적

점수 UI 의 **정적 프레젠테이션**이 밋밋하다(연출 juice 와 별개로 프레임·구조·대비가 없어 "떠 있는 텍스트"로 보임). 어두운 반투명 라운드 플레이트 + 골드 테두리 + "SCORE" 상단 탭으로 배지화해 맵 위에서도 또렷하고 HUD 요소로 읽히게 한다.

검증 질문: **"점수 UI 가 맵 위에서 눈에 확 띄고, 디자인된 HUD 배지로 읽히는가?"** (연출은 이미 있음 — 정적 외형만 개선)

## 변경 대상

- `Assets/_Project/Scripts/UI/ScoreHudView.cs` (플레이트/테두리/탭 요소 추가)
- 씬 값: `BattleScene.unity` 의 `ScoreHud` (신규 SerializeField 직렬화 시 동기화)

## 구현

기존 연출(`TriggerHit`/버스트/글로우/샤인/마일스톤)은 **손대지 않는다**. `BuildCanvas()` 에 정적 요소만 추가하고, 숫자/캡션은 그 위에 얹는다.

1. **플레이트**: `_panel` 의 first sibling 으로 라운드 사각형 Image. 어두운 반투명 fill(기본 `#0A0E14 α0.55` 근처, SerializeField). 절차적 라운드 사각형 스프라이트(코너 반경 SerializeField) 또는 프로젝트 9-slice 스프라이트. 숫자+캡션을 감싸는 패딩.
2. **골드 테두리 + 이너글로우**: 플레이트에 얇은 골드 스트로크(`baseColor` 계열, 두께 SerializeField). 이너글로우는 기존 additive 글로우 재활용 가능.
3. **"SCORE" 상단 탭**: 플레이트 상단 모서리에 걸친 작은 골드 배너/알약 Image + 그 안에 다크 "SCORE" 텍스트(현 `_caption` 을 탭 안으로 이동, small caps/자간). 탭 크기·색 SerializeField.
4. **숫자**: 골드 104pt 유지, 플레이트 중앙. z-순서: 플레이트(뒤) → 글로우 → 숫자/탭(앞). 기존 `_valueRect`/글로우/샤인 배치와 z-순서 충돌 없게 정리.
5. **튜닝 필드**: 플레이트색/알파/코너반경/테두리색/두께/탭크기/패딩을 SerializeField 로 노출 — Play 보며 값 조정.

## 완료 기준

- [ ] 컴파일 통과, 콘솔 에러 없음.
- [ ] Play 배틀 → 점수가 어두운 라운드 플레이트 + 골드 테두리 + 상단 "SCORE" 탭으로 표시, 맵 위에서 또렷.
- [ ] 기존 연출(펀치/골드 플래시/스파크/글로우/마일스톤) 회귀 없음 — 플레이트 위에서 정상 동작.
- [ ] 사용자 Play 확인: "눈에 띄고 배지로 읽힌다" 통과.

> 확인: 2026-07-08 사용자 Play 확인 통과. 어두운 라운드 플레이트(절차적 SDF 9-slice) + 골드 테두리 + 상단 "SCORE" 골드 탭. 추가 조정: 배지를 **화면 우상단 모서리로 이동**(`cornerPadding` 36px). 연출 회귀 없음.
