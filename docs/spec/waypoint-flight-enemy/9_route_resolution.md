# 9. 켜기 — 레인 경로 해석 + 도달 판정 완화

## 목적

unit 8 의 데이터를 스폰이 읽게 한다. 지상 적이 처음으로 저작 경로를 탄다. **한 커밋**(계약 5 승계 — unit 3 을 쪼개지 않은 것과 같은 이유).

## 변경 대상

- `Assets/_Project/Scripts/Bridge/BattleBridge.cs` — `SpawnUnit` 의 경로 해석 (`8357~8377` 의 기존 부착 분기)
- `Assets/_Project/Scripts/Battle/Movement/WaypointProgress.cs` — 도달 판정
- `Assets/_Project/Tests/EditMode/` — 해석 우선순위 · 도달 판정
- `Assets/_Project/Tests/PlayMode/WaypointRoutingLiveTest.cs` — 레인별 경로 통과

## 구현

### 해석 순서 — 좁은 쪽(개체)이 이긴다

```
pathIndex = unit.waypointPathIndex >= 0        ? unit.waypointPathIndex
                                               : map.RouteForSpawn(laneIndex)
```

**적 SO 지정이 이기는 이유**: 그것은 **종의 정체성**이다 — Skimmer 의 Air 경로는 어느 레인에서 나오든 Skimmer 의 성질이다. 레인 기본은 「지정이 없는 적이 이 맵에서 어디로 오나」다. 두 축이 겹치면 좁은 쪽이 이긴다.

이 두 축이 합쳐져 spec 의 검증 질문(「같은 맵에서 **적마다** 다른 길」)에 「**레인마다** 다른 길」이 더해진다.

`laneIndex` 는 이미 그 자리에 있다 — `SpawnUnit` 이 `pending.laneIndex`(`BattleBridge.cs:8188`)로 받고, 웨이포인트 부착 분기가 그 아래 `8357` 이다. 새로 넘길 값이 없다.

**유효성 검사는 기존 분기 그대로다.** `pathIndex < WaypointPathCount` 실패 시 골 직행 + 스폰 1회 경고 — 해석 결과가 SO 에서 왔든 레인에서 왔든 같은 문장을 탄다.

### 도달 판정 — 셀 일치 → 체비셰프 1 이내

D2 가 셀 일치(`currentCell.Equals(waypointCell)`)로 시작한 근거는 「필드가 이미 그 칸으로 데려간다」였고, **판당 2기인 Skimmer 에서는 맞았다**(Serpent 라이브 계측 5,295프레임, 순서 위반 0).

**스웜에서는 안 맞는다.** 축분리 스윕이 서로를 밀어내므로 20기가 한 칸에 수렴할 수 없다. 밀려서 그 칸을 **스치고 지나간** 개체는 `advanced` 가 서지 않아 되돌아온다 — 화면에서 버그로 읽히고, 이 unit 의 목적(스웜을 저작 경로로 보낸다)이 곧 그 조건이다.

`WaypointProgress.Step` 의 도달 술어를 체비셰프 1 이내로 바꾼다. 순수 함수이고 **인자 추가가 없다** — 지금도 현재 셀과 목표 셀만 본다. 「도달 불가 시 건너뜀」 안전망은 그대로다.

**완화가 만드는 저작 함정 — 인접한 두 지점은 뒤엣것이 자동 통과된다.** 저작자에겐 지점이 둘로 보이는데 실제로는 하나만 작동한다. `ValidatePaths` 가 연속 중복 경고 옆에서 **체비셰프 1 이내 인접**도 경고한다(계약 9 — 조용하면 안 된다). 같은 이유로 **스폰 바로 옆 첫 지점도 무의미**하다.

⚠ **반경을 저작 값으로 만들지 않는다.** `1` 은 「인접 칸이면 지났다」는 **격자의 위상**이지 튜닝 손잡이가 아니다. 제약 6(하드코딩 수치 금지)은 게임 밸런스 값에 관한 것이고, 이것은 8이웃 격자의 정의다 — 저작 필드로 노출하면 맵마다 다른 값이 들어와 순서 관리가 다시 이동 방식을 알게 된다(계약 1 위반).

## 완료 기준

- **EditMode**
  - 해석 우선순위 3케이스 — SO 지정 / 레인 기본 / 둘 다 없음(골 직행)
  - SO 지정이 레인 기본을 **이긴다**

  - 도달 불가 건너뜀이 유지된다
- **PlayMode** — 두 레인이 서로 다른 경로를 실제로 통과한다. **통과 순서를 센다**(계약 6 — 순수 함수 그린은 증거가 아니다)
- **무회귀** — `spawnRoutes` 미저작 맵의 이동이 기존과 동일. 기존 `WaypointRoutingLiveTest` 초록
